# 场景一：输出程序与文件

## 配置文件

| 类型 | 路径 | 说明 |
|---|---|---|
| 场景一主配置 | `config/data_clean/data_clean_calibrated.yaml` | 现有浏览器标定向导写回的主配置，后续需迁移到 [[Scene1Config]] 契约。 |
| 夹爪配置 | `gripper_streams` / [[GripperCalibrationConfig]] | 由浏览器 GoPro 标定程序生成，包含 marker、像素范围和 `gripper_max`。 |
| 位姿转换配置 | `camera_from_tcp.translation_mm`、`work_frames.position_mm / rotation_euler_rad` | 普通 Web 配置中心维护；人工平移单位 `mm`，work frame 旋转单位 `rad`，Runtime 位置统一换算为 `m`。 |
| 位姿转换配置（旧） | `frame_alignment` / [[FrameAlignmentConfig]] | 已废弃，仅保留历史读取兼容。 |

## 程序入口

| 程序 / 模块 | 路径 | 说明 |
|---|---|---|
| 浏览器标定向导 | `src/data_clean/ui/mcap_calibration_wizard.py` | 已有实现。负责启动浏览器、显示左右 GoPro 画面、采样/点击并写回配置。 |
| MCAP 批处理入口 | `src/data_clean/runtime/mcap_clean_launcher.py`、`src/data_clean/ui/web_launcher.py` | legacy CLI 与普通 Web 批次入口。 |
| 配置加载 | `src/data_clean/config/mcap_process_config.py`、`src/data_clean/repo/config/mcap_process_config.py` | 解析 [[GripperCalibrationConfig]]、`camera_from_tcp`、`work_frames` 和旧配置兼容。 |
| 生产配置模块 | `src/data_clean/runtime/production_config.py` | 普通 Web 配置中心的读取、校验、原子保存和 readiness 检查。 |
| 夹爪宽度提取 | `src/data_clean/service/gripper_width.py` | 根据夹爪配置生成 gripper width。 |
| 动态 TCP 中间位姿 | `src/data_clean/service/tcp_transform.py` | 将每帧 Baton Mini pose 与 `camera_from_tcp.translation_mm` 组合为 [[TcpInCamera]]。 |
| arm-base 位姿转换 | `src/data_clean/service/arm_base_transform.py` | 调用 `Algo.rm_algo_workframe2base` 将动态 TCP 中间位姿转换为 [[ArmBaseTcpPose]]。 |
| MCAP 写出 | `src/data_clean/service/mcap_io.py` | 后续需保留 raw pose 并写出 arm-base TCP pose。 |

## 输出数据

| 输出 | 路径 / topic | 契约 |
|---|---|---|
| cleaned MCAP | `asset/阶段二：数据清洗/dev/mcap_cleaned/*.mcap` | [[CleanedMcap]] |
| raw pose | `/baton_mini_left/fast_odom`、`/baton_mini_right/fast_odom` | 必须保留或可追溯。 |
| arm-base TCP pose | `/left_arm_base_tcp_pose`、`/right_arm_base_tcp_pose`（frame_id=`left_arm_base` / `right_arm_base`） | [[ArmBaseTcpPose]] |
| ~~common camera pose~~ | ~~配置中的 `output_camera_pose_common`~~ | ~~[[CommonFrameCameraPose]]~~ 历史字段，不推荐使用 |
| ~~common TCP pose~~ | ~~配置中的 `output_tcp_pose_common`~~ | ~~[[CommonFrameTcpPose]]~~ 历史字段，不推荐使用 |
| gripper width | `/gopro_left/gripper_width`、`/gopro_right/gripper_width` | [[GripperWidthSample]]，`std_msgs/msg/Float32`，归一化 `[0, 1]`。 |

## 需要改造的现实差异

- 历史文档中仍可能出现 `start_from_common` 和替换 pose payload 的旧语义；当前有效契约要求 raw pose 保留，arm-base TCP pose 有明确输出 topic。
- 新位姿配置默认使用 `camera_from_tcp.translation_mm` + [[WorkFrameInBaseConfig]] + `work_frames.position_mm / rotation_euler_rad`，不再依赖 `common_frame`。
- 浏览器配置生成器已经存在；普通 Web 只暴露 gripper-only 自动标定入口和紧凑 arm-base 配置中心。
