# L3 候选选择行为

## 消费 Agent

- 主 Agent

## 本文职责

本文只约束主 Agent 如何从目标 L2 dispatch 中选择本轮可派发的 L3 候选。

## 不负责

本文不生成 sub-agent prompt、不执行 L3、不验收、不提交。

## 选择条件

候选 L3 必须同时满足：

- 属于当前目标 L2。
- `dispatch_status` 为 `ready`。
- `depends_on` 全部完成或明确豁免。
- 外部依赖 L2 Gate 满足要求。
- 当前 wave 已开放。
- 不与同轮其他候选产生 `conflict_scope` 冲突。
- 满足 `must_run_after`。
- 不超过 `max_parallel_agents`。

## 冲突判断

以下任一字段有交集时，不得并行：

- `conflict_scope.files`
- `conflict_scope.modules`
- `conflict_scope.config_keys`
- `conflict_scope.hardware_paths`

## 输出

- 本轮可派发 L3 列表。
- 每个 L3 的派发理由。
- 被跳过 L3 及跳过原因。
