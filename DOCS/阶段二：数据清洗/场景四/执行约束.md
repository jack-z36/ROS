# 阶段二场景四：执行约束

## 必读文档

每次处理本场景前，必须先阅读阶段二四个阶段级文档，以及本场景五个固定文档。涉及对齐结果时，还应阅读场景三的目标描述和背景信息。

## 前置条件

- 场景三已完成，aligned MCAP 和 alignment_report 可用。
- 数据的 observation 字段、action 格式和坐标系定义已明确。

## 技术约束

- action chunk 必须使用 UMI 风格（相对于同一当前起点的相对轨迹），不能使用逐步 delta。
- 位姿字段必须是 common frame 下的 TCP pose，不能是 raw pose。
- schema 文件必须记录单位、shape、frame、四元数顺序和字段来源。
- `dataset_index.parquet` 字段名和类型必须尽早固定。

## 解耦边界

- 本场景不重新执行滤波和异常值处理（场景二已负责）。
- 本场景不重新执行时间对齐（场景三已负责）。
- 本场景不导出训练格式（场景五负责）。
- 本场景不做部署阶段在线安全检查。

## 验收边界

不能把以下情况算作完成：

- 只创建目录，没有生成 schema 文件。
- schema 中没有单位、shape、frame 或字段来源。
- step_index 无法定位 observation 来源。
- action chunk 不是相对于同一当前起点的相对轨迹。
- masks 只给布尔值，不记录 invalid reason。
- 没有生成 alignment/quality/robot_constraint report。
- processing_manifest 缺失。
