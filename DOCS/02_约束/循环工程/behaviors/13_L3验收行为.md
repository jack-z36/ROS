# L3 验收行为

## 消费 Agent

- 验收 sub-agent

## 本文职责

本文只约束验收 sub-agent 如何验收单个 L3 并输出固定结论。

## 不负责

本文不实现修复、不更新 dispatch、不提交 Git、不执行 L2 Gate。

## 必须行为

- 先读取对应 L3 验收卡片。
- 按验收卡片的 `acceptance_mode` 执行。
- 读取对应 L3 文件、执行摘要、允许查看的 diff 和日志。
- 写入新的 acceptance round 日志。
- 输出固定结论。

## 固定结论

- `PASS_LOCAL`
- `FAIL_LOCAL`
- `BLOCKED_ENV`
- `BLOCKED_HARDWARE_EXPECTED`
- `DEFER_TO_L2_GATE`

## 禁止事项

- 禁止改源码。
- 禁止改测试。
- 禁止改任务状态。
- 禁止改 Git。
- 禁止覆盖旧 round 日志。
- 禁止无硬件时声明 real-robot 通过。
