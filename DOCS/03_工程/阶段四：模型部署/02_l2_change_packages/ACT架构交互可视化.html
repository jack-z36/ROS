宏观数据流：外部数据如何变成执行器命令

只看关键 RAM 对象的流转和所有权。InferenceRequest 是 ControlLoop 发出的异步请求（不是模型 batch）；ActionChunk 是动作块（不是单步 action）；raw single action 经 SafetyGuard 后直接交给 L2-06 发布。

ControlLoop.tick()：每一轮调度什么

tick 是中央总控：读状态、调服务、做发布决策，不亲自做数学加工。第 ④ 步取 raw action 是条件分叉——多数 tick 直接取 active 动作；只有 chunk 切换边界（cursor≥execute_horizon 或 chunk 用尽，且有 pending）才走 smoothstep blend。任何环节不可用都汇入 fallback。

失败传播：每类失败如何被暴露

失败不隐藏：配置非法阻断启动；观测/推理/chunk/safety 问题进入 fallback（hold/safe_stop/status-only）；hardware gate 关闭只 shadow；bridge/driver 失败写入 command status。

失败源 状态/指标 外部输出

Metrics / status：所有 L2 共同贡献

Metrics 不是某个 L2 的私有输出。每个 L2 贡献运行事件，由 L2-07 统一汇总到 RuntimeMetrics，再发布为 /act/status、/act/metrics；L2-06 额外发布硬件发送链路的 /act/command/status。

L2-07 ControlLoop 中央运行调度按 control_hz 周期调度各 service，是中央总控而非加工函数

输入

DeployConfig · latest_observation · inference_request_queue · chunk_result_queue · chunk smoother · SafetyGuard · publisher/bridge

输出

InferenceRequest · safe action 或 fallback 输出（交 L2-06 发布）· status/metrics

负责

  • 按 control_hz 周期运行 tick
  • 读取 latest observation
  • 决定是否提交 InferenceRequest（prefetch 策略）
  • 收集 ActionChunk，调 L2-04 取 raw action
  • 调 L2-05 安全检查，调 L2-06 发布
  • 处理 fallback：无 observation/chunk 过期/safety 拒绝/推理失败
  • 更新 metrics 和 status

不负责

  • 不直接解析配置文件
  • 不直接预处理图像
  • 不直接构造 ACT batch 或前向推理
  • 不直接实现硬件 SDK 细节
  • 不把 service 逻辑塞进 tick() 内部

阅读方式

Human View

先看什么

  • 先看"总览"，确认 ControlLoop 是中央总控，L2-01 是契约地基。
  • 再看"宏观数据流"，确认外部数据如何变成执行器命令。
  • 重点看"ControlLoop 调控"：tick 每轮 8 步，第 ⑥ 步取 raw action 是条件分叉——常规直取 vs 边界 blend。
  • 最后看"失败传播"和"Metrics / status"。

L2-04 平滑的触发条件

  • 常规（多数 tick）：直接取 active_chunk.actions[cursor]，cursor 自增。
  • 边界 blend：cursor ≥ execute_horizon 或 chunk 用尽，且有 pending_chunk 时，用 smoothstep 在 last_command 与新 chunk 之间做 blend_steps 步混合。
  • 冷启动 / blend_steps≤0 / 无 last_command：硬切，不 blend。

关键不变量

  • tick() 是中央调度器，不吞并 L2-02~L2-06 的实现。
  • L2-04 只管理 chunk 生命周期和平滑，不做安全检查。
  • L2-05 只做 policy-action 通用安全检查，不做硬件级检查。
  • 真机发送必须经 shadow-run / gate / command_status。

不要把它当成什么

  • 不是 L3 任务生成依据。
  • 不是字段级契约或完整配置 schema。
  • 不是 Pi0.5 源码盘点（Pi0.5 仅作为参考）。
