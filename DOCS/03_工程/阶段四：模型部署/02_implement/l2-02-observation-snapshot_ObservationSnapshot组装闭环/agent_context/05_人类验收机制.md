  - 验收项 3：Pi0.5 映射审查 -> 对象级源码盘点完整 -> [ ] 通过
  - 验收项 4：HTML 对齐检查 -> view 均可追溯到 agent_context -> [ ] 通过
  - 验收项 5：ROS 真机边界 -> env / hardware blocked 记录正确 -> [ ] 通过

缺少验收人、日期或「已通过」勾选时，不允许视为通过。

## 4. 真机与 ROS 风险

- 本 L2 不触发机械臂或夹爪动作。
- 本 L2 真实 ROS topic 订阅需要 ROS 环境和 mock / shadow topic；当前无 ROS 环境只能验收 service/runtime mock 行为。
- 真机传感器接入不是本 L2 自动验收条件。若后续现场验证，需要用户明确授权、ROS topic 可观察、记录缺字段和 stale 现象。
