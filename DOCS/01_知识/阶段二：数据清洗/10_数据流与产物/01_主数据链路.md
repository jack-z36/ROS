# 主数据链路

## 核心链路

阶段二主数据链路为：

```text
raw MCAP
  -> cleaned MCAP
  -> MCAP_A
  -> aligned MCAP
  -> LeRobotDataset v3
  -> PI0.5 / ACT 训练前检查
```

这条链路的核心变化是：数据从 ROS2 topic 日志逐步变成训练框架可消费的 episode / step / observation / action 结构。

## 产物语义

| 产物 | 语义 | 主要下游 |
|---|---|---|
| raw MCAP | 阶段一/Octopus 采集的原始多 topic 日志。 | 场景一清洗 |
| cleaned MCAP | 补齐夹爪宽度、位姿派生和基础清洗后的 MCAP。 | 场景二可靠性处理 |
| MCAP_A | 经过异常检测、修复、滤波和主数据写出的中间 MCAP。 | 场景三 step 对齐 |
| aligned MCAP | 按统一 step 时间轴对齐后的语义 MCAP。 | LeRobot v3 构建 |
| LeRobotDataset v3 | 当前阶段二目标数据集格式。 | PI0.5 / ACT 训练前检查 |

## 场景关系

- 场景一：`raw MCAP -> cleaned MCAP`
- 场景二：`cleaned MCAP -> MCAP_A`
- 场景三：`MCAP_A -> aligned MCAP`
- 场景四：`aligned MCAP -> LeRobotDataset v3`
- 场景五：训练前检查与数据集交付判断
