# L3 状态固化行为

## 消费 Agent

- 主 Agent

## 本文职责

本文只约束主 Agent 如何在 L3 验收后固化 dispatch、验收证据和状态摘要。

## 不负责

本文不定义 L3 实现、验收结论生成或 Git 提交流程。

## 可固化结论

以下结论可进入 `accepted_local`：

- `PASS_LOCAL`
- `DEFER_TO_L2_GATE`
- `BLOCKED_ENV`
- `BLOCKED_HARDWARE_EXPECTED`

`FAIL_LOCAL` 必须交给失败回路处理行为。

## 写入要求

- dispatch 状态必须与验收结论一致。
- 验收日志路径必须可追溯。
- `00_status/l3_dispatch_status.md` 可作为摘要更新。
- 状态摘要不得覆盖权威验收日志事实。

## 禁止事项

- 禁止只在最终回复中口头说明完成。
- 禁止使用未定义状态。
- 禁止验收日志缺失时标记完成。
