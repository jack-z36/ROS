# 回调机制详解

## 总览

`Pi05VlaDeployNode` 注册 **5 种回调函数**，对应 **10 路 ROS2 topic**。每个回调在收到消息后完成两件事：
1. **就地预处理**数据并存入 `ObservationCollector`
2. 尝试触发 `_publish_observation_if_ready()`，若所有字段到齐则产出 `ObservationSnapshot`

所有回调运行在 ROS2 executor 线程中，通过 `threading.Lock` 保证线程安全。

---

## 回调总表

| 回调 | 订阅 Topic 数 | Msg Type | 处理内容 | 存入 Collector 的字段 |
|------|-------------|----------|----------|----------------------|
| `_image_cb` | 3 路 | `Image` / `CompressedImage` | 解码 + resize_pad + 归一化 | `_images[name]` |
| `_proprio_cb` | 1 路 | `JointState` | 拆分左右臂 12D → 各 6D | `_values["left_arm_q"]`, `_values["right_arm_q"]` |
| `_hand_cb` | 2 路 | `JointState` | 提取第一个 position 值 | `_values["{side}_hand_q"]` |
| `_point_cb` | 2 路 | `Point` | 提取 xyz 3D 向量 | `_values[key]` |
| `_vec3_cb` | 2 路 | `Vector3` | 提取 xyz 3D 向量 | `_values[key]` |

## 回调 1：`_image_cb` — 图像回调

### 注册方式

```python
# _create_subscriptions() 中，为每路相机动态注册：
for image_name in self.policy_image_names:  # ("top", "left_wrist", "right_wrist")
    self.create_subscription(
        Image,                          # transport="raw" 时
        raw_topic,                      # 如 /realsense/top/color/image_raw
        lambda msg, name=image_name: self._image_cb(name, msg),
        10,                             # queue_size
    )
```

> [!note] 闭包陷阱
> `lambda msg, name=image_name: ...` 中的 `name=image_name` 是默认参数绑定，确保每个闭包捕获**当前循环值**而非循环变量本身。如果不加这个默认参数，所有回调都会使用循环结束时的最后一个 `image_name`。

### 完整处理流程

```
ROS2 Image msg 到达
  │
  ├─ 1. _decode_image(msg)
  │     ├─ CompressedImage → cv2.imdecode → BGR → cvtColor → RGB
  │     └─ Image (raw)     → reshape → 条件 cvtColor → RGB
  │     └─ 输出: np.ndarray (H, W, 3) uint8
  │
  ├─ 2. preprocess_rgb_image(rgb, self.image_config)
  │     ├─ resize_pad 模式:
  │     │   ├─ 等比缩放: scale = min(224/W, 224/H)
  │     │   ├─ cv2.resize(rgb, (new_W, new_H), INTER_AREA)
  │     │   ├─ 居中置于 (224, 224) 黑色画布
  │     │   └─ TF.to_tensor(canvas) → float32 [0, 1]
  │     └─ 输出: torch.Tensor (3, 224, 224) float32
  │
  ├─ 3. collector.update_image(name, tensor)
  │     └─ 加锁 → _images[name] = tensor.detach().clone()
  │     └─ 记录时间戳 _stamps[f"image_{name}"] = time.monotonic()
  │
  └─ 4. _publish_observation_if_ready()
        └─ 见下方统一出口
```

### 解码细节（`_decode_image`）

| 输入 encoding | 处理 |
|---------------|------|
| `CompressedImage` | `np.frombuffer` → `cv2.imdecode(INTER_COLOR)` → `cvtColor(BGR2RGB)` |
| `rgb8` | `reshape(H, W, 3)` → 直接使用 |
| `bgr8` | `reshape(H, W, 3)` → `cvtColor(BGR2RGB)` |
| `rgba8` | `reshape(H, W, 4)` → `cvtColor(RGBA2RGB)` |
| `bgra8` | `reshape(H, W, 4)` → `cvtColor(BGRA2RGB)` |

> [!warning] 异常处理
> `_decode_image` 可能抛出 `ValueError`（不支持的 encoding 或解码失败）。外层 `_image_cb` 用 `try/except` 捕获并记录 warning 日志，**不会中断程序**。

### resize_pad 图解

```
原始图像 (H, W)            缩放后 (h, w)            输出 (224, 224)
┌──────────────┐          ┌──────────┐            ┌──────────────┐
│              │          │          │            │   ■■■■■■■    │
│   原始内容    │  ──→    │ 缩放内容  │   ──→     │   ■内容■    │
│              │          │          │            │   ■■■■■■■    │
└──────────────┘          └──────────┘            └──────────────┘
                            scale = min(224/W, 224/H)
                            黑色填充 (0, 0, 0) → uint8
                            TF.to_tensor() 自动 [0,255] → [0,1]
```

## 回调 2：`_proprio_cb` — 本体感觉回调

### 注册方式

```python
self.create_subscription(
    JointState,
    topics.proprioception,        # /vla_teleop/proprioception
    self._proprio_cb,
    10,
)
```

### 完整处理流程

```
JointState msg 到达
  │
  ├─ 1. 提取 position 列表
  │     positions = list(msg.position)     # [right_j1, ..., right_j6, left_j1, ..., left_j6]
  │
  ├─ 2. decode_picotele_proprioception(values)
  │     ├─ right = values[0:6].copy()     # 前 6 个 = 右臂
  │     └─ left  = values[6:12].copy()    # 后 6 个 = 左臂
  │
  ├─ 3. collector.update_proprioception(positions)
  │     ├─ 加锁
  │     ├─ _values["left_arm_q"]  = left   # np.ndarray (6,) float32
  │     ├─ _values["right_arm_q"] = right  # np.ndarray (6,) float32
  │     └─ _stamps["proprioception"] = time.monotonic()
  │
  └─ 4. _publish_observation_if_ready()
```

> [!important] 编码顺序：right_left
> 默认配置 `proprioception_order: right_left`，即 `/vla_teleop/proprioception` 发布的 12D 向量是 **[right6, left6]** 顺序（picotele 遗留协议）。`decode_picotele_proprioception()` 负责将其拆分并**翻转顺序**，使内部字段 `left_arm_q` 对应 index 0-5，`right_arm_q` 对应 index 6-11，与 26D 编码布局一致。
>
> 若配置为 `left_right`，则直接切片 `left = values[:6]`, `right = values[6:12]`，不做翻转。

## 回调 3：`_hand_cb` — 灵巧手回调

### 注册方式

```python
# 左手
self.create_subscription(
    JointState, topics.left_hand_state,   # /inspire/left_hand/joint_states
    lambda msg: self._hand_cb("left", msg), 10,
)
# 右手
self.create_subscription(
    JointState, topics.right_hand_state,  # /inspire/right_hand/joint_states
    lambda msg: self._hand_cb("right", msg), 10,
)
```

### 完整处理流程

```
JointState msg 到达
  │
  ├─ 1. 空值检查
  │     if not msg.position: return    # 无数据则跳过
  │
  ├─ 2. 提取第一个值
  │     value = float(msg.position[0])  # 单自由度，范围 300-1000
  │
  ├─ 3. collector.update_hand(side, value)
  │     ├─ 加锁
  │     ├─ _values[f"{side}_hand_q"] = float(value)
  │     └─ _stamps[f"{side}_hand"] = time.monotonic()
  │
  └─ 4. _publish_observation_if_ready()
```

> [!note] 单自由度
> Inspire 灵巧手在此部署中只用 `position[0]`，代表开合程度。300 = 完全闭合，1000 = 完全张开。

## 回调 4 & 5：`_point_cb` / `_vec3_cb` — 末端位姿回调

### 注册方式

```python
# 末端位置 (Point)
self.create_subscription(Point, topics.left_ee_position,
    lambda msg: self._point_cb("left_ee_pos", msg), 10)
self.create_subscription(Point, topics.right_ee_position,
    lambda msg: self._point_cb("right_ee_pos", msg), 10)

# 末端姿态 (Vector3)
self.create_subscription(Vector3, topics.left_ee_rpy,
    lambda msg: self._vec3_cb("left_ee_rpy", msg), 10)
self.create_subscription(Vector3, topics.right_ee_rpy,
    lambda msg: self._vec3_cb("right_ee_rpy", msg), 10)
```

### 完整处理流程

```
Point / Vector3 msg 到达
  │
  ├─ 1. 提取 xyz 三维向量
  │     Point:    [msg.x, msg.y, msg.z]   # 末端位置 (m)
  │     Vector3:  [msg.x, msg.y, msg.z]   # 末端姿态 rpy (rad)
  │
  ├─ 2. collector.update_vector(key, values)
  │     ├─ np.asarray(values, dtype=np.float32).reshape(-1)
  │     ├─ 加锁
  │     ├─ _values[key] = vector            # np.ndarray (3,) float32
  │     └─ _stamps[key] = time.monotonic()
  │
  └─ 3. _publish_observation_if_ready()
```

> [!tip] `_point_cb` 和 `_vec3_cb` 的实现完全相同
> 两个回调的函数体一样——都是提取 xyz 三个 float → `update_vector(key, [x, y, z])`。区别仅在于 key 名和 ROS2 Msg Type（`Point` vs `Vector3`），它们在 ROS2 IDL 中结构相同。

## 统一出口：`_publish_observation_if_ready()`

每个回调的**最后一步**都调用此方法，尝试产出完整的 `ObservationSnapshot`：

```
_publish_observation_if_ready()
  │
  ├─ collector.snapshot(max_age_s=0.5)
  │     │
  │     ├─ 检查必需字段是否到齐
  │     │   ├─ 3 路图像: top, left_wrist, right_wrist
  │     │   └─ 8 个状态字段: left_arm_q, right_arm_q,
  │     │       left_hand_q, right_hand_q,
  │     │       left_ee_pos, left_ee_rpy, right_ee_pos, right_ee_rpy
  │     │
  │     ├─ 检查时间戳是否过期
  │     │   └─ 任何一个字段的 (now - stamp) > max_age_s → 返回 None
  │     │
  │     └─ 组装 ObservationSnapshot
  │           ├─ images = clone 所有图像 tensor
  │           ├─ values = copy 所有状态值
  │           ├─ state = BimanualState(...)
  │           ├─ encoded_state = encode_bimanual_state(state) → (26,)
  │           └─ captured_at_s = now
  │
  ├─ snapshot 不为 None → shared_buffer.set_observation(snapshot)
  │     └─ 覆盖式写入，旧观测被丢弃（metrics 计数 +1）
  │
  └─ snapshot 为 None → 每 2 秒打印一次缺失字段日志
        "waiting for observation fields: image_top, right_ee_rpy"
```

> [!important] 触发频率
> `snapshot()` 在**每次任何回调执行后**都被调用。由于 10 路 topic 以不同频率发布（相机 ~30Hz，关节角 ~100Hz 等），实际触发频率远高于推理频率（10Hz）。多余的 `ObservationSnapshot` 在 `SharedBuffer` 中被覆盖丢弃。

## 线程安全模型

```
ROS2 Executor 线程 (4 threads)         推理线程 (InferenceWorker)        控制线程 (ControlLoop)
  │                                       │                               │
  ├─ _image_cb ─┐                         │                               │
  ├─ _proprio_cb │                        │                               │
  ├─ _hand_cb   ├─→ collector._lock ──→ snapshot() ──→ SharedBuffer._lock
  ├─ _point_cb  │    (threading.Lock)      │              (threading.Lock)  │
  ├─ _vec3_cb ──┘                         │                               │
  │                                       │                               │
  │                              shared_buffer.latest_observation()       │
  │                              shared_buffer.set_observation()          │
```

- `ObservationCollector._lock`：保护 `_images`、`_values`、`_stamps` 的读写
- `SharedBuffer._lock`：保护 `_latest_observation` 的读写
- 所有回调共享同一个 `ObservationCollector` 实例，通过 `_lock` 保证单次 `snapshot()` 看到一致的数据快照

## 数据从回调到 26D 编码的完整映射

```
回调写入 Collector._values:
  _proprio_cb → "left_arm_q"   (6,)   ──┐
  _proprio_cb → "right_arm_q"  (6,)   ──┤
  _hand_cb    → "left_hand_q"  float  ──┤
  _hand_cb    → "right_hand_q" float  ──┤
  _point_cb   → "left_ee_pos"  (3,)   ──┼──→ BimanualState ──→ encode_bimanual_state() ──→ (26,) float32
  _vec3_cb    → "left_ee_rpy"  (3,)   ──┤
  _point_cb   → "right_ee_pos" (3,)   ──┤
  _vec3_cb    → "right_ee_rpy" (3,)   ──┘

回调写入 Collector._images:
  _image_cb   → "top"          (3,224,224) ──┐
  _image_cb   → "left_wrist"   (3,224,224) ──┼──→ ObservationSnapshot.images
  _image_cb   → "right_wrist"  (3,224,224) ──┘
```
