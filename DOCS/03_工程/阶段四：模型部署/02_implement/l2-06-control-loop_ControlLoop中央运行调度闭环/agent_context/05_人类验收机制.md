# L2-06 人类验收机制

## 人类验收清单

| 项目 | cwd / 命令 | 环境与输入 | 观察点 | PASS | FAIL 调试入口 | 风险 |
|---|---|---|---|---|---|---|
| mock Gate | 仓库根：`bash DOCS/03_工程/阶段四：模型部署/05_acceptance/l2-06-control-loop/scripts/l2_06_verify.sh --mode mock` | fake observation/chunk/guard/publisher | terminal labels 与汇总 | 无 FAIL；cursor、fallback、metrics 标签 PASS | `runtime/control_loop.py` 与对应 pytest | 低 |
| dry-run | 同上加 `--mode dry-run` | ROS 可启动；禁用硬件输出 | `/act/status`、`/act/metrics` | timer 运行，不发送 driver 命令 | UI node、ROS 日志 | 中 |
| shadow-run | 同上加 `--mode shadow` | topic/bridge 可用，gate 关闭 | command_status | safe/fallback 可追溯且 `sent_to_driver=false` | L2-05 bridge/status | 高 |
| 真机 | 仅明确授权后按运行手册 | E-stop 就绪、shadow 记录、现场操作者 | command_status 与机器人 | 由人工签字，不由本表自动断言 | 停机、E-stop、driver 日志 | 极高 |

真机开始前必须确认：操作者授权、E-stop 可达、gate/deadman 状态、shadow-run 证据与明确安全区域。任何缺失均为 `BLOCKED`，不得将机器人行为标为已通过。
