# 阶段产物语义边界

## raw MCAP

raw MCAP 是外部只读输入。阶段二不应覆盖、重命名或移动原始 MCAP；所有处理结果都写入独立产物目录或 sidecar。

## cleaned MCAP

cleaned MCAP 是场景一输出，主要负责补齐后续链路需要的基础语义：

- 夹爪宽度。
- Baton Mini 位姿到 TCP / arm-base TCP pose 的派生链路。
- 清洗报告、配置快照和失败原因。

cleaned MCAP 不负责滤波、step 对齐或 LeRobotDataset v3 目录结构。

## MCAP_A

MCAP_A 是场景二输出，承载经过可靠性检测、补全、滤波后的主数据。它仍然是 MCAP 世界中的中间产物，重点是让场景三有更稳定的输入。

MCAP_A 不决定最终 LeRobotDataset v3 的 episode、action 和 metadata 结构。

## aligned MCAP

aligned MCAP 是场景三输出，表达统一 step 时间轴上的对齐结果。它需要能追溯每个 step 字段的来源 topic、对齐方法、时间误差和质量状态。

aligned MCAP 不等于训练数据集。它是 LeRobotDataset v3 构建前的语义中间层。

## LeRobotDataset v3

LeRobotDataset v3 是阶段二当前目标产物。它需要表达 PI0.5 / ACT 训练前检查所需的 observation、action、episode、step 和必要 metadata。

实际 feature 维度、offset、启用段落和 action 语义以当前 LeRobot feature contract 为准，不应在知识层写死为某个固定维度。
