# ui 层设计：L2-01

## 1. 本 L2 不在该层新增源码产物

原因：

- `ui/` 层负责外部交互边界，例如 ROS node、subscriber、publisher、message converter。
- L2-01 只定义 topic 名和配置对象，不创建 ROS node，不订阅，不发布。

## 2. 本 L2 允许定义的 topic 契约

`TopicsConfig` 可以定义：

```text
/act/observation/*
/act/policy_action
/act/status
/act/metrics
/act/command/*
```

定义 topic 名不等于创建 publisher/subscriber。订阅属 L2-02，发布属 L2-05。

## 3. 与去除平滑处理的关系

本 L2 不定义任何 `/act/smoothed_action`、`/act/blended_action` 或 RTC 平滑相关 topic。第一版输出路径只围绕 raw/safe single action 和 command topic。

## 4. 验收如何确认

- L2-01 不产生 `src/model_deploy/act/ui/*.py` 或 launch 产物。
- topic 配置中不存在平滑处理专用 topic。

## 5. 边界继承声明

本文件边界来自当前 L1/L2 功能边界，不来自旧 layer-based L2 卡片。
