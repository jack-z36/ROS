# ui 层设计：L2-04

## 1. 本 L2 不在该层新增源码产物

原因：L2-04 不订阅 observation topic、不发布 policy action、不转换 ROS message、不调用机械臂或夹爪 SDK。外部交互由 L2-02 输入和 L2-05 输出承担。

## 2. 下游输出边界

L2-04 只把 C5 `SafetyResult` 交回 RAM 内调用方。L2-05负责：

- 把内部 `xyzw` 转换为 RM65 所需外部表示；
- 把部署 ActionDomain 的夹爪标量转换为 F100 硬件命令；
- topic、shadow-run、hardware gate、driver status。

因此本层不能增加 publisher、node、adapter 或 hardware handle。

## 3. Class/函数、依赖与验收

无 Class、无函数、无副作用。Pi0.5 bridge 二次过滤只是 L2-05 防御纵深参考。

验收如何确认：静态 import 检查 `service/safety_guard.py` 无 ROS/hardware；由 L2-05 shadow-run 验收 C5.action 的下游适配。

本文件的任务边界继承当前 L1/L2 功能边界，不继承旧 layer-based 卡片。
