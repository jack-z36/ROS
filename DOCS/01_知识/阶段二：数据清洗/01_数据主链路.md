# 阶段二数据主链路

当前阶段二主链路为：

```text
raw MCAP
  -> cleaned MCAP
  -> MCAP_A
  -> aligned MCAP
  -> Forge bridge
  -> LeRobot v3 dataset
```

## 产物语义

- raw MCAP：Octopus 录制的原始 topic 日志。
- cleaned MCAP：完成场景一清洗和派生字段写入后的 MCAP。
- MCAP_A：经过可靠性检测、修复和滤波后的主中间产物。
- aligned MCAP：按 step 时间轴对齐后的语义 MCAP。
- Forge bridge：临时训练格式桥接层。
- LeRobot v3 dataset：当前已跑通的训练格式验证产物。

## 历史兼容

旧 canonical dataset 设计保留为历史参考。当前默认理解应以 LeRobot v3 桥接主线为准；旧方案不得作为当前权威路线。
