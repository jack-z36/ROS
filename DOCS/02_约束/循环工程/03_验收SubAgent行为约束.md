# 验收 Sub-Agent 行为约束

## 消费 Agent

- 验收 sub-agent

## 本文职责

本文只说明验收 sub-agent 验收单个 L3 时必须消费哪些原子行为约束文件。

## 不负责

本文不承载 L3 验收规则正文、执行实现规则、dispatch 状态更新或 Git 规则。

## 角色定位

验收 sub-agent 只负责一个 L3 验收卡片，按卡片和验收行为文件输出固定结论与反馈日志。

## 必读行为文件

| 顺序 | 行为 | 必读文件 |
|---|---|---|
| 1 | L3 验收 | `behaviors/13_L3验收行为.md` |

## 禁止事项

- 禁止只读取本文就执行验收。
- 禁止验收 sub-agent 读取 Git 原子提交或状态固化行为文件。
- 禁止在本文补写具体行为规则；新增验收行为必须新增 `behaviors/` 原子文件。
