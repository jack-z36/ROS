# Git 同步加载规则

## 适用范围

涉及 Git 状态、提交、推送、拉取、远端、分支、合并或同步的任务。

## 触发信号

“提交”“推送”“同步”“拉取”“分支”“远端”“merge”“Git 状态”。

## 上下文加载顺序

1. 读取 `DOCS/02_约束/Git协作/INDEX.md`。
2. 读取 `DOCS/02_约束/Git协作/Git操作规则.md`。
3. 如果任务属于明确阶段，读取对应阶段专属 Git 规则。
4. 如果任务属于阶段四模型部署，读取 `skills/stage4-git-integrator/SKILL.md`。
5. 检查当前分支、远端、用户、工作区状态。
6. 按任务类型确认是否允许提交、推送、拉取或合并。
7. 执行前给出摘要和拟用提交信息。

## 必读入口

- `DOCS/02_约束/Git协作/INDEX.md`
- `DOCS/02_约束/Git协作/Git操作规则.md`

## 禁止默认读取

- 历史执行日志中的旧 Git 记录
- 归档中的旧分支策略

## 阻断条件

- 当前分支与任务要求不一致。
- 远端领先、分叉或冲突，需要 merge/rebase/强推。
- 用户未明确要求 Git 写操作。

## 输出要求

说明当前分支、变更范围、提交/推送结果和剩余工作区状态。
