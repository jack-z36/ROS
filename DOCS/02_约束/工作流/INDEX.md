# 工作流约束索引

本主题收纳必须遵守的工作流和模板资产。工作流属于约束体系，不放入工程区。

## 工作流入口

- `原工作流/从零编写程序.md`
- `原工作流/阶段二开发范式.md`

## 模板入口

- `原工作流/attachments/L2能力模块说明文件模板.md`
- `原工作流/attachments/L3微元任务文件模板.md`
- `原工作流/attachments/templates/`

## 读取规则

- 只有任务进入对应工作流时才读取工作流全文。
- 只有准备生成正式 L2/L3 文档时才读取模板全文。
- 工作流中的通用强制规则应逐步抽取到对应原子约束文件；模板资产保留在本主题下。
