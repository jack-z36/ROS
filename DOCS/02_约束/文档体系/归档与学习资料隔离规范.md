# 归档与学习资料隔离规范

## 适用范围

- 阶段：全局
- 任务模式：文档迁移、历史追溯、学习资料整理
- 适用对象：`DOCS/98_archive/`、`DOCS/99_learning/`
- 不适用对象：当前权威知识、约束和工程工作台

## 强制规则

`DOCS/98_archive/` 只用于保存旧快照、迁移过程记录和已失效但需要追溯的历史材料。

`DOCS/99_learning/` 只用于保存给人阅读的学习材料、外部厂商资料、长篇解释材料和历史复盘。

默认上下文加载规则不得读取 `98_archive` 或 `99_learning`。只有用户明确点名历史复盘、外部资料检索或学习笔记时，才允许定点读取。

## 禁止事项

- 禁止把归档内容作为当前权威规则。
- 禁止把 learning 内容作为默认 Agent 上下文。
- 禁止在归档或 learning 中继续维护当前进度。

## 维护规则

从归档或 learning 中抽取仍有效的语义时，必须迁入 `01_知识/`、`02_约束/` 或 `03_工程/`，并在新文档中标明来源。
