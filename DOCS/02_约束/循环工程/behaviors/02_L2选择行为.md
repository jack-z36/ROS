# L2 选择行为

## 消费 Agent

- 主 Agent

## 本文职责

本文只约束主 Agent 如何选择本轮 Ralph / OpenCode 循环的目标 L2。

## 不负责

本文不选择具体 L3、不派发 sub-agent、不执行 Git、不判断 L2 Gate 细节。

## 新版 L2 序列来源

主 Agent 必须以新版 L1 任务文档作为 L2 顺序来源：

```text
DOCS/03_工程/阶段四：模型部署/02_implement/00_L1_ACT部署程序任务文档.md
```

当前第一版 ACT 部署程序的唯一有效 L2 ID 序列是：

1. `l2-01-external-contract`
2. `l2-02-observation-snapshot`
3. `l2-03-act-inference`
4. `l2-04-action-smoothing`
5. `l2-05-safety-guard`
6. `l2-06-action-publisher`
7. `l2-07-control-loop`

旧 layer-based L2 ID 已作废：`l2-01-types`、`l2-02-config`、`l2-03-assembly`、`l2-04-publish`、`l2-05-hardware`。如果它们出现在 active dispatch、当前状态摘要或目标 L2 中，主 Agent 必须停止并报告“旧流程残留”。

## 选择规则

主 Agent 必须按新版 L2 依赖顺序扫描。

选择第一个同时满足以下条件的 L2：

- 上游依赖 L2 Gate 已通过或明确不需要。
- 本 L2 Gate 未通过。
- 本 L2 存在新版 L2 设计目录：`DOCS/03_工程/阶段四：模型部署/02_implement/<new-l2>/`。
- 本 L2 设计目录中引用新版 L1 Agent 架构上下文：`01_L1_ACT功能模块边界.md` 和 `02_L1_ACT功能模块协作架构.md`。
- 本 L2 dispatch 存在且路径为 `DOCS/03_工程/阶段四：模型部署/03_tasks/task/dispatch/<new-l2>.yaml`。
- 本 L2 acceptance 目录存在且路径为 `DOCS/03_工程/阶段四：模型部署/05_acceptance/<new-l2>/`。
- 本 L2 dispatch 中存在 `ready` L3，或存在可由状态恢复更新为 `ready` 的 L3。
- 本 L2 未处于 `waiting_user` 或不可解释 blocked。

## 输出

- 本轮目标 L2。
- 选择理由。
- 被跳过 L2 及跳过原因。

## 禁止事项

- 禁止同时选择多个 L2。
- 禁止跳过未通过 Gate 的上游 L2 推进下游。
- 禁止为了效率跨 L2 混合派发 L3。
- 禁止从 `_legacy_layer_based_act/`、`_archived_pi05/` 或旧 L2 ID 中选择目标 L2。
