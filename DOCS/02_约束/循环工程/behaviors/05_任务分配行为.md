# 任务分配行为

## 消费 Agent

- 主 Agent

## 本文职责

本文只约束主 Agent 如何把选中的单个 L3 分配给执行 sub-agent 或验收 sub-agent。

## 不负责

本文不定义 L3 实现步骤、不定义验收结论、不执行 Git。

## 执行任务分配

执行 sub-agent prompt 必须只包含：

- `DOCS/02_约束/循环工程/02_执行SubAgent行为约束.md`
- `DOCS/02_约束/循环工程/behaviors/06_L3执行实现行为.md`
- `DOCS/02_约束/循环工程/behaviors/07_L3局部验证行为.md`
- `DOCS/02_约束/循环工程/behaviors/08_执行交接行为.md`
- 被分配的单个 L3 文件路径
- 该 L3 文件列出的必读上下文

## 验收任务分配

验收 sub-agent prompt 必须只包含：

- `DOCS/02_约束/循环工程/03_验收SubAgent行为约束.md`
- `DOCS/02_约束/循环工程/behaviors/13_L3验收行为.md`
- 被分配的单个 L3 验收卡片路径
- 对应 L3 文件、执行摘要和允许查看的日志 / diff

## 禁止事项

- 禁止给 sub-agent 多个 L3。
- 禁止给执行 sub-agent Git 权限。
- 禁止给验收 sub-agent 修改源码或 dispatch 的权限。
- 禁止把整个阶段四目录作为 sub-agent 默认上下文。
