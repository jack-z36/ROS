# 阶段四：模型部署

## 1. 阶段目标

**本阶段定位**：阶段四负责把训练得到的 PI0.5 / VLA 能力接到真实双臂系统上。它关注模型 bundle、观测采集、动作解码、运行调度、安全约束和 ROS topic 边界，是连接训练模型与真实机器人的桥梁。

**本阶段输入**：训练好的模型 bundle
- PI0.5 / VLA 模型检查点
- 模型配置文件（`experiment_config.yaml`、`normalizers.json`）
- 适配器代码（`adapter/`）
- 训练时的 observation/action 契约

**本阶段输出**：机器人控制命令
- 左右臂关节目标（`/pi05_vla/command/*/joint_target`）
- 左右手夹爪目标（`/pi05_vla/command/*/target`）
- 状态和指标（`/pi05_vla/status`、`/pi05_vla/metrics`）
- 安全桥接命令（`/vla/*/safe_joint_target`）

**支撑下游**：
- 真实机器人执行层：通过 mux 路由到 picotele 执行
- 遥操作回退：支持手动接管（teleop mode）
- 安全约束层：关节增量限制、观测超时、命令超时

**本阶段不负责**：
- 不承载阶段二数据清洗细节
- 不负责模型训练（阶段三的工作）
- 不直接控制硬件（通过 picotele 和 mux 路由）
- 不做数据采集（阶段一的工作）

**注意事项**：
1. **运行模式**：`dry-run`（仅推理日志）、`shadow-run`（发布命令但不执行）、`safe-run`（安全执行）
2. **action 语义**：14 维 = 左臂 6 维 + 右臂 6 维 + 左右手各 1 维（`TCP_width` 语义）
3. **state 语义**：26 维 = 左右臂关节 + 左右手状态 + 左右末端位置和姿态
4. **坐标系**：左右臂分别属于独立物理坐标系，不能当成同一坐标系叠加解释
5. **安全约束**：最大关节增量 0.03 rad，观测超时 0.5s，命令超时 0.45s

## 5. 快速上手指南

### 5.1 环境准备
```bash
# 系统要求
# - Ubuntu 24.04 或兼容 ROS 2 Jazzy 的系统
# - NVIDIA GPU（支持 CUDA）
# - ROS 2 Jazzy

# 安装依赖
sudo apt install ros-jazzy-desktop
conda create -n lerobot312 python=3.12
conda activate lerobot312
pip install -e .
```

### 5.2 编译与启动
```bash
# 进入工作空间
cd 01-doing/ROS/src/model_deploy/pi05

# 安装依赖
pip install -e .

# 启动部署
source /opt/ros/jazzy/setup.bash
conda activate lerobot312
bash deploy/scripts/run_inference.sh
```

### 5.3 部署流程
1. **准备模型 bundle**：
   ```bash
   # 从训练机复制 bundle
   rsync -av /path/to/pi05_grasp_generalization_v1 \
     ~/pi05_ws/projects/pi05/outputs/exports/
   
   # 更新配置
   # 编辑 deploy/config/deploy.yaml
   # 设置 bundle.bundle_dir 指向 bundle 路径
   ```

2. **选择运行模式**：
   - `dry-run`：仅推理和日志，不发布命令
   - `shadow-run`：发布 `/pi05_vla/command/*`，但不执行
   - `safe-run`：发布命令并允许桥接执行

3. **启动部署**：
   ```bash
   # 启动推理
   bash deploy/scripts/run_inference.sh
   
   # 启动桥接（可选）
   bash deploy/scripts/run_bridge.sh
   
   # 启动 mux 路由（可选）
   bash deploy/scripts/run_command_mux.sh
   ```

4. **监控和调试**：
   ```bash
   # 查看 ROS topics
   ros2 topic list
   
   # 查看推理状态
   ros2 topic echo /pi05_vla/status
   
   # 查看性能指标
   ros2 topic echo /pi05_vla/metrics
   ```

### 5.4 常见问题
1. **GPU 不可用**：检查 `nvidia-smi`，确保 CUDA 驱动正常
2. **ROS 导入失败**：确保先 `source /opt/ros/jazzy/setup.bash`
3. **Bundle 路径错误**：检查 `deploy/config/deploy.yaml` 中的 `bundle.bundle_dir`
4. **机器人不动**：
   - `dry-run` 模式不发布命令
   - `shadow-run` 模式发布命令但桥接可能未启用
   - `safe-run` 模式需要确保 topic 和安全检查通过
5. **观测超时**：检查相机和 proprioception topic 是否正常发布

## 6. 系统架构

### 6.1 部署流水线
```text
训练模型 bundle
  -> PI0.5 推理引擎（10Hz）
  -> 动作解码（14维 action）
  -> 安全约束检查
  -> Bridge 桥接
  -> Mux 路由（teleop/vla 切换）
  -> picotele 执行
  -> 睿尔曼 R65 双臂
```

### 6.2 核心组件

| 组件 | 职责 | 关键配置 |
|---|---|---|
| PI0.5 推理引擎 | 模型推理，生成 action | `runtime.inference_hz: 10` |
| 观测采集 | 采集相机、proprioception、手部状态 | `topics.observation.*` |
| 动作解码 | 将模型输出转换为关节目标 | `action_dim: 14`, `state_dim: 26` |
| 安全约束 | 关节增量限制、超时检测 | `safety.*` |
| Bridge 桥接 | 将 VLA 命令路由到执行层 | `bridge.*` |
| Mux 路由 | teleop/vla 模式切换 | `mux.*` |

### 6.3 ROS Topic 映射

**观测 Topic**：
| Topic | 说明 | 频率 |
|---|---|---|
| `/realsense/top/color/image_raw` | 顶部相机图像 | 30Hz |
| `/realsense/left_hand/color/image_rect_raw` | 左手相机图像 | 30Hz |
| `/realsense/right_hand/color/image_rect_raw` | 右手相机图像 | 30Hz |
| `/vla_teleop/proprioception` | 本体感知（关节状态） | 100Hz |
| `/inspire/*/joint_states` | 手部关节状态 | 60Hz |
| `/left_arm/ee_position` | 左臂末端位置 | 100Hz |
| `/right_arm/ee_position` | 右臂末端位置 | 100Hz |

**命令 Topic**：
| Topic | 说明 | 频率 |
|---|---|---|
| `/pi05_vla/command/left_arm/joint_target` | 左臂关节目标 | 30Hz |
| `/pi05_vla/command/right_arm/joint_target` | 右臂关节目标 | 30Hz |
| `/pi05_vla/command/left_hand/target` | 左手夹爪目标 | 30Hz |
| `/pi05_vla/command/right_hand/target` | 右手夹爪目标 | 30Hz |
| `/pi05_vla/status` | 部署状态 | 1Hz |
| `/pi05_vla/metrics` | 性能指标 | 1Hz |

**桥接 Topic**：
| Topic | 说明 |
|---|---|
| `/vla/left_arm/safe_joint_target` | 左臂安全关节目标 |
| `/vla/right_arm/safe_joint_target` | 右臂安全关节目标 |
| `/vla/left_hand/trigger` | 左手触发 |
| `/vla/right_hand/trigger` | 右手触发 |

### 6.4 安全约束配置

| 参数 | 默认值 | 说明 |
|---|---|---|
| `max_joint_delta_rad` | 0.03 | 最大关节增量（弧度） |
| `stale_observation_timeout_s` | 0.5 | 观测超时（秒） |
| `command_timeout_s` | 0.45 | 命令超时（秒） |
| `clamp_normalized_action` | true | 是否 clamp 归一化 action |
| `hold_last_action` | true | 超时时是否保持最后动作 |
| `hand_min` | 300 | 手部最小值 |
| `hand_max` | 1000 | 手部最大值 |
