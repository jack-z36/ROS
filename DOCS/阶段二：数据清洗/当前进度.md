### 正常用户网页

已有能力：

- 本机网页仅监听 `127.0.0.1`，浏览器刷新或关闭不会取消任务。
- 看板、新建任务、历史记录、目录浏览、新建目录和当前层 `.mcap` 文件勾选。
- 最终 dataset 父目录可自由选择任意本机目录，不做路径限制或风险提示。
- 每个 MCAP 独立执行 cleaned、MCAP_A、aligned、Forge bridge；成功 bridge episodes 聚合为一个 LeRobot v3 dataset。
- 多批次可以并行运行，并共享默认最多 `6` 个文件处理 worker。
- 单文件失败不阻止成功 episode 发布；失败文件可以一键生成重试草稿。
- 用户取消批次时回滚本批次 dataset 与 sidecar；删除历史摘要不会删除真实产物。
- 结果页可视化展示 Forge quality 总分、各维度分数、逐 episode 分数和 flags。
- 结果页提供固定右手坐标系 TCP 3D 轨迹：单 episode 按原始时间戳播放，全部 episode 静态总览。
- 轨迹视图使用 `bounds.min` 作为左下角显示局部原点，只做可视化平移和等比例缩放，不改写原始坐标。
- `format-only` 双手轨迹使用共享 `common_frame` 单画布；`formal` 左右 `arm_base` 使用双画布同步播放。
- 历史任务没有新版轨迹缓存时，`GET /api/jobs/{job_id}/trajectory` 会按需补齐左右 bounds、坐标系 profile 和投影提示并写回 sidecar。
- 可按需启动 Forge Web Viewer，在新标签页打开最终 dataset。

网页 sidecar 固定写入：

```text
asset/阶段二：数据清洗/dev/debug/web_jobs/<dataset_name>_data_clean_sidecar/
```

- 场景四、场景五的正式 canonical/export 架构仍需继续推进；当前 LeRobot v3 是临时桥接验证路径。

## 风险与判断边界

- 不要把 `format-only` 的 LeRobot 输出当作正式训练数据。
- 不要把 Forge quality 分数单独当作数据质量最终结论；它缺少 formal 标定和机器人约束前提。
- aligned MCAP 是语义中间产物，临时 Forge bridge 必须输出到独立 `04_forge_bridge/`，避免污染场景三契约。
- Forge CLI `--config` 可能不会把 MCAP topic config 传给 reader；当前正确转换入口是 `runtime/forge_bridge_to_lerobot.py`。
- `formal` 左右 TCP 分别位于各自 arm-base 坐标系；可视化不得把两条轨迹当成共享物理坐标系直接叠加。
- 网页自由输出目录只适用于最终 LeRobot dataset；sidecar、中间 MCAP、bridge、日志和缓存仍必须留在受控目录。
