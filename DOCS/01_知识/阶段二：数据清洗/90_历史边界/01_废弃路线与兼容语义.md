# 废弃路线与兼容语义

## 文档定位

本页只记录会影响当前理解的历史边界。普通任务不应默认读取归档全文，也不应把历史路线恢复为当前权威路线。

## common_frame

`common_frame` 和旧 robot_base 转换只保留为历史兼容或开发 smoke 语义，不是普通生产主链路。

当前生产语义以左右 arm-base TCP pose 为主。左右 arm-base 属于不同物理坐标系，不能无条件叠加解释为同一世界坐标。

## canonical dataset

旧 canonical dataset 方案是过去的错误路线或历史参考，不再作为阶段二当前主线。

当前权威目标是 LeRobotDataset v3，用于 PI0.5 / ACT 训练前输入。生成新知识文档、工程规划、L2/L3 或功能定义时，不应再把 canonical dataset 作为当前目标产物。

## format-only

`format-only` 只能证明结构烟测、基础格式和部分质量检查链路能运行。它不能代表正式训练可用，也不能替代生产 readiness。
