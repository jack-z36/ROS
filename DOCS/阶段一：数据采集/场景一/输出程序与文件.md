# 场景一输出程序与文件

本文记录场景一“一个一个启动 4 个相机节点”已经形成或依赖的具体程序、文件地址和功能。

## 输出清单

| 类型 | 地址 | 功能 |
| --- | --- | --- |
| Baton Mini ROS2 launch | `src/baton_mini_sdk_demo/launch/baton_mini.launch.py` | 启动单个 Baton Mini ROS2 节点；支持 `server_ip`、`local_ip`、`node_name` 和各 topic 名称参数，用于分别启动 `baton_mini_right` 与 `baton_mini_left`。 |
| Baton Mini 主程序 | `src/baton_mini_sdk_demo/src/baton_mini.cpp` | 连接 Baton Mini 设备、登录 SDK、开启算法、IMU、快速里程计和图像接收，并把数据交给 ROS 接口发布。 |
| Baton Mini ROS 发布接口 | `src/baton_mini_sdk_demo/src/io/ros_interface.cpp` | 创建 ROS publisher，读取 topic 参数，并发布图像、IMU 和 Odometry 消息。 |
| Baton Mini 架构文档 | `src/baton_mini_sdk_demo/baton_mini_architecture.md` | 说明 Baton Mini SDK Demo 的目录、数据流、端口、ROS2 参数和 topic。 |
| Baton Mini 运行指南 | `src/baton_mini_sdk_demo/batonmini运行指南.md` | 说明单台 Baton Mini 从网卡识别、IP 确认、构建到 topic 验证的手工流程。 |
| GoPro ROS2 launch | `src/gopro_camera_launch/launch/gopro_pose_record.launch.py` | 启动单个 `v4l2_camera_node`；支持指定 `video_device`、namespace、节点名、相机名、frame_id 和 topic 名称，用于分别启动左右 GoPro。 |
| GoPro V4L2 配置 | `src/gopro_camera_launch/config/gopro_camera.yaml` | 配置 GoPro 采集卡图像参数，例如分辨率、像素格式、输出编码和帧率配置项。 |
| GoPro 辅助脚本 | `src/gopro_camera_launch/start_capture_demo.sh` | 提供 GoPro 单节点构建、运行和验证命令入口，适合独立排查单路 GoPro。 |
| GoPro 架构文档 | `src/gopro_camera_launch/ARCHITECTURE.md` | 说明 GoPro 采集链路、launch 参数、发布 topic 和已移除功能。 |
| GoPro 运行指南 | `src/gopro_camera_launch/gopro节点运行操作指南.md` | 说明 GoPro 采集卡设备确认、帧率确认、节点启动和 topic 验证流程。 |
| GoPro 双节点说明 | `DOCS/阶段一：数据采集/场景一/GoPro两个节点运行说明.md` | 记录左右 GoPro 的 `/dev/videoX` 映射、启动命令、topic 验证命令和标定 warning 边界。 |

## 场景一目标输出 topic

| 节点 | 主要 topic | 功能 |
| --- | --- | --- |
| BatonMini right | `/baton_mini_right/imu`、`/baton_mini_right/fast_odom`、`/baton_mini_right/image_left`、`/baton_mini_right/image_right`、`/baton_mini_right/odometry` | 右侧 Baton Mini 的惯性、位姿和双目图像数据。 |
| BatonMini left | `/baton_mini_left/imu`、`/baton_mini_left/fast_odom`、`/baton_mini_left/image_left`、`/baton_mini_left/image_right`、`/baton_mini_left/odometry` | 左侧 Baton Mini 的惯性、位姿和双目图像数据。 |
| GoPro right | `/gopro_right/image_raw`、`/gopro_right/camera_info` | 右手 GoPro 图像和相机信息。 |
| GoPro left | `/gopro_left/image_raw`、`/gopro_left/camera_info` | 左手 GoPro 图像和相机信息。 |

## 使用边界

- 本场景的输出重点是“单节点逐个启动与 topic 验证”，不是一键批量启动。
- 4 个相机节点分别验证通过后，才进入场景二的一键启动整合。
- 如修改上述程序或配置，必须同步更新场景一执行记录或当前进度。
