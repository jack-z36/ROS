## 3. 必须人工核对的语义

- candidate Action 已解归一化；L2-04不得再次缩放。
- `previous_safe_action` 是命令连续性基准，observation 是实测基准；两者不可混称。
- 内部 quaternion 为 `xyzw`；RM65 `wxyz` 是 L2-05适配。
- 无 reference 必须 REJECTED，不得静默跳过。
- F100 `0~100` 是硬件输出语义，不能反推为 L2-04 输入域。
