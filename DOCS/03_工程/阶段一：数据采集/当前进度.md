# 阶段一：数据采集当前进度

## 当前状态

阶段一旧工程工作台已迁移到 `DOCS/03_工程/阶段一：数据采集` 目录下。

当前阶段一的主要工作已经覆盖：

- 逐个启动 GoPro/相机节点。
- 一键启动多个相机 ROS 节点。
- 一键启动 Baton Mini、GoPro 和触觉等传感器链路。
- 通过 Octopus 选择并录制目标 topic。
- 维护硬件枚举到稳定设备名和 topic 名的映射。

## 已完成的阶段性能力

- 已具备 `start_all_sensor.sh` 作为传感器总启动入口。
- 已具备 `start_octopus.sh` 作为 Octopus 独立启动入口。
- Octopus 录制链路已围绕目标 topic 做过配置和修复。
- 触觉、GoPro、Baton Mini 等数据源已有对应场景文档和输出清单。
- 原始采集结果以 MCAP 为核心产物，输出目录为 `mcap`。

## 仍需关注

- 采集时左右 GoPro FPS、Octopus UI 显示 FPS、写盘和压缩压力仍需要结合实机继续验证。
- USB 拓扑和串口 by-path 变化仍可能影响触觉设备稳定性。
- 阶段一只保证 raw MCAP 采集，不保证 raw MCAP 已经满足训练语义。
- 如果新增设备或 topic，必须同步更新对应场景文档、输出清单和后续阶段的 schema 设计。

## 下钻规则

本文件只描述阶段级进度。需要命令、日志、配置、topic 清单、故障处理细节时，应自动进入阶段一对应场景目录读取五个固定文档和 `输出程序与文件.md`。
