## 3. L2 Gate 场景覆盖

### S1：类型契约（TYPES-RESULT）

- **贡献 L3**: deploy_031, deploy_035
- **覆盖要点**:
  - `SafetyStatus` 三态：PASS / ADJUSTED / REJECTED
  - `SafetyCode`、`SafetyFinding`、`SafetyResult` 字段冻结
  - REJECTED 强制 `action is None`；PASS/ADJUSTED 强制 `action` 非 None
  - findings 为不可变 tuple；types 层无 config/service/runtime/ui 依赖
- **证据**: types 单测 23 PASS；verify `TYPES-RESULT` / `TYPES-RESULT-UNIT` PASS

### S2：配置契约（SafetyConfig / ActionDomain）

- **贡献 L3**: deploy_032, deploy_035
- **覆盖要点**:
  - 字段：`max_translation_step_m`、`max_rotation_step_rad`、`gripper_min/max`、
    `max_gripper_step`、`quaternion_norm_tolerance`（米/弧度/训练域夹爪/四元数容差）
  - 非法阈值拒绝；默认夹爪域 `0.0~1.0`，非 F100 `300~1000`
  - 旧 YAML 键破坏性拒绝，不静默映射
  - 无 joint limits / F100 寄存器映射；fallback 不进入 SafetyConfig
- **证据**: config 单测 41 PASS；verify `CONFIG-SAFETY` PASS

### S3：纯函数算法（C4 / C6–C15）

- **贡献 L3**: deploy_033, deploy_035
- **覆盖要点**:
  - INPUT-SHAPE / INPUT-FINITE / QUAT-CANDIDATE
  - REFERENCE-ORDER / BOOTSTRAP / MISSING（previous → observation → NO_REFERENCE）
  - POSE-TRANSLATION / POSE-ROTATION（欧氏/转角恰达阈值，非逐轴 clip）
  - GRIPPER-RANGE / GRIPPER-STEP（同域投影）
  - BIMANUAL-ASSEMBLY / OUTPUT-INVARIANT
- **证据**: primitives 40 PASS；verify 对应 service 标签 + `SERVICE-PRIMITIVES-FULL` PASS

### S4：编排入口（A1 / B1–B5）

- **贡献 L3**: deploy_034, deploy_035
- **覆盖要点**:
  - `SafetyGuard.filter_action(candidate, previous_safe_action=None, latest_observation=None) -> SafetyResult`
  - 三态正确：小步 PASS；可投影超限 ADJUSTED；契约/无基准 REJECTED 且 `action is None`
  - Guard 无跨 tick 业务状态（不记忆 previous / metrics）
  - 不实现 fallback / hold / safe-stop；不 import runtime/ui/ROS/hardware
  - 仅相对单一参考做投影，无 previous+observation 双重裁剪
- **证据**: guard+primitives 57 PASS；verify `RESULT-STATUS` / `SERVICE-GUARD-FULL` PASS
