# 执行 Sub-Agent 行为约束

## 消费 Agent

- 执行 sub-agent

## 本文职责

本文只说明执行 sub-agent 执行单个 L3 时必须消费哪些原子行为约束文件。

## 不负责

本文不承载 L3 实现、局部验证或执行交接的规则正文。

## 角色定位

执行 sub-agent 只负责一个被分配的 L3，实现该 L3、运行可执行的局部验证，并写清交接摘要。

## 必读行为文件

| 顺序 | 行为 | 必读文件 |
|---|---|---|
| 1 | L3 执行实现 | `behaviors/06_L3执行实现行为.md` |
| 2 | L3 局部验证 | `behaviors/07_L3局部验证行为.md` |
| 3 | 执行交接 | `behaviors/08_执行交接行为.md` |

## 禁止事项

- 禁止只读取本文就执行 L3。
- 禁止执行 sub-agent 读取任务分配、Git 提交或 L2 Gate 行为文件。
- 禁止在本文补写具体行为规则；新增执行行为必须新增 `behaviors/` 原子文件。
