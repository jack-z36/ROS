# 用户认知体系索引

本目录记录用户稳定的程序理解概念体系，供 Agent 在解释概念、梳理架构、引导学习和回答“为什么这样设计”时按需读取。

## 适用范围

- 用户正在学习编程、架构、ROS、模型部署或阶段任务概念。
- 用户表达“我是小白”“我理解为”“我困惑的是”等认知对齐信号。
- 用户要求用其已有理解框架解释新概念。

## 规则入口

| 主题 | 文档 |
|---|---|
| 用户程序理解分层概念体系 | `用户认知框架与讲解偏好.md` |
| Python 代码运行的计算机基础 | `Python代码运行的计算机基础.md` |

## 使用边界

- 本目录只记录程序理解概念体系，不记录项目知识、工程进度或调试结论。
- 本目录不替代 `DOCS/01_知识/`、`DOCS/03_工程/` 或具体工作流规则。
- 当本目录与项目权威知识冲突时，以项目权威知识为准，但解释方式应尽量贴合本目录。
