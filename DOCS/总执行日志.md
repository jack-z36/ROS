# 总执行日志

本文件记录 `.` 工作区中无法明确归入某个固定场景的零散执行事项。

当一次任务不明显属于某个阶段/场景，也不适合写入某个包的专用文档时，将执行记录写入本文件。

## 使用规则

- 每次记录必须追加到文件末尾，不覆盖已有记录。
- 记录应包含日期时间、用户请求、执行内容、涉及文件、观察结果和后续建议。
- 如果任务后来被确认属于某个场景，应在对应场景的执行记录中补充正式记录，并在本文件中保留这条零散记录作为线索。
- 仅记录跨场景、公共维护、文档体系、仓库管理、环境整理等零散事项；具体场景任务仍写入对应场景目录。
