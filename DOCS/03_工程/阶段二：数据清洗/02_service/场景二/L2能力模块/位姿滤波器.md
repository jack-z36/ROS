# L2 能力模块说明：位姿滤波器

## 1. 能力名称

```text
位姿滤波器
```

## 2. 所属位置

阶段：阶段二：数据清洗
L1：service_s2
场景：场景二：硬件数据可靠性验证
模块类别：数据计算类
来源功能模块清单：`DOCS/03_工程/阶段二：数据清洗/02_service/场景二/功能模块清单.md`

## 3. 一句话目标

```text
对数据补全器输出的 arm-base TCP pose 序列做可追溯平滑，降低高频噪声，同时保持 topic、时间戳、排序和样本数量不变。
```

## 4. 能力角色

本能力是场景二 P0 预处理链路中“数据补全器”和“MCAP_A 生成器”之间的 pose 平滑层。它只处理补全后的 [[ArmBaseTcpPose]] 序列，输出 [[PoseFilterResult]] 和滤波后 pose 序列引用，供 [[McapA|MCAP_A]] 生成器写入主数据 MCAP。

已按 `grill-me` 约束完成意图澄清：位姿滤波器首版只做补全后位姿平滑，不负责异常检测、补全、重采样或 MCAP 写出；默认使用 Savitzky-Golay；位置和姿态都纳入首版；不可补全或跳过样本作为分段边界；输出样本级审计。

## 5. 上游关系

- 直接上游是 [[数据补全器]]。
- 输入修复结果为 [[SignalRepairResult]]。
- 补全后 pose 序列通过 [[PoseFilterInputSequence]] 表达。
- pose 样本定位复用 [[SignalSampleRef]]。
- 无样本缺失区间复用 [[MissingIntervalIssue]]，滤波不得跨越。
- pose 相关 `unrepaired` / `skipped` 样本来自 [[SignalRepairRun]] 和 [[SignalRepairSampleRecord]]，必须作为分段边界。
- 原始 pose 语义来自场景一 [[ArmBaseTcpPose]]。

## 6. 下游关系

- [[McapA|MCAP_A]] 生成器消费滤波后 pose 序列和 [[PoseFilterResult]]。
- Parquet 标注与验证报告生成器消费 [[PoseFilterSampleRecord]]、[[PoseFilterSegmentSummary]] 和 guard 拒绝记录。
- IK 求解与 MCAP_B 生成器后续消费 MCAP_A 中的滤波后 pose。
- 开发者入口 `scene2_pose_filter` 展示滤波前后差异、分段摘要、guard 拒绝记录和运行日志。

## 8. 职责边界

本能力负责：

1. 将 [[SignalRepairResult]] 的 pose 输出解释为 [[PoseFilterInputSequence]]。
2. 基于 [[MissingIntervalIssue]] 和 pose 相关未修复样本切分连续可靠片段。
3. 对位置 `x/y/z` 做 Savitzky-Golay 平滑。
4. 对姿态四元数做符号连续化、旋转向量空间平滑和归一化输出。
5. 对超过 guard 阈值的候选滤波结果保留原值并写入样本级审计。
6. 输出 [[PoseFilterResult]]、[[PoseFilterSegmentSummary]] 和 [[PoseFilterSampleRecord]]。

本能力不负责：

1. 不重新做异常检测。
2. 不补全、插入、删除或重采样消息。
3. 不修改 topic 名称、时间戳结构、排序或样本数量。
4. 不处理触觉或夹爪滤波。
5. 不写 [[McapA|MCAP_A]]。
6. 不执行 IK、关节限制或 MuJoCo 仿真。
7. 不决定最终 episode 丢弃或训练 mask。

## 9. 计算职责

| 计算项 | 输入 | 输出 | 影响下游 |
|---|---|---|---|
| 输入语义对齐 | [[SignalRepairResult]]、[[PoseFilterInputSequence]] | 可滤波 pose topic 序列 | 避免直接猜测补全 artifact 格式 |
| 分段边界构建 | [[MissingIntervalIssue]]、pose `unrepaired` / `skipped` 样本 | 连续可靠片段 | 防止滤波跨坏段扩散 |
| 时间窗口换算 | [[PoseFilterConfig]]、片段时间戳 | 奇数样本窗口 | 决定 Savitzky-Golay 实际窗口 |
| 短片段处理 | 片段样本数、`polyorder` | 自适应窗口或原样保留 | 保持边界行为可解释 |
| 位置滤波 | 片段内 `x/y/z` | 候选滤波位置 | 降低高频噪声 |
| 姿态滤波 | 片段内四元数 | 候选滤波姿态 | 降低姿态抖动并保证归一化 |
| guard 检查 | 原始 pose、候选滤波 pose | 最终 pose 与拒绝记录 | 防止过度平滑 |
| 结果聚合 | 样本记录、片段摘要、序列引用 | [[PoseFilterResult]] | MCAP_A 和报告生成器消费 |

## 10. 计算规则

| 规则 | 触发条件 | 计算 / 判断方式 | 结果表达 |
|---|---|---|---|
| 只消费补全后 pose | [[SignalRepairResult]] 已存在 | 通过 [[PoseFilterInputSequence]] 读取补全后 pose 序列 | 输入接口记录 |
| 保持时间结构 | 任意输入 topic | 不新增、不删除、不重采样、不改时间戳 | `timestamp_policy=preserve_original` |
| 缺失区间分段 | 出现 [[MissingIntervalIssue]] | 缺失区间两侧分别滤波 | [[PoseFilterSegmentSummary]] |
| 未修复样本分段 | pose 相关 `unrepaired` / `skipped` | 该样本不进入滤波窗口，左右两侧分段 | `status=skipped_boundary` |
| 时间窗口换算 | 连续可靠片段长度足够 | 用片段时间戳中位 `dt` 将 `window_duration_ms` 换算为最近奇数样本窗口 | `actual_window_size_samples` |
| 短片段策略 | 样本数小于默认窗口 | 缩小到可用最大奇数窗口；仍不满足 `polyorder` 时原样保留 | `kept_original_short_segment` |
| 位置滤波 | 片段可滤波 | 对 `x/y/z` 分量执行 Savitzky-Golay | 候选滤波位置 |
| 姿态滤波 | 片段可滤波 | 四元数符号连续化，转旋转向量空间平滑，再转回单位四元数 | 候选滤波姿态 |
| guard 拒绝 | 位置差大于 `0.02m` 或姿态差大于 `5deg` | 保留原始 pose，不采用候选滤波值 | `filter_rejected_by_guard` |
| 样本级审计 | 每个 pose 样本 | 记录原值、候选值、最终值、差异和 reason | [[PoseFilterSampleRecord]] |

## 11. 输出结果结构

| 字段 | 类型 | 含义 | 有效性要求 | 下游使用方式 |
|---|---|---|---|---|
| `input_repair_result_ref` | [[SignalRepairResult]] | 来源补全结果引用 | 必须可追溯 | 报告和复现 |
| `pose_filter_config_ref` | [[PoseFilterConfig]] | 本次滤波配置引用 | 必须可追溯 | 调参和复现 |
| `input_sequence_refs` | list[[PoseFilterInputSequence]] | 输入 pose 序列引用 | 与补全结果对齐 | 复现输入 |
| `output_sequence_refs` | object/list | 滤波后 pose 序列引用 | 不塞完整 MCAP | MCAP_A 生成器 |
| `segment_summaries` | list[[PoseFilterSegmentSummary]] | 分段和窗口摘要 | 覆盖所有连续可靠片段 | 调试和报告 |
| `sample_records` | list[[PoseFilterSampleRecord]] | 样本级审计 | 覆盖每个处理样本 | 审计和报告 |
| `timestamp_policy` | enum string | 固定 `preserve_original` | 必填 | 验收不重采样 |
| `sample_count_before` / `sample_count_after` | object | 各 pose topic 样本数 | 必须相等 | 验收长度不变 |
| `summary_by_topic` | object | 按 topic 汇总 filtered/kept/rejected/skipped | 必须区分 guard 拒绝 | 开发者入口摘要 |

## 12. 异常与边界输入

| 边界情况 | 预期结果 | reason / error 表达 | 是否阻塞下游 |
|---|---|---|---|
| 缺少 [[SignalRepairResult]] | 功能检验失败 | `missing_signal_repair_result` | 是 |
| `timestamp_policy` 不是 `preserve_original` | 功能检验失败 | `unsupported_timestamp_policy` | 是 |
| `output_sequence_refs` 无法映射为 [[PoseFilterInputSequence]] | 功能检验失败 | `invalid_pose_filter_input_sequence` | 是 |
| 片段时间戳重复或倒退 | 当前片段原样保留并记录 | `invalid_segment_time_order` | 否，进入报告 |
| 片段过短 | 当前片段原样保留 | `short_segment_kept_original` | 否 |
| 四元数非法 | 当前样本作为边界跳过或功能检验失败 | `invalid_orientation` | 取决于上游是否已标记 |
| guard 超阈 | 当前样本保留原值 | `filter_rejected_by_guard` | 否 |

## 13. 可验证样例

| 样例 | 输入特征 | 预期输出 | 验证方式 |
|---|---|---|---|
| 合法输入 | 连续 pose 序列，无缺失和未修复样本 | 生成滤波后序列，样本数和时间戳不变 | 单元测试 |
| 缺失区间 | 中间存在 [[MissingIntervalIssue]] | 左右分段独立滤波，不跨段 | 分段测试 |
| 未修复样本 | 某 pose 样本 `unrepaired` 或 `skipped` | 该样本作为边界，左右分段 | 上游接口兼容测试 |
| 短片段 | 片段样本数小于默认窗口 | 自适应窗口或原样保留 | 窗口换算测试 |
| 姿态抖动 | 四元数符号可能翻转 | 输出连续且归一化四元数 | 姿态滤波测试 |
| guard 超阈 | 候选滤波值偏移过大 | 保留原值并写 `filter_rejected_by_guard` | guard 测试 |

## 18. 给 L3 任务生成的约束

1. 每个 L3 只能解决一个核心目标。
2. 位姿滤波器 L3 不得重新做异常检测。
3. 位姿滤波器 L3 不得补全、插入、删除或重采样消息。
4. 滤波不得跨越 [[MissingIntervalIssue]]。
5. pose 相关 `unrepaired` / `skipped` 样本必须作为分段边界。
6. 姿态滤波必须做四元数符号连续化，并在旋转向量空间平滑后转回单位四元数。
7. guard 超阈时必须保留原值，并输出 [[PoseFilterSampleRecord]]。
8. 每个 Service 场景 L3 必须写明它对应或影响 `./start_data_clean.sh --dev` 下的场景二功能检验项或场景完整 smoke test。
9. L3 自动化验收只证明局部实现正确；场景最终验收必须由用户本人运行 `./start_data_clean.sh --dev` 后确认。
