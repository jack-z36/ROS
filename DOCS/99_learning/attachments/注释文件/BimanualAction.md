# BimanualAction

> [!abstract] 核心定义
> 单步双臂双手动作的结构化表示，把 14D 动作拆成左臂、右臂、左手、右手。

## 数据结构

| 字段名 | 类型 | 含义 | 是否必填 |
|--------|------|------|----------|
| `left_arm` | np.ndarray(6,) | 左臂 6 个目标关节角 | 是 |
| `right_arm` | np.ndarray(6,) | 右臂 6 个目标关节角 | 是 |
| `left_hand` | float | 左手/夹爪命令 | 是 |
| `right_hand` | float | 右手/夹爪命令 | 是 |

> [!info] 结构说明
> `BimanualAction.as_vector()` 可将四个语义字段重新拼回 14D 向量。

> [!tip] 生活场景类比
> 像把长购物小票分装到四个袋子：左臂袋、右臂袋、左手袋、右手袋。
