# L2-06 功能微元总览与组织结构

本文件是 L2-06 A/B/C 编号、父子关系和运行时调用树的唯一权威。实现、L3、验证与 HTML 蓝图引用编号前必须先读本文件。

## 编号与总量

| 层 | 总量 | 编号 | 责任 |
|---|---:|---|---|
| A（3.25 class） | 2 | A1-A2 | 跨 tick 状态与 ROS 生命周期打包 |
| B（3.375 编排） | 3 | B1-B3 | tick、fallback、timer 编排 |
| C（3.5 原子） | 5 | C1-C5 | 数据、计算、状态更新和边界读写 |

| 编号 | 名称 | 类型 | 父级 | 责任 |
|---|---|---|---|---|
| A1 | ControlLoop | class | — | 持有 active chunk、cursor、request 与 metrics |
| A2 | ActDeployNode | class | — | 持有 ROS timer 与 status 发布句柄 |
| B1 | tick | 编排函数 | A1 | 收结果、请求、直取、安全、发布、计数 |
| B2 | _emit_fallback | 编排函数 | A1 | 把失败 reason 交给 L2-05 并记录状态 |
| B3 | _control_tick | 编排函数 | A2 | ROS timer 调用 A1.tick |
| C1 | 调度状态 | 数据 | A1 | active_chunk、cursor、request_pending、metrics |
| C2 | validate_chunk_for_cursor | 计算函数 | A1 | chunk 与 cursor 合法性纯 RAM 判断 |
| C3 | _collect_latest_chunk | 内部状态更新函数 | A1 | 以 latest-only 结果替换 active chunk |
| C4 | _take_cursor_action | 内部状态更新函数 | A1 | 读取当前 16D action 并递增 cursor |
| C5 | _publish_status_metrics | 数据读写函数 | A2 | 将 runtime snapshot 写到 ROS status/metrics |

## 运行时调用树

```text
ActDeployNode._control_tick (B3)
└─ ControlLoop.tick (B1)
   ├─ _collect_latest_chunk (C3)
   ├─ validate_chunk_for_cursor (C2)
   ├─ _take_cursor_action (C4)
   ├─ SafetyGuard.filter_action（L2-04 复用，不新编号）
   ├─ L2-05 publisher port（复用，不新编号）
   └─ _emit_fallback (B2)
ActDeployNode._publish_status_metrics (C5)
└─ 读取 RuntimeMetrics（L2-06 汇总状态）
```

## 上游复用对象（不新编号）

- L2-01：`DeployConfig`、`ActionSpec`。
- L2-02：`ObservationSnapshot`、`latest_observation`。
- L2-03：`InferenceRequest`、`ActionChunk`、request/result latest-only queue。
- L2-04：`SafetyGuard`、`SafetyResult`。
- L2-05：安全动作与 fallback 的发布接口。
