# Runtime MVP 功能模块清单

## L1 任务定位

`runtime_mvp` 是阶段二数据清洗 pipeline 的最小运行控制框架。它不实现真实清洗、验证、对齐、dataset 构建或导出算法，而是先把配置读取、输入预检查、run 目录、场景调度、fake service、结构化日志、manifest、错误摘要和 smoke test 串成可运行闭环。

Runtime MVP 的目标是让阶段二后续五个 Service 场景能够接入统一运行骨架，而不是让每个场景各自实现入口、日志、错误处理和目录管理。

## 功能模块总数

本 L1 拆分为 10 个 L2 功能模块。

## 模块清单

| 编号 | 功能模块 | 核心目标 | 上游依赖 | 下游消费者 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| 1 | Runtime 运行上下文定义 | 定义一次 Runtime 运行需要携带、记录和交付的最小上下文。 | 阶段二运行入口、场景选择、配置路径、输入路径。 | Run 目录管理、配置快照、调度、日志、manifest、错误摘要。 | P0 |
| 2 | Run 目录管理模块 | 为每次运行创建独立目录，隔离调试产物、运行日志和正式数据产物。 | Runtime 运行上下文、文件存放规范。 | 配置快照、run log、manifest、error summary、fake service 输出。 | P0 |
| 3 | 配置加载与配置快照模块 | 读取本次运行配置，并把实际生效配置保存到 run 目录。 | 配置文件、临时覆盖参数、run 目录。 | 配置预检查、Service 调度、日志、manifest。 | P0 |
| 4 | 配置预检查模块 | 在执行前检查全局配置和场景配置是否完整、合法、可追溯。 | 配置加载结果、场景选择。 | 输入产物预检查、调度、错误摘要。 | P0 |
| 5 | 输入产物预检查模块 | 检查当前场景依赖的上游产物是否存在、可读且符合最小边界。 | 场景选择、配置预检查结果、阶段二产物契约。 | Service 调度、错误摘要、run log。 | P0 |
| 6 | 场景注册与 Service 调度模块 | 根据用户选择找到对应场景 service，并统一调用单场景或全流程。 | 运行上下文、预检查结果、Service 注册表。 | fake service、真实 service、日志、manifest。 | P0 |
| 7 | Fake Service 模块 | 在真实 service 未完成前，用假服务跑通 Runtime 空流程。 | 调度模块、run 目录、输入产物预检查结果。 | Runtime smoke test、日志、manifest。 | P0 |
| 8 | 结构化日志模块 | 记录输入、配置、执行步骤、输出、耗时、状态和错误。 | 运行上下文、调度事件、Service 返回结果。 | 人工排错、error summary、后续任务验收。 | P0 |
| 9 | Manifest 与错误摘要模块 | 成功时写 processing manifest，失败时写 error summary。 | 运行上下文、配置快照、日志事件、Service 结果。 | 追溯、失败定位、后续数据产物解释。 | P0 |
| 10 | Runtime smoke test 模块 | 验证单场景 fake run、fake 全流程、缺配置、缺输入和失败摘要。 | 前 1-9 个模块。 | Runtime MVP 验收、后续真实 Service 接入。 | P0 |

## 模块关系

```text
1. Runtime 运行上下文定义
   -> 2. Run 目录管理
   -> 3. 配置加载与配置快照
   -> 4. 配置预检查
   -> 5. 输入产物预检查
   -> 6. 场景注册与 Service 调度
   -> 7. Fake Service
   -> 8. 结构化日志
   -> 9. Manifest 与错误摘要
   -> 10. Runtime smoke test
```

更准确地说：

- 1-6 是 Runtime 主干能力。
- 7 是替身业务能力，用来解除真实 Service 尚未完成的阻塞。
- 8-9 是运行追溯能力。
- 10 是 Runtime MVP 的最小验收能力。

## 总体验收标准

- 能通过阶段二开发者入口进入 Runtime MVP 运行路径。
- 能选择单场景或 fake 全流程。
- 能创建独立 run 目录。
- 能读取配置并保存配置快照。
- 能检查配置缺失。
- 能检查输入产物缺失。
- 能调用 fake service。
- 能生成 `run_log.json`。
- 能生成 `processing_manifest.json`。
- 失败时能生成 `error_summary.json`。
- fake 全流程 smoke test 通过。
