# Git 协作约束索引

## 规则入口

- `Git操作规则.md`：全局 Git 底线规则、三层分支模型、阶段规则路由和**工作树（Worktree）** 规范。
- `阶段二：数据清洗 Git操作规则.md`：阶段二 `data_clean` 二级长期分支与三级功能分支规则。
- `阶段四：模型部署 Git操作规则.md`：阶段四 `model_deploy` 二级长期分支、三级功能分支规则和**多 Agent 并行工作树**约定。

## 当前长期分支

| 层级 | 分支 | 用途 |
|---|---|---|
| 一级 | `main` | 稳定里程碑主干。 |
| 二级 | `data_collection` | 数据采集长期集成分支。 |
| 二级 | `data_clean` | 数据清洗长期集成分支。 |
| 二级 | `model_deploy` | 模型部署长期集成分支。 |
| 二级 | `docs_maintaining` | 文档体系长期维护分支。 |

三级功能分支必须从对应二级分支创建，合入后二级分支后删除。

## 读取条件

只有任务涉及 Git 状态、提交、推送、拉取、远端、分支、合并或同步时读取本主题。

如果任务属于明确阶段，读取 `Git操作规则.md` 后，必须继续读取对应阶段专属 Git 规则。

## 禁止事项

- 禁止从历史执行日志推断当前 Git 规则。
- 禁止未读取 `Git操作规则.md` 就执行 Git 写操作。
- 禁止删除 `main`、`data_collection`、`data_clean`、`model_deploy`、`docs_maintaining`。
