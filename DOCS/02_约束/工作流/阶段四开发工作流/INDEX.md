# 阶段四开发工作流索引

本目录收纳阶段四模型部署程序改造相关工作流。阶段四是在同事已有部署程序基础上做契约化改造，不使用阶段二从零开发范式。

## 工作流入口

| 任务 | 必读文件 |
|---|---|
| 规划或执行阶段四模型部署程序改造 | `阶段四模型部署程序改造工作流.md` |
| 生成阶段四 L3 微元改造任务 | `attachments/L3微元改造任务模板.md` |

## 核心边界

- 阶段四 L1 / L2 / L3 只表示任务层级。
- 阶段四 L2 是改造工作包，不是阶段二功能模块说明。
- 阶段四 L3 是已有代码上的最小改造任务，不是从零实现任务。
- 阶段四默认从 AS-IS Contract、TO-BE Contract 和 Contract Delta 推导任务。

## 禁止默认套用

- `阶段二开发工作流/阶段二开发范式.md`
- 阶段二 L2 能力模块模板
- 阶段二 L3 微元任务模板正文
- 阶段二功能模块清单机制

阶段二 L3 模板只能作为结构参考；阶段四正式 L3 必须使用 `attachments/L3微元改造任务模板.md`。
