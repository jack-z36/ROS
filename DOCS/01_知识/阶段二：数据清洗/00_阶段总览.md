# 阶段二：数据清洗总览

阶段二负责把阶段一/Octopus 录制得到的 raw MCAP，从多 topic 原始日志整理为后续训练可以稳定消费的数据形态。

阶段二当前应理解为两层：

- Runtime：入口、配置、run 目录、日志、manifest、开发者检查和场景调度。
- Service：具体数据处理能力，例如夹爪提取、位姿转换、可靠性检测、字段对齐和训练格式桥接。

## 阶段边界

阶段二不只是另存 MCAP。它要把 topic 世界逐步转成 step 级 observation/action 语义，并保留报告、manifest、sidecar 和可复现导出能力。

具体工程进度、L2/L3、dispatch 和 debug 记录位于 `DOCS/03_工程/阶段二：数据清洗/`。
