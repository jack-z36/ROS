# ui 层设计：L2-03

## 1. 本 L2 不在该层新增源码产物

原因：

- `ui/` 层负责外部交互边界，例如 ROS node、subscriber、publisher、message converter。
- L2-03 是后台计算角色，只消费 RAM 内的 `InferenceRequest`、产出 RAM 内的 `ActionChunk`，**不直接与外部世界交换数据**。
- 订阅 observation topic 属 L2-02；发布 `/act/policy_action` 或 `/act/command/*` 属 L2-05；启动 ROS node 与 timer 属 L2-06。
- L2-03 的 `InferenceWorker` 是普通 `threading.Thread`，不是 ROS node。

## 2. 本 L2 与 ui 层的边界

L2-03 通过 RAM 队列与 L2-06（runtime/ui 层）协作，不跨越 ROS topic 边界：

```text
L2-06 (ui: ROS node / timer)
  -> ControlLoop.tick() 提交 InferenceRequest 到 inference_request_queue
L2-03 (runtime: InferenceWorker 后台线程)
  -> 消费 request -> 推理 -> 写 ActionChunk 到 chunk_result_queue
L2-06 (ui)
  <- 收集 chunk -> 直取 raw action -> 调 L2-05 发布
```

本 L2 不创建任何 publisher / subscriber / ROS node / launch 入口。

## 3. 与去除平滑处理的关系

本 L2 不定义任何 `/act/smoothed_action`、`/act/blended_action` 或 RTC 平滑相关 topic。第一版输出路径只围绕 L2-06 直取 raw action 和 L2-05 发布 safe single action / command topic。

## 4. 验收如何确认

- L2-03 不产生 `src/model_deploy/act/ui/*.py` 或 launch 产物。
- `rg` 检查 L2-03 范围内无 `import rospy` / `rclpy` / publisher / subscriber（ROS 交互归 L2-02/L2-05/L2-06）。

## 5. 边界继承声明

本文件边界来自当前 L1/L2 功能边界，不来自旧 layer-based L2 卡片。
