# 阶段二场景五：模型训练格式导出器

## 一句话总结

从 canonical dataset 导出目标模型训练格式，完成阶段二到阶段三模型训练的交接。

## 核心目标

本场景负责阶段二的最后一步：证明 canonical dataset 可以稳定派生为训练程序可消费的数据格式。

本场景只做格式适配，不回头修复 raw、cleaned、validated、aligned 或 canonical dataset 中的问题。

## 软件能力产出

本场景应形成以下中粒度软件能力：

- 导出入口：用户可以选择目标训练格式并发起导出。
- canonical dataset 读取能力：读取 schema、dataset index、episode、step index 和 masks。
- 样本过滤能力：根据 masks 排除不可训练 step。
- 格式适配能力：把 canonical observation/action 映射为目标训练框架需要的字段、shape、dtype 和目录结构。
- 多格式扩展能力：支持在确定模型后增加新的导出格式。
- 导出校验能力：确认导出数据能被目标训练代码或最小读取脚本加载。
- 导出报告能力：记录样本数量、过滤数量、字段映射和失败原因。

具体脚本名、模块名、配置名和代码结构在实现时决定，不在本目标描述中提前固定。

## 自动化处理目标

用户运行本场景入口后，理想情况下应自动完成：

1. 读取 canonical dataset。
2. 按 masks 过滤不可训练 step。
3. 定位 observation 和 action。
4. 转换为目标训练格式。
5. 写出训练数据。
6. 生成导出报告。
7. 执行导出校验。

## 数据输出

| 输出 | 用途 |
| --- | --- |
| 目标训练格式数据 | 阶段三模型训练输入。 |
| 导出报告 | 记录导出统计、字段映射和过滤原因。 |
| 导出校验结果 | 证明训练程序或读取脚本可以加载数据。 |

## 成功标准

- exporter 只依赖 canonical dataset。
- 不可训练 step 不进入训练集。
- 导出结果记录来源 episode、schema version 和过滤统计。
- 删除 `exports/` 后可由 canonical dataset 重新生成。
- 导出结果可被目标训练流程读取。
