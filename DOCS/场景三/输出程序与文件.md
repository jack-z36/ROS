## 使用边界

- 本场景的验收重点是 8 个目标 topic 都能被 Octopus 录入 MCAP，且 `ros2 bag info` 可确认消息存在。
- UI 展示布局、实时 FPS、位姿曲线和触觉热力图属于场景四。
- 硬件身份稳定映射属于场景五。
- MCAP 后处理和清洗属于场景六。
