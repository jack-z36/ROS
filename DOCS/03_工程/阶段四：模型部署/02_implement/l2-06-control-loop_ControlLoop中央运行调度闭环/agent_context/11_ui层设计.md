# ui 层设计：L2-06

## 目标源码

`src/model_deploy/act/ui/act_deploy_node.py`（若 L3 选择既有 node 文件，保持同等 UI 边界）。

层职责：ROS 外部交互。`ActDeployNode` 在启动期装配既有 L2 对象，创建 `1/control_hz` timer；`_control_tick()` 只调用 `control_loop.tick()`，status/metrics timer 将 runtime snapshot 转成 ROS 消息。它不实现 chunk 选择、安全计算或模型推理。

class 设计：Node 已拥有 ROS handles、timer 生命周期和 publisher，适合封装。函数设计：`_control_tick()` 是数据读写函数（timer/ROS 边界）；`_publish_status_metrics()` 是数据读写函数。输入：ROS timer、runtime snapshot；输出：ROS status/metrics；副作用：创建 timer、发布 topic。

依赖方向：UI 可依赖 runtime/service/config/types；runtime 不可 import UI。Pi0.5 参考：`pi05_vla_deploy_node.py:42-89,196-218`。验收覆盖：dry-run 不调用硬件、timer 调用 tick、status 可观测；未知具体 topic/driver 为 shadow-run BLOCKED。

本文件任务边界继承当前 L1/L2 功能边界，不来自旧 layer-based L2 卡片。
