## 通过现象

- `ACTION_DIM == 16`，第一版不含触觉时 `STATE_DIM == 16`。
- `split_bimanual_action(...).as_vector()` 能还原构造的 16D action。
- state 编码输出维度为 16D，段序与文档一致。
- 错误维度和非法数值会导致明确失败，不会进入下游运行链路。
- 验收过程中没有启动 ROS 节点，也没有触发 dry-run、shadow-run、real-policy 或 real-robot。

## 失败现象与排查入口

- 维度仍为 14D 或 26D：优先检查 `action_spec.py` 和 `state_codec.py` 常量。
- round-trip 不一致：优先检查 split/as_vector 的段序。
- 非法 shape 未报错：优先检查 `action_codec.py` 和 state/action codec 的输入校验。
- 测试导入失败：优先检查包路径、测试路径和新增测试文件落点。
