# ui 层设计：L2-03

## 1. 本 L2 不在该层新增源码产物

`ui/` 是 ROS message、node、subscriber、publisher 和外部适配边界。L2-03 不跨越进程外 I/O，因此不新增 ui 文件。

## 2. 外部接口分工

| 外部交互 | 所有者 | L2-03 的关系 |
|---|---|---|
| observation ROS message 订阅、解码和时间记录 | L2-06 | 不读取 message，只接受 L2-02 产生的 snapshot |
| observation 业务缓存、图像预处理、snapshot 组装 | L2-02 | 消费最终 snapshot，不再处理像素 |
| policy/status/metrics ROS publish | L2-05/L2-06 | 不构造 message、不 publish |
| arm/gripper command publish | L2-05 | 不接触 command topic 或硬件 SDK |

## 3. L2-03 与外部世界的唯一间接关系

```text
ROS observation
-> L2-06 decode
-> L2-02 ObservationSnapshot
-> L2-06 调用 L2-03
-> ActionChunk
-> L2-06 选择单步
-> L2-04 safety
-> L2-05 ROS publish
```

L2-03 的 batch、raw tensor 和 service class 都是 Python 进程内对象，不能被表述为 ROS message、topic 或 node。

## 4. 禁止内容

```text
rclpy/rospy import
Node, subscriber, publisher, timer
Image/CompressedImage/Pose/Point message decode
/act/observation/* topic 名消费
/act/policy_action 或 /act/command/* publish
RM65 SDK、Modbus、USB/serial 调用
```

## 5. 验收

- L2-03 不新增 `src/model_deploy/act/ui/*.py` 或 launch 产物。
- 静态扫描 types/service 不含 ROS/hardware import 和 publish/subscribe 调用。
- 人工数据流审查确认 ActionChunk 先到 L2-06，未绕过 L2-04/L2-05。

## 6. 边界声明

GPU inference tensor 计算不等于 ROS/硬件 I/O。L2-03 既不向机器人发送命令，也不接收 ROS 消息。
