# 路由文档纯度规范

## 适用范围

- 阶段：全局
- 任务模式：修改根 `AGENTS.md`、设计上下文加载入口
- 适用对象：所有承担路由职责的文档
- 不适用对象：知识索引、工程目录索引、约束主题 `INDEX.md`

## 强制规则

路由文档只回答一个问题：某类任务开始前应该读取哪个加载规则入口。

路由文档允许包含：

- 任务类型名称
- 一句话触发说明
- 加载规则路径
- 默认禁止读取区

路由文档不得包含：

- 项目主链路、业务背景或当前能力说明
- 代码模块列表、实现细节或运行命令
- 规则正文
- 当前进度、执行记录或 debug 结论
- 历史方案解释

## 禁止事项

- 禁止在 `AGENTS.md` 中复制约束文件全文。
- 禁止在 `AGENTS.md` 中维护阶段二主链路、网页行为或 L3 细节。
- 禁止在 `DOCS/` 子目录新增局部 `AGENTS.md`。

## 维护规则

根 `AGENTS.md` 只允许指向 `DOCS/02_约束/上下文加载/` 下的加载规则文件。详细流程必须在加载规则文件中维护。
