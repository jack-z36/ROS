## 当前需要修正的阶段理解

阶段二不应只理解为“输出一个清洗后 MCAP”。更准确的目标是形成 `canonical_dataset_mcap`。

也就是说，核心时间序列仍可保留在每个 episode 的 `data.mcap` 中，但必须用 dataset 级 schema、episode 级 `step_index.parquet`、`masks.parquet`、report 和 manifest 解释训练语义。

已补充 canonical dataset 的完整定义：它现在被明确为 raw MCAP 和训练格式之间的标准数据契约，包含数据本体层、语义契约层、step 映射层、质量与追溯层，以及 dataset/episode/schema/step/mask/report/manifest 的不变量。

最终目录结构已按用户确认版本固定：`schema/` 只包含 observation、action、frame、topic、quality 五个 schema；episode 内必须包含 `robot_constraint_report.json`。
