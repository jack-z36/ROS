说明

在编程区域，点击左上角的说明按钮，可呈现 `30s上手流程图编程` 简要描述，用户可根据提示快速上手进行流程图编程。

下面将按照上表的顺序，依次对各区域/按键进行说明：

## 单步按钮

在线编程数据可单步运行。点击 `单步` 按钮， `单步` 、 `低速` 和 `运行` 按钮分别变为 `下一步` 、 `暂停` 和 `停止` 按钮。单步模式下，程序逐条执行，只有在完成一段轨迹后，点击 `下一步` 按钮才能下发下一段轨迹命令。

![程序单步运行](https://develop.realman-robotics.com/realman/docs/attachments/multimedia/zh/robot4th/quickUseManual/teachingPendantfour/onlineCode/image-1.png)

## 低速按钮

当在线编程工程建立完成后，点击 `低速` ， `单步` 、 `低速` 和 `运行` 按钮分别变为 `暂停` 和 `停止` 按钮。轨迹自动运行过程中，当前运动编程点的背景颜色变为亮色。

在机器人运动过程中点击 `暂停` 按钮，机器人将立即停止运动， `暂停` 和 `停止` 按钮分别变为 `停止` 和 `继续` 按钮，当再次点击 `继续` 时，机器人将继续移动。

#### 步进模式设置

为了能够增加示教的精度，需要用到步进控制这个模式，能够让被控制的变量以步进的方式精确变化。

1. 首先点击 `步进模式` 右侧的开关开启步进模式，进入步进控制方式。
2. 用户可以通过修改步长数值来调整机器人运动相应的步长。
	- **位置** ：表示在位置控制区，点击一次某个方向按钮，末端在相应方向平移的距离，单位为毫米（移动的过程中不得松开该按钮，松开后将中途停止）。
		- **姿态** ：表示在姿态控制区，末端姿态运动的角度，单位可选为弧度（rad）或者度（°）。
		- **关节** ：表示在关节控制区，控制相应关节运动的角度，单位为度（°）。

说明

步进控制只对末端控制及关节轴控制有效。

![步进模式示意图](https://develop.realman-robotics.com/realman/docs/attachments/multimedia/zh/robot4th/quickUseManual/teachingPendantfour/onlineCode/image-33.png)

### 编辑模式

1. 通过修改关节角度或者拖动3D仿真区域中红色虚拟模型各关节可大体调节机械臂各关节角度。
2. 通过 `+` 和 `-` 按钮可微调关节角度以及位置姿态。调整后的机械臂位置姿态由红色虚拟模型表示。

### 拖动模式

#### 示教器拖动示教

除了通过机器人示教界面记录点位，运行轨迹之外，机器人还支持拖动示教功能。

**拖动示教设置包括** ：

- **电流环拖动示教** ：开启电流环模式后，可拖动机械臂的任意位置来改变机械臂的姿态，支持设置灵敏度数值，数值越高，机械臂拖动越容易；数值越低，机械臂拖动越困难。
- **六维力拖动示教** ：仅六维力版本的机械臂提供此拖动模式，可根据需要选择参考坐标系，并支持自定义、只动位置、只动姿态、位姿结合等拖动方式。用户也可自由组合六维力版本机械臂的拖动状态。
	- **参考坐标系** ：可根据需要选择工作坐标系和工具坐标系。
		- **拖动方式** ：只动位置，允许机械臂通过所有轴移动，无法旋转；只动姿态，允许机械臂在所有轴上以球面运动方式绕TCP（末端中心点）移动；位姿结合，允许通过所有轴移动，所有轴都是自由的。

在机械臂末端法兰外壳上有两个按钮，分别控制机器人进行拖动示教和轨迹复现。

### 设置初始姿态

机器人可设置初始姿态，方便用户控制机器人快速到达该位姿。

当前示教器支持在示教模式或编辑模式下设置机械臂初始姿态。

- **示教模式** ：进入示教模式后，参照 [示教模式](#352414) 修改关节和位姿参数后，点击 `设置初始` ，完成初始姿态设置。
- **编辑模式** ：进入编辑模式后，参照 [编辑模式](#352415) 修改关节和位姿参数后，点击 `设置初始` ，完成初始姿态设置。

### 模块

模块为图形化编程的基础指令单元，包含基础、运动、控制、IO、Modbus、生态和轨迹七个类别。  
双击添加的模块，可在设置页签设置目标模块的参数。

#### 节点功能概述

| 节点 | 功能描述 |
| --- | --- |
| 运动 | 运动模块提供关节运动（MoveJ/MoveJ\_P）、直线运动（MoveL）、圆弧运动（MoveC）及曲线运动（MoveS）等多种指令类型，可配置路点、速度与过渡参数，以规划机械臂的各类运动轨迹。 |
| 偏移 | 偏移模块控制机械臂的末端，基于指定的工具或用户坐标系，沿X、Y、Z轴方向进行精确的直线偏移。可设定各轴的偏移量、移动速度与交融半径，并选择是否阻塞后续指令以确保运动完成。 |
| 等待 | 等待模块用于在流程中创建一个可配置的暂停，可以手动输入时间或选择变量来设定等待时长，程序将在此阻塞直至时间结束再执行后续指令。 |
| 等待 IO | 等待 IO 模块使程序暂停，等待指定的数字输入信号达到预设的电平状态。 |
| 等待 Modbus | 等待 Modbus 模块使程序暂停，等待通过指定的Modbus连接（如TCP、RTU或机械臂从站）读取到的设备寄存器数据，满足预设的条件。可配置协议类型、设备地址、寄存器地址及预期数据，程序将在此阻塞直至条件满足。 |
| 判断 | 判断模块根据设置的条件表达式进行逻辑判断，以控制程序流程的分支走向。可配置操作数、比较运算符（如等于、大于）和判断值，操作数与判断值均支持手动输入或变量绑定，从而实现动态条件判断。 |
| 计算 | 计算模块用于执行数学运算，计算由常量/变量及运算符组成的表达式，并将结果保存到目标变量中，供后续指令调用，实现程序中的动态数值计算与传递。 |
| 弹窗 | 弹窗该模块用于在程序运行时弹出提示窗口，显示自定义的标题与备注信息。此操作为阻塞模式，程序将暂停执行直至用户确认关闭，从而实现关键信息的即时通知与流程控制。 |
| 读取 IO | 读取 IO 模块用于实时读取指定数字输入端口（如DIN1）的当前电平状态（高/低），并将此状态值存储到指定的变量中，以供后续逻辑判断或数据处理使用。 |
| 设置 IO | 该模块用于控制指定数字输出端口（如DOUT1）的电平状态，可将其设置为高电平或低电平，从而直接驱动外部设备的通断。 |
| 读取 Modbus | 读取 Modbus 模块通过指定的Modbus连接（TCP、RTU或机械臂从站）从设备寄存器中读取数据，可配置设备地址、寄存器地址（支持变量）和读取长度，并将读取结果存储到指定变量中，用于后续数据处理与逻辑判断。 |
| 写入 Modbus | 写入 Modbus 模块通过指定的Modbus连接（TCP、RTU或机械臂从站）向设备寄存器写入数据，可配置目标设备、寄存器地址、数据长度及待写入的数据，用于对外部设备进行控制或参数配置。 |
| 末端工具 | 在示教器扩展界面开启RM\_ARM+协议自动获取末端设备信息后，可将控制夹爪/灵巧手的目标角度或位置存储为动作；本模块则用于在图形化程序中直接调用这些预存动作，并可设置阻塞或非阻塞执行模式。 |
| 升降机 | 升降机模块用于控制已启用的升降机构运动到指定的目标高度。您可手动输入或通过变量设置目标高度与运动速度，并选择阻塞或非阻塞执行模式。（注意：使用前需确保已开启升降机构功能） |
| 轨迹 | 轨迹模块用于调用并执行通过拖动示教方式预先录制并保存的完整运动轨迹。可直接选择轨迹名称，并设置以阻塞或非阻塞模式来回放整个路径。 |
| 力控 | 力控模块提供完整的六维力控功能，可为X、Y、Z方向设置力控模式、目标力及线速度，同时为MX、MY、MZ方向设置力矩控制模式、目标力矩及角速度，从而实现精确的顺应性作业，如精密装配或曲面打磨。 |

| 托盘 | 通过设定托盘原点、行列布局及间距，为整个托盘自动规划并生成所有点位的坐标数据集合，是托盘运动的基础。 |

##### 运动指令

![移动指令参数](https://develop.realman-robotics.com/realman/docs/attachments/multimedia/zh/robot4th/quickUseManual/teachingPendantfour/onlineCode/image-47.png)

运动指令参数

运动指令分为“MOVEJ”、“MOVEL”、“MOVEC”、“MOVES”、“MOVEJ\_P”五种运动类型。

1. MOVEJ与MOVEJ\_P指令：只保证最终路点位置，不对中间轨迹进行约束。
2. MOVEL指令：在保证最终路点位置的同时，保证两点之间轨迹为直线运动。
3. MOVEC指令：用来执行圆弧或圆形轨迹，只能添加两个路点（中间点和终点）。
4. MOVES指令：可以实现更加复杂的曲线运动，不能有连续点位位置相同。

![运动指令](https://develop.realman-robotics.com/realman/docs/attachments/multimedia/zh/robot4th/quickUseManual/teachingPendantfour/onlineCode/image79.png)

运动指令类型

**“运动”** 指令可对运动类型、路点、运动速度、交融半径、阻塞模式进行设定。

运动指令

- **运动类型：** 包括“MOVEJ”、“MOVEJ\_P”、“MOVEL”、“MOVEC”、“MOVES”，分别表示关节运动、直线运动、圆弧运动（当执行圈数为“0”时，执行圆弧轨迹；当执行圈数为大于等于1时，执行圆形轨迹）和曲线运动。其中“MOVEJ”与“MOVEJ\_P”均为关节运动，但路点参数不同，“MOVEJ”的路点参数为各轴关节角度，“MOVEJ\_P”为工具坐标点的位姿。
- **路点：** 用户可点击下拉框选择自己保存好的路点，作为机器人工作运动点位。该指令可选择事前保存的路点。选择路点后，可执行以下操作。
	- 可通过点击编辑按钮，跳转至 `示教` > `编辑模式` 进行编辑路点，具体请参考 [点位菜单](#352416) 。
		- 可通过点击路点右侧的 `关节运动` 或 `直线运动` 调试机械臂运动到该点位，仅对当前“路点”有作用。
		- 在右侧设置栏中选择目标点位，长按 `关节运动` 按钮，控制机器人从当前位置以MOVEJ形式运动到目标点，松开按钮运动停止。
				- 在右侧设置栏中选择目标点位，长按 `直线运动` 按钮，控制机器人从当前位置以MOVEL形式运动到目标点，松开按钮或者发生不可达时运动停止。
- **运动速度：** 为该移动指令下路点的默认速度，支持通过手动输入或者选择手动添加的变量的方式进行设置。
- **交融半径：** 默认为100% ，无需更改，支持通过手动输入或者选择手动添加的变量的方式进行设置。
- **阻塞模式：** 分为阻塞和非阻塞模式。阻塞模式下，当前运动到位后，机器人执行后续指令；非阻塞模式下，当前运动过程中，机器人同步执行后续程序。

### 设为默认

系统支持将某一个编程文件设为默认编程文件，此时，在后续进入示教器时，默认打开设为默认的编程文件。

在文件列表中，点击目标编程文件右侧的设为默认按钮，完成对应编程文件的设为默认操作。

设为默认

### 编辑

修改保存的编程文件名称、编号和速度。

1. 在文件列表中，点击目标编程文件右侧的编辑按钮。
2. 在弹出编辑文件对话框中，填写修改后的文件名称、编号和速度后，点击 `保存` 完成编辑编程文件。
	编辑编程文件

### 运行

支持在编程文件列中直接运行已保存的编程文件。

在文件列表中，点击目标编程文件右侧的运行按钮，将打开对应的编程文件，并直接运行对应的编程文件。

运行编程文件

如果编程文件设置速度与当前运行速度不一致，则弹出速度不一致的提示，请根据需要选择按文件或按当前速度运行。

速度不一致提示

### 导出

编程文件支持导出到本地。

勾选待导出的编程文件，支持通过点击左下角的 `全选` 选择所有编程文件，然后点击 `导出` 按钮，可以将编程文件导出到浏览器设置的下载路径中，后缀为.tar。

导出编程文件

### 删除

当编程文件不再使用时，支持删除对应编程文件。

勾选待删除的编程文件，支持点击左下角的 `全选` 选择所有编程文件，然后点击 `删除` 按钮，并在弹出的提示框中，点击 `确认` 完成删除目标编程文件。

删除编程文件

### 导入

支持从本地导入编程文件。

点击 `导入` 按钮，并在弹出的对话框中选择目标编程文件，点击 `打开` ，完成编程文件导入。

导入编程文件

备注：当导入的编程文件与示教器中的编程文件冲突时，会弹出如下提示，请根据需要选择对应处理方案，并点击 `确认` 完成导入。

名称冲突

### 新增

用于新建编程文件。

1. 点击 `新增` 按钮，并在弹出的新增文件对话框中，设置文件名称、编号和速度。
	新增编程文件
2. （可选）示教器支持从模版选择已有模版进行快速创建，点击从模版选择右侧的开关，可显示已有模版，请根据需要选择对应模版。
	从模版新建
3. 点击 `保存` 完成新建编程文件。  
	新建的编程文件将自动添加至文件列表中。
	完成新增编程文件

## 点位菜单

点位管理页面显示点位名称、创建时间，可执行 `编辑` 、 `查看详细参数` 、 `导出` 、 `删除` 、 `导入` 和 `新增` 操作。

- 支持根据时间倒序、时间顺序、名称倒序和名称顺序进行排序。
- 支持根据文件名称或编号进行精确搜索。

点位列表

### 编辑

修改保存的点位参数、名称以及备注。

1. 在点位列表中，点击目标点位右侧的编辑按钮，跳转至示教菜单。
	编辑点位
2. 请根据需要在示教或编辑页签，修改对应的参数，并点击下方的 `更新` 。
	更新点位
3. 在弹出编辑点位对话框中，填写修改后的点位名称和备注后，点击 `保存` 完成编辑点位。
	编辑点位信息

### 查看详细参数

点位列表支持查看点位的详细参数。

在点位列表中，点击目标点位右侧的展开按钮，可显示点位的详细信息，包括工作坐标系、工具坐标系以及关节和位姿信息。

查看点位详细参数

### 导出

点位文件支持导出到本地。

勾选待导出的点位文件，支持通过点击左下角的 `全选` 选择所有点位文件，然后点击 `导出` 按钮，可以点位文件导出到浏览器设置的下载路径中，后缀为.TXT。

导出点位文件

### 删除

当点位文件不再使用时，支持删除对应点位文件。

勾选待删除的点位文件，支持点击左下角的 `全选` 选择所有点位文件，然后点击 `删除` 按钮，并在弹出的提示框中，点击 `确认` 完成删除目标点位文件。

删除点位文件

### 导入

支持从本地导入点位文件。

点击 `导入` 按钮，并在弹出的对话框中选择目标点位文件，点击 `打开` ，完成点位文件导入。

导入点位文件

备注：当导入的点位文件与示教器中的点位文件冲突时，会弹出如下提示，请根据需要选择对应处理方案，并点击 `确认` 完成导入。

名称冲突

### 新增

用户可通过此功能添加常用点位，保存的点位可在点位菜单中查看编辑，方便用户使用。

**新增点位示例：**

1. 打开 `点位` 菜单，点击点位列表下方的 `新增` 按钮，则会跳转至示教菜单。

新增点位

2. 在此页面通过示教按钮、位姿编辑或者末端拖动示教按钮拖动使机械臂到达需要的点位后，点击页面下方的 `保存` 。

新增点位

3. 在弹出新建点位对话框中，填写点位名称和备注后，点击 `保存` 完成新增点位。

新增点位
