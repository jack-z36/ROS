# 非具体编程规划加载规则

## 适用范围

输出 Markdown、架构梳理、数据定义、功能定义、L2/L3 规划、从零编写程序的蓝图阶段。不直接改代码。

## 触发信号

用户要求生成或讨论文档、架构、数据定义、功能模块、L2/L3、微元任务、开发蓝图。

## 上下文加载顺序

1. 读取相关阶段知识主题页，先建立语义上下文。
2. 读取对应约束：文档体系、工作流、阶段二任务体系等。
3. 读取对应工程工作台中的现有进度。
4. 只在准备产出正式文档时读取模板文件。

## 必读入口

- `DOCS/01_知识/<阶段>/`
- `DOCS/02_约束/文档体系/文档分类与目录规范.md`
- 任务对应的工作流或阶段任务体系约束

## 禁止默认读取

- 全部模板目录
- `DOCS/98_archive/`
- `DOCS/99_learning/`

## 阻断条件

- 无法判断目标语义应归知识、约束还是工程。
- 目标文档落点不符合文档分类规范。
- 阶段二 L2/L3 规划未读取阶段二任务体系约束。

## 输出要求

产出前说明目标文档类型、目标路径、适用范围和仍待确认的问题。
