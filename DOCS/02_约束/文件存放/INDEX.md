# 文件存放约束索引

## 规则入口

- `阶段二文件存放规则.md`：阶段二 `data_clean` 相关源码、配置、测试、运行记录、数据产物、缓存和外部 SDK 缓存的存放规则。
- `Conda环境存放规则.md`：全仓库所有 Conda 环境的共享路径、分支/worktree 隔离和迁移验收规则。

## 读取条件

涉及阶段二代码、配置、测试、数据产物、Runtime 运行记录、L3 任务归档或外部 SDK 缓存时读取本主题；涉及 Conda 环境创建、迁移、启动或测试时必须继续读取 `Conda环境存放规则.md`。

## 禁止事项

- 禁止在未读取文件存放规则时创建阶段二新文件。
- 禁止把数据产物、缓存或运行输出散落到未登记目录。
