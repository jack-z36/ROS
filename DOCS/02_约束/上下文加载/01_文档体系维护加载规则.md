# 文档体系维护加载规则

## 适用范围

调整 DOCS 目录、迁移文档、修改文档分类规范、修改根 `AGENTS.md` 或整理归档学习资料。

## 触发信号

用户要求优化 DOCS、重构文档体系、调整知识/约束/工程分类、迁移旧文档、维护路由入口。

## 上下文加载顺序

1. 读取 `DOCS/02_约束/文档体系/INDEX.md`。
2. 按任务读取对应文档体系原子规则。
3. 读取 `DOCS/98_archive/2026-06-15_DOCS重构过程记录/语义迁移审计表.md`；如果不存在，则先创建于 `DOCS/语义迁移审计表.md`。
4. 按审计表需要定点读取旧文档或新目标文档。

## 必读入口

- `DOCS/02_约束/文档体系/文档分类与目录规范.md`
- `DOCS/02_约束/文档体系/语义微元迁移规范.md`
- `DOCS/02_约束/文档体系/消费对象文档形态规范.md`（涉及生成或重构非代码文件时）

## 禁止默认读取

- `DOCS/98_archive/`
- `DOCS/99_learning/`

## 阻断条件

- 目标目录不符合 `文档分类与目录规范.md`。
- 迁移未登记到 `DOCS/98_archive/2026-06-15_DOCS重构过程记录/语义迁移审计表.md`。
- 准备修改根 `AGENTS.md` 但未读取 `AGENTS维护规则.md`。

## 输出要求

说明新增、移动、拆分、归档了哪些语义和路径；列出仍待迁移的语义。
