# 传感器数据详解

## 总览

Pi0.5 部署程序订阅 **10 路 ROS2 topic**，采集 **4 类数据**，最终组装为 26D 状态向量 + 3 路图像。

---

## 传感器数据总表

| # | 数据名称 | Message Type | 默认 Topic | 维度 | 单位 | 说明 |
|---|----------|--------------|------------|------|------|------|
| 1 | 顶部相机 | `CompressedImage` | `.../image/top/compressed` | H×W×3 | — | JPEG/PNG 压缩图像 |
| 2 | 左腕相机 | `CompressedImage` | `.../image/left_wrist/compressed` | H×W×3 | — | JPEG/PNG 压缩图像 |
| 3 | 右腕相机 | `CompressedImage` | `.../image/right_wrist/compressed` | H×W×3 | — | JPEG/PNG 压缩图像 |
| 4 | 本体感知 | `JointState` | `.../proprioception` | 12D | rad | 左臂6 + 右臂6 关节角 |
| 5 | 左手状态 | `JointState` | `.../left_hand/joint_state` | 1D | 300-1000 | 电机编码器值 |
| 6 | 右手状态 | `JointState` | `.../right_hand/joint_state` | 1D | 300-1000 | 电机编码器值 |
| 7 | 左臂末端位置 | `Point` | `.../left_arm/ee_position` | 3D | m | xyz 坐标 |
| 8 | 左臂末端姿态 | `Vector3` | `.../left_arm/ee_rpy` | 3D | rad | roll/pitch/yaw |
| 9 | 右臂末端位置 | `Point` | `.../right_arm/ee_position` | 3D | m | xyz 坐标 |
| 10 | 右臂末端姿态 | `Vector3` | `.../right_arm/ee_rpy` | 3D | rad | roll/pitch/yaw |

## 26D 状态向量编码

| Index | 字段 | 维度 | 单位 | 说明 |
|-------|------|------|------|------|
| 0-5 | `left_arm_q` | 6D | rad | 左臂 6 关节角 |
| 6-11 | `right_arm_q` | 6D | rad | 右臂 6 关节角 |
| 12 | `left_hand_q` | 1D | 300-1000 | 左手电机编码器值 |
| 13 | `right_hand_q` | 1D | 300-1000 | 右手电机编码器值 |
| 14-16 | `left_ee_pos` | 3D | m | 左臂末端 xyz |
| 17-19 | `left_ee_rpy` | 3D | rad | 左臂末端 rpy |
| 20-22 | `right_ee_pos` | 3D | m | 右臂末端 xyz |
| 23-25 | `right_ee_rpy` | 3D | rad | 右臂末端 rpy |

## 各类 Topic 数值示例

### 1. 三路图像（CompressedImage）

```
header:
  stamp: {sec: 1718000000, nanosec: 500000000}
  frame_id: "top_camera"
format: "jpeg"
data: [0xFF, 0xD8, 0xFF, 0xE0, ...]   # JPEG 字节，约 15-50KB
```

### 2. 本体感知（JointState，12D）

```
header:
  stamp: {sec: 1718000000, nanosec: 0}
name: [joint1, joint2, joint3, joint4, joint5, joint6,
       joint1, joint2, joint3, joint4, joint5, joint6]
position:
  # 左臂 6 关节角（弧度）
  - 0.12      # joint1: 肩关节俯仰
  - -0.45     # joint2: 肩关节滚转
  - 0.78      # joint3: 肩关节偏航
  - -0.03     # joint4: 肘关节
  - 0.56      # joint5: 腕关节俯仰
  - 0.21      # joint6: 腕关节滚转
  # 右臂 6 关节角（弧度）
  - -0.08
  - 0.52
  - -0.33
  - 0.15
  - -0.67
  - 0.44
```

### 3. 灵巧手状态（JointState，1D）

```
# 左手
header:
  stamp: {sec: 1718000000, nanosec: 0}
position: [750.0]   # 电机编码器值，范围 300-1000

# 右手
header:
  stamp: {sec: 1718000000, nanosec: 0}
position: [420.0]   # 电机编码器值，范围 300-1000
```

> [!note] 数值范围
> - 300.0 = 完全闭合
> - 1000.0 = 完全张开
> - 在 bridge node 中通过 `hand_command_to_trigger()` 归一化到 0-1

### 4. 末端位姿（Point + Vector3，各 3D）

```
# 左臂末端位置（米）
left_ee_position:
  x: 0.45      # 基座前方 45cm
  y: 0.12      # 基座右侧 12cm
  z: 0.38      # 基座上方 38cm

# 左臂末端姿态（弧度）
left_ee_rpy:
  x: 0.05      # Roll:  2.9°
  y: -1.23     # Pitch: -70.5°
  z: 0.78      # Yaw:   44.7°

# 右臂末端位置（米）
right_ee_position:
  x: 0.42
  y: -0.15     # Y 为负（左侧）
  z: 0.35

# 右臂末端姿态（弧度）
right_ee_rpy:
  x: -0.03
  y: -1.18
  z: -0.82     # Yaw 为负（镜像）
```

## 数据来源

| 数据类型 | 来源 | 说明 |
|----------|------|------|
| 三路图像 | 相机驱动节点 | RealSense 深度相机等 |
| 机械臂关节角 | 机械臂控制器节点 | 直接读取，非 FK 计算 |
| 灵巧手关节角 | 灵巧手驱动节点 | Inspire Hand 等 |
| 末端位姿 | 外部节点 | 直接发布，Pi0.5 只订阅 |
