# ui 层 — L2-01 外部参数加载与契约校验闭环

> `l2_id`：`l2-01-external-contract`

本 L2 不在该层新增源码产物。

**原因**：`ui/` 层负责外部交互边界（ROS node、subscriber、publisher、message converter）。本 L2 不订阅任何 ROS topic、不创建 publisher、不做 ROS node 生命周期管理。本 L2 虽然定义了 `/act/*` topic**名**（在 `TopicsConfig` 中），但只是配置**值**，不实际订阅/发布——订阅属 L2-02，发布属 L2-06。

**验收如何确认**：
- 本 L2 完成时不产生任何 `ui/*.py` 文件，不产生 launch 文件。
- topic 名作为 `TopicsConfig` 的字段存在（归 `config/`），被 L2-02/L2-06 在运行时读取使用。
