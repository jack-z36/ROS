# L3 执行实现行为

## 消费 Agent

- 执行 sub-agent

## 本文职责

本文只约束执行 sub-agent 如何实现被分配的单个 L3。

## 不负责

本文不约束本地验证、执行交接、验收结论、任务分配或 Git。

## 必须行为

- 执行代码类 L3 前读取并遵守 `DOCS/02_约束/编程执行/Agent编程执行原则.md`。
- 阶段二和阶段四代码类 L3 必须读取并遵守 `DOCS/02_约束/编程执行/架构边界与机械约束原则.md`。
- 校验任务文件路径、文件名编号、正文 L3 编号和 dispatch `task_id` 一致。
- 只完成 L3 中声明的唯一目标。
- 只修改 L3 允许修改的文件。
- 保留 L3 明确要求保留的旧行为。
- 遇到范围外问题，只记录为后续建议，不顺手修复。

## 禁止事项

- 禁止选择其他 L3。
- 禁止跨 L2 修改文件。
- 禁止擅自修改 dispatch。
- 禁止修改验收卡片结论。
- 禁止任何 Git 写操作。
