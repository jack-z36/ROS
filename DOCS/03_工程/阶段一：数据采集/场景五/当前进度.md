## 当前风险

- 多个同型号 CH340 可能没有唯一序列号，导致仅靠 USB 设备属性无法区分四个触觉设备。
- 多个同型号 HDMI 采集卡可能没有唯一序列号，导致仅靠采集卡属性无法区分左右 GoPro。
- 当前两路 `Generic USB Camera3` 的 `ID_SERIAL`/`ID_SERIAL_SHORT` 完全相同，左右为用户授权的临时随机分配；实际画面反向时需要交换两条 USB 拓扑配置。
- 当前 `ID_PATH` / by-path 依赖 USB 插口拓扑，不能满足“无论怎么接入都稳定”的最终目标。
- 如果硬件身份不足，必须设计人工标定流程，否则容易把左右手或 l1/l2/r1/r2 映射错。
- 当前 `r1` 设备信息通道会响应，但响应类型实测为 `0x02`，不是文档中的 `0x03`；后续接入其他触觉传感器时需要确认是否一致。
- 任何 topic 名称变化都可能影响场景三 MCAP 配置和场景四 UI 显示。
