# 阶段二场景四：输出程序与文件

## 预期输出程序

| 程序/模块 | 功能 | 输入 | 输出 |
| --- | --- | --- | --- |
| canonical dataset 初始化器 | 创建 dataset 目录、metadata、schema 模板和空索引 | dataset 名称、配置 | `canonical_dataset_mcap/` 骨架 |
| schema 生成/校验模块 | 生成和维护五个 schema 文件 | schema 定义 | `schema/*.json` |
| episode builder | 将 aligned MCAP 转换为 episode 目录 | aligned MCAP、schema | episode 目录结构 |
| step_index 生成器 | 生成 topic 到 step 的映射索引 | 对齐结果 | `step_index.parquet` |
| action chunk 生成器 | 基于 TCP pose 生成 UMI 风格相对轨迹 | step_index、TCP pose | action chunk 数据 |
| masks 生成器 | 标记每个 step 各字段的有效性 | step_index、对齐质量 | `masks.parquet` |
| report 生成器 | 生成 alignment/quality/robot_constraint report | 各检查结果 | report 文件 |
| manifest 生成器 | 记录处理过程 | 处理参数 | `processing_manifest.json` |

## 预期输出文件

| 文件 | 位置 | 说明 |
| --- | --- | --- |
| dataset_meta.json | `canonical_dataset_mcap/` | 描述整批数据集 |
| dataset_index.parquet | `canonical_dataset_mcap/` | 全局 episode 索引 |
| observation_schema.json | `canonical_dataset_mcap/schema/` | 定义 observation 字段 |
| action_schema.json | `canonical_dataset_mcap/schema/` | 定义 action 格式 |
| frame_schema.json | `canonical_dataset_mcap/schema/` | 定义坐标系 |
| topic_schema.json | `canonical_dataset_mcap/schema/` | 定义 topic 映射 |
| quality_schema.json | `canonical_dataset_mcap/schema/` | 定义质量字段 |
| episode_meta.json | `episodes/episode_xxxxxx/` | 描述单条 episode |
| data.mcap | `episodes/episode_xxxxxx/` | 时间序列数据本体 |
| step_index.parquet | `episodes/episode_xxxxxx/` | step 级索引 |
| masks.parquet | `episodes/episode_xxxxxx/` | step 有效性标记 |
| alignment_report.json | `episodes/episode_xxxxxx/` | 同步质量报告 |
| quality_report.json | `episodes/episode_xxxxxx/` | 数据质量报告 |
| robot_constraint_report.json | `episodes/episode_xxxxxx/` | 机器人约束报告 |
| processing_manifest.json | `episodes/episode_xxxxxx/` | 处理过程记录 |
