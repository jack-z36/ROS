# 阶段四：模型部署目标描述

## 阶段定位

阶段四负责让训练好的 VLA 在本地推理环境中，根据实时 observation 和 language instruction 输出 candidate action，并通过后处理与机器人接口适配，驱动真实机械臂执行任务。

部署阶段不是简单加载 checkpoint。它要把模型输出接到真实机器人控制闭环里。

## 核心目标

阶段四的核心目标是：

- 从实时 ROS2 topic 构造模型需要的 observation。
- 调用 VLA policy server 输出 candidate action。
- 按训练时一致的 action 语义解释模型输出。
- 对 candidate action 做限幅、平滑、安全检查和异常过滤。
- 通过 robot adapter 转成 RM65、双臂和夹爪控制接口可执行的命令。
- 驱动真实机械臂完成示教任务，例如看到桌面上的胶水，夹取胶水，移动到篓筐，放入篓筐。

## 在线部署数据流

阶段四在线数据流是：

实时传感器发布 ROS2 topic，Observation Builder 从 topic 构造 `observation_t`，VLA Policy Server 根据 observation 和语言指令输出 candidate action，Action Post-processor 将其变成 safe action，Robot Adapter 转成机械臂和夹爪控制命令，机械臂执行后产生状态反馈，再进入下一轮 observation。

## 成功标准

阶段四成功时应满足：

- 实时 observation 与训练时 observation schema 一致。
- 推理输出 action 与训练时 action schema 一致。
- UMI 风格 relative trajectory action 能根据当前真实 TCP pose 还原为目标 TCP pose。
- safe action 通过限幅、平滑和安全检查。
- robot adapter 能把 safe action 转为机械臂接口命令。
- 真实机械臂能执行目标任务，并能记录日志和回放。
