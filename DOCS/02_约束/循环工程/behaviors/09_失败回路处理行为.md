# 失败回路处理行为

## 消费 Agent

- 主 Agent

## 本文职责

本文只约束主 Agent 如何处理 L3 验收结果为 `FAIL_LOCAL` 的 execute-review 回路。

## 不负责

本文不定义验收标准、不实现修复、不提交 Git。

## 处理规则

- 第一次或第二次 `FAIL_LOCAL`：把验收反馈交回同一 L3 的执行 sub-agent。
- 第三次 `FAIL_LOCAL`：停止该 L3 自动推进，记录阻断原因并等待人工介入。
- 每轮失败反馈必须对应新的验收 round 日志。

## 禁止事项

- 禁止把 `FAIL_LOCAL` 任务提交。
- 禁止为了绕过失败改验收卡片。
- 禁止把失败任务标记为 blocked，除非验收反馈明确是环境或硬件阻塞。
