| 失败现象 | 排查入口 |

| `ModuleNotFoundError: No module named 'act.config...'` | 检查 `src/model_deploy/act/config/__init__.py` 及 `act/tests/config/__init__.py` 是否存在；确认从仓库根目录运行 |

| observation 字段不是 6 个 / command 非单路 | 检查 `ObservationTopicsConfig`（应为 6 字段）/`CommandTopicsConfig`（应为 policy_action/status/metrics 单路） |
| 残留 Bridge/Mux/JointLimits | grep schema.py 确认无 `BridgeTopicsConfig`/`MuxTopicsConfig`/`max_joint_delta_rad`/`hand_min`/`hand_max`/`JointLimitsConfig` |

| deploy.yaml 加载失败 | 对照 deploy.yaml 字段名与 schema.py dataclass 字段名；检查 `_deploy_from_mapping` 映射 |
