# 04 数据定义文件修改方案

## 问题定位

现有 L2 数据定义沿用了旧的 `common_frame` 主链路。它把左右手位姿先统一到 common frame，再在场景二后半段规划 `common_frame -> robot_base`、IK、MCAP_B 和关节限制检查。

新的最终语义要求：

- 左手 TCP pose 描述在左手机械臂基坐标系下。
- 右手 TCP pose 描述在右手机械臂基坐标系下。
- 不再把左右手 TCP pose 统一描述到同一个 `common_frame` 或统一 `robot_base`。
- 当前主线不再继续 IK / MCAP_B / 关节限制检查，而是转向 `MCAP_A -> 数据对齐 -> LeRobot v3`。

因此，数据定义文件需要在后续实施阶段单独改造。本文件只描述修改方案，不直接修改现有 L2 数据定义文件。

## 建议新增的数据定义

后续实施时建议新增或替换为以下数据定义。命名可在正式改造前再统一，但语义必须保持稳定。

### `ArmBaseTcpPose`

责任：描述单侧 TCP 在对应机械臂基坐标系下的位姿。

建议字段：

- `hand`：`left` 或 `right`。
- `frame_id`：`left_arm_base` 或 `right_arm_base`。
- `timestamp_ns`：样本时间戳。
- `position_m`：TCP 位置，单位 m。
- `orientation_quat`：TCP 姿态四元数，必须明确顺序。
- `source_camera_pose_ref`：来源相机位姿引用。
- `source_tcp_in_camera_ref`：TCP 在相机坐标系下位姿或外参引用。
- `source_work_frame_in_base_ref`：工作坐标系在机械臂基坐标系下的位姿引用。
- `official_transform_api`：实际调用的官方函数名或版本。

### `WorkFrameInArmBasePose`

责任：描述用户输入的工作坐标系在对应机械臂基坐标系下的位姿。

建议字段：

- `hand`：`left` 或 `right`。
- `base_frame_id`：`left_arm_base` 或 `right_arm_base`。
- `work_frame_id`：工作坐标系名称。
- `position_m`：工作坐标系原点在机械臂基坐标系下的位置。
- `orientation_quat`：工作坐标系在机械臂基坐标系下的姿态四元数。
- `source`：用户输入、标定文件或外部配置来源。
- `valid_from`：适用数据批次或采集任务。

### `McapAArmBasePoseChannel`

责任：约束 MCAP_A 中左右 arm-base TCP pose 的 channel、schema、左右侧和时间戳语义。

建议字段：

- `left_tcp_pose_channel`
- `right_tcp_pose_channel`
- `message_schema`
- `timestamp_policy`
- `frame_id_policy`
- `required_for_lerobot_v3_export`

## 修改原则

后续真正修改 L2 数据定义时必须遵守：

1. 不在原定义中继续扩大 `common_frame` 的职责。
2. 不把 `robot_base` 写成左右手共享的统一最终坐标系。
3. 左右手必须分别绑定到 `left_arm_base` 和 `right_arm_base`。
4. 滤波前后都必须保持对应侧 arm-base 坐标系语义。
5. `common_frame -> robot_base` 不再作为主位姿链路的数据定义。
6. IK / MCAP_B / 关节限制相关数据定义暂不作为当前修改目标。
7. 官方函数 API 未补充前，不得把自研转换公式固化进数据定义。

## 验收标准

后续完成数据定义文件改造后，应满足：

- 场景一数据定义中不再要求生成 `FrameAlignmentConfig/common_anchor` 作为主链路输入。
- 场景一输出契约能明确给出左右 arm-base TCP pose。
- 场景二滤波输入、滤波输出和 MCAP_A 写出契约都以左右 arm-base TCP pose 为主位姿。
- 数据定义中能追溯官方函数的两个输入：TCP 在相机坐标系下的位姿、工作坐标系在机械臂基坐标系下的位姿。
- 数据定义中不再要求实现 `common_frame -> robot_base` 后置转换。
- 数据定义中不再把 IK / MCAP_B / 关节限制检查作为当前主线依赖。
