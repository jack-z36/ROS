## 0. 前置说明

- 本 L2 **不依赖 ROS、不依赖硬件、不依赖真实模型 bundle**——全部验收在本地 Python 进程内完成。
- 真实 ACT bundle 缺失时，用 fixture/fake bundle 验证；真实 bundle 校验标 env-blocked，留待 L2-03 有真 bundle 时复验。
- 所有命令用 `python3`（禁止 `python`）。cwd = 仓库根 `/home/hit/ROS`。
- 本 L2 **无真机风险**（不发送任何硬件命令）。

## 1. 验收清单

### 验收项 1：types 层单测通过

- cwd：`/home/hit/ROS`
- 命令：`python3 -m pytest src/model_deploy/act/tests/types/ -v`
- 所需环境：Python3 + pytest（无 ROS、无硬件）。
- 测试输入：types 层单测自带的 16D 合法/非法向量 fixture。
- 观察点：pytest 输出。
- 通过现象：全部 types 测试 PASS；能看到 `ACTION_DIM==16`、`STATE_DIM==16`、段序拼接/拆分、维度校验异常的用例通过。
- 失败现象：有用例 FAIL。排查入口：`src/model_deploy/act/types/action_spec.py`、`state_spec.py`。
- 风险级别：低（纯本地）。

### 验收项 2：repo 层单测通过

- cwd：`/home/hit/ROS`
- 命令：`python3 -m pytest src/model_deploy/act/tests/repo/ -v`
- 所需环境：Python3 + pytest。
- 测试输入：repo 单测自带的临时 fixture bundle 目录（含 manifest.json/normalizers.json/experiment_config.yaml/checkpoint）。
- 观察点：pytest 输出。
- 通过现象：repo 测试 PASS；合法 bundle 读取成功，缺文件抛 FileNotFoundError。
- 失败现象：读取异常或未抛缺失异常。排查入口：`src/model_deploy/act/repo/*.py`。
- 风险级别：低。

### 验收项 3：config 层单测通过（含 contract 校验）

- cwd：`/home/hit/ROS`
- 命令：`python3 -m pytest src/model_deploy/act/tests/config/ -v`
- 所需环境：Python3 + pytest。
- 测试输入：config 单测的合法/非法 deploy.yaml fixture + contract 校验 fixture（三处 dim 一致/不一致、normalizer dim 匹配/不匹配）。
- 观察点：pytest 输出。
- 通过现象：合法配置构造出 DeployConfig（dims=16）；各类非法配置抛异常；bundle contract 三处 dim 不一致判 fail；normalizer dim≠16 判 fail。
- 失败现象：合法配置构造失败 或 非法配置未抛错。排查入口：`src/model_deploy/act/config/schema.py`。
- 风险级别：低。

### 验收项 4：端到端集成测试通过

- cwd：`/home/hit/ROS`
- 命令：`python3 -m pytest src/model_deploy/act/tests/integration/ -v -k l2_01`
- 所需环境：Python3 + pytest。
- 测试输入：一份合法 fixture bundle + deploy.yaml。
- 观察点：pytest 输出 + 构造出的对象字段。
- 通过现象：`load_deploy_config` 返回 `DeployConfig`；`runtime.action_dim==16`、`state_dim==16`；`BundleContractResult.passed is True`；`NormalizerContractResult.passed is True`。
- 失败现象：端到端构造失败。排查入口：`config/schema.py:load_deploy_config` 编排顺序。
- 风险级别：低。

### 验收项 5：下游可 import 契约对象

- cwd：`/home/hit/ROS`
- 命令：`python3 -c "from model_deploy.act.config import DeployConfig; from model_deploy.act.types import StateSpec, ActionSpec; print('import ok')"`（具体包路径以 L3 落地为准）
- 所需环境：Python3（已 `colcon build` 或 PYTHONPATH 就绪）。
- 观察点：stdout。
- 通过现象：打印 `import ok`，无 ImportError。
- 失败现象：ImportError。排查入口：`__init__.py` 导出 + 包结构。
- 风险级别：低。
