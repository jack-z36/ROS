边界契约

16D 维度契约（已锁定，源自阶段二交付说明）
state 16D（去触觉，左全在前）：左TCP(7) + 右TCP(7) + 左夹爪(1) + 右夹爪(1)
action 16D（左右交替）：左TCP目标(7) + 左夹爪(1) + 右TCP目标(7) + 右夹爪(1)
action 是绝对动作（target at t+1）；TCP 用 xyzw quaternion 归一化；夹爪 [0,1]。
详见 types/README.md 维度契约表。
