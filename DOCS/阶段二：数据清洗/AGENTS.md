# 阶段二：数据清洗工作入口

本目录是阶段二数据清洗的工作环境入口。阶段二采用两层 Harness：

- 阶段二总层：阶段级目标、背景、进度、产出、架构路线图和真实数据产物落点。
- 具体开发层：`01_runtime_mvp/` 与 `02_service/` 两条并行任务线。
- 任务记录层：`03_tasks/` 记录 active/completed 任务计划和执行前对话确认。

## 任务线入口

### Runtime MVP

目录：`01_runtime_mvp/`

- `目标描述.md`
- `背景信息.md`
- `执行约束.md`
- `执行记录.md`
- `当前进度.md`
- `输出程序与文件.md`

Runtime MVP 只负责流程编排、场景选择、配置读取、输入检查、run 目录、日志、manifest 和错误摘要，不实现真实清洗算法。

处理 Runtime MVP 任务前，还必须先阅读：

- `03_tasks/README.md`
- `03_tasks/active/001_runtime_mvp_harness.md`

### Service

目录：`02_service/`

先阅读 `02_service/` 任务级六件套，再按具体场景继续阅读对应 `场景一` 到 `场景五` 的六件套。

Service 任务线负责五个阶段二业务场景的真实处理能力：

1. 场景一：提取夹爪开合以及位姿转换。
2. 场景二：硬件数据可靠性验证。
3. 场景三：MCAP 多 topic 时间轴对齐。
4. 场景四：构建标准 canonical dataset。
5. 场景五：模型训练格式导出器。
