# 循环快照写入行为

## 消费 Agent

- 主 Agent

## 本文职责

本文只约束主 Agent 在每轮结束时如何写入下一轮恢复快照。

## 不负责

本文不定义 L3 执行、验收、Gate 或 Git 规则。

## 写入位置

```text
DOCS/03_工程/阶段四：模型部署/00_status/current_loop_snapshot.md
```

## 必须记录

- 更新时间。
- 本轮目标 L2。
- 本轮完成的 L3。
- 本轮提交 / pending push 项。
- 当前阻塞项。
- 下一轮建议目标 L2。
- 下一轮首先应读取的权威来源。

## 禁止事项

- 禁止用快照替代 dispatch 或验收结果。
- 禁止写入无法追溯到权威来源的状态。
