# L2 能力模块说明：关节限制检查器

> ⚠️ 当前不在主路径；保留以备未来。

## 1. 能力名称

```text
关节限制检查器
```

## 2. 所属位置

阶段：阶段二：数据清洗
L1：service_s2
场景：场景二：硬件数据可靠性验证
模块类别：数据计算类

## 3. 一句话目标

```text
基于 [[McapB|MCAP_B]] 和 [[IkSolveSummary]] 检查 R65M 4代 6DOF 的 IK 失败、关节角、速度、加速度和 workspace 问题，输出 [[JointConstraintCheckResult]]。
```

## 4. 能力角色

本能力是场景二机器人约束诊断层，位于 [[IK 求解与 MCAP_B 生成器]] 之后、MuJoCo 仿真验证器和 Parquet 标注与验证报告生成器之前。它只做离线诊断和标注输入生成，不修改 [[McapA|MCAP_A]] 或 [[McapB|MCAP_B]]。

已按 `grill-me` 约束完成意图澄清：首版机械臂型号为睿尔曼 R65M 4代 6DOF；R65M 在 SDK 中按 RM65 系列处理，使用 `RM_MODEL_RM_65_E` 和默认 `RM_MODEL_RM_B_E`；所有阈值由官网核实后落入 [[JointConstraintConfig]]，L3 执行端不再上官网查询。

## 5. 上游关系

- 直接上游是 [[IK 求解与 MCAP_B 生成器]]。
- 读取 [[McapB|MCAP_B]] 中 IK 成功帧的左右 JointState。
- 必须同时读取 [[IkSolveSummary]]，因为 IK 失败帧不会写入 MCAP_B。
- 逐样本 IK 记录来自 [[Rm65IkSampleResult]]。
- workspace 检查使用 [[RobotBaseTcpPose]] 语义。
- 约束阈值来自 [[JointConstraintConfig]]。

## 6. 下游关系

- Parquet 标注与验证报告生成器消费 [[JointConstraintIssueInterval]]。
- MuJoCo 仿真验证器可复用连续成功片段和关节约束摘要。
- 场景四 masks 和 robot constraint report 消费本能力输出的问题时间段。
- 开发者入口 `scene2_joint_constraint_check` 展示 SDK 自检、阈值来源、问题区间、样本证据和运行日志。

## 7. 上游接口对齐检查

| 上游功能 | 上游接口 / 产物 | 本能力如何依赖 | 对齐状态 | 处理方式 |
|---|---|---|---|---|
| IK 求解与 MCAP_B 生成器 | [[McapB]] | 读取左右 JointState 成功帧 | 已对齐 | 复用，不修改 |
| IK 求解与 MCAP_B 生成器 | [[IkSolveSummary]] | 读取失败帧、逐样本记录、source pose 引用 | 已对齐 | 必读；缺失时 strict 失败 |
| IK 样本结果 | [[Rm65IkSampleResult]] | 区分 success / failed / sdk_error，聚合 IK 失败区间 | 已对齐 | 复用 |
| 机器人 base pose | [[RobotBaseTcpPose]] | 计算 workspace 半径和禁区风险 | 已对齐 | 复用 source pose 语义 |
| 睿尔曼 SDK | `Algo` 限位函数 | 调用 position / velocity limit 检查 | 部分依赖环境 | 先执行 SDK 自检 L3 |

## 8. 职责边界

本能力负责：

1. 部署并自检睿尔曼官方 SDK 的离线算法能力。
2. 定义 [[JointConstraintConfig]]、[[JointConstraintSampleEvidence]]、[[JointConstraintIssueInterval]] 和 [[JointConstraintCheckResult]]。
3. 对齐读取 [[McapB|MCAP_B]] 与 [[IkSolveSummary]]，切分连续 IK 成功片段。
4. 调用睿尔曼 SDK 检查关节角和速度限制。
5. 根据配置检查关节加速度和 workspace 半径 / 禁区。
6. 输出问题时间段、样本级证据和检查摘要。

本能力不负责：

1. 不重新求解 IK。
2. 不写或修改 MCAP_B。
3. 不执行 MuJoCo 碰撞、接触或力矩仿真。
4. 不决定 canonical dataset 的最终 mask 或 episode 删除。
5. 不连接真实机械臂作为首版强依赖。

## 10. 计算职责

| 计算项 | 输入 | 输出 | 影响下游 |
|---|---|---|---|
| SDK 自检 | 官方 `RM_API2`、`Algo` | SDK 可用性记录 | 阻止无 SDK 时执行 SDK 限位检查 |
| 上游对齐读取 | [[McapB]]、[[IkSolveSummary]] | 成功帧、失败帧、左右臂时间轴 | 避免漏标 IK 失败 |
| 连续成功片段切分 | JointState 时间戳、IK 失败、大 gap | 连续成功片段 | 速度 / 加速度只在片段内计算 |
| 关节角检查 | JointState position、SDK Algo | [[JointConstraintSampleEvidence]] | 输出角度超限区间 |
| 关节速度检查 | 相邻成功样本、SDK Algo | [[JointConstraintSampleEvidence]] | 输出速度超限区间 |
| 关节加速度检查 | 连续三点或速度差分、配置阈值 | [[JointConstraintSampleEvidence]] | 输出加速度超限区间 |
| workspace 检查 | [[RobotBaseTcpPose]]、工作半径和禁区配置 | [[JointConstraintSampleEvidence]] | 输出 workspace 问题 |
| 问题聚合 | 样本证据、IK 失败区间 | [[JointConstraintIssueInterval]] | Parquet 标注消费 |

## 11. 计算规则

| 规则 | 触发条件 | 计算 / 判断方式 | 结果表达 |
|---|---|---|---|
| 必须读 sidecar | 任意检查开始 | 缺少 [[IkSolveSummary]] 时失败 | `missing_ik_solve_summary` |
| IK 失败 | `Rm65IkSampleResult.status != success` | 聚合为硬问题区间 | `issue_type=ik_failed` |
| 不跨失败帧 | 速度 / 加速度计算 | IK 失败帧、大 gap 切断片段 | `continuous_success_segments` |
| 关节角 | 每个成功样本 | 调 SDK position limit，并用配置阈值记录证据 | `joint_position_limit` |
| 关节速度 | 片段内相邻成功样本 | 调 SDK velocity limit，dt 单位 sec | `joint_velocity_limit` |
| 关节加速度 | 片段内相邻速度差 | 与配置 `joint_max_acceleration_deg_s2` 比较 | `joint_acceleration_limit` |
| workspace 半径 | 每个 `RobotBaseTcpPose` | TCP 到 base 原点距离超过 `workspace_radius_mm` | `workspace_radius_limit` |
| workspace 禁区 | TCP 位于配置的 base 正上 / 正下柱状禁区 | 标为硬问题 | `workspace_no_go_zone` |
| 输出建议 | 任意问题 | 首版所有问题 `severity=hard` | `suggested_mask=drop_or_mask` |

## 12. 输出结果结构

| 字段 | 类型 | 含义 | 有效性要求 | 下游使用方式 |
|---|---|---|---|---|
| `input_mcap_b` | [[McapB]] | 来源 MCAP_B | 必须存在 | 追溯 |
| `input_ik_solve_summary` | [[IkSolveSummary]] | 来源 IK sidecar | 必须存在 | 补齐失败帧 |
| `constraint_config_ref` | [[JointConstraintConfig]] | 约束配置 | 必须含阈值来源 | 复现 |
| `continuous_success_segments` | list | 连续成功片段 | 不跨失败帧 / 大 gap | 速度加速度检查 |
| `sample_evidence` | list[[JointConstraintSampleEvidence]] | 样本级证据 | 可追溯到样本 | 人工调试 |
| `issue_intervals` | list[[JointConstraintIssueInterval]] | 问题时间段 | 下游主消费 | Parquet 标注 |
| `summary_by_issue_type` | object | 问题统计 | 必须区分左右臂 | 开发者入口 |

## 13. 异常与边界输入

| 边界情况 | 预期结果 | reason / error 表达 | 是否阻塞下游 |
|---|---|---|---|
| MCAP_B 缺失 | 检查失败 | `missing_mcap_b` | 是 |
| IkSolveSummary 缺失 | 检查失败 | `missing_ik_solve_summary` | 是 |
| SDK 不可导入 | SDK 相关检查失败 | `realman_sdk_import_failed` | 是 |
| 加速度阈值缺失 | 加速度检查失败或跳过并报告 | `missing_joint_acceleration_threshold` | 不阻塞其他检查 |
| JointState 与 sidecar 时间戳不匹配 | 对齐失败 | `mcap_b_ik_summary_mismatch` | 是 |
| 大 gap | 切分片段 | `large_gap_segment_boundary` | 否 |

## 14. 可验证样例

| 样例 | 输入特征 | 预期输出 | 验证方式 |
|---|---|---|---|
| 合法输入 | 连续成功 JointState，无失败和超限 | `issue_intervals=[]` | 单元测试 |
| IK 失败 | sidecar 有失败样本 | 输出 `ik_failed` 区间 | 上游兼容测试 |
| 角度超限 | 某关节超过配置范围 | 输出角度证据和区间 | 规则测试 |
| 速度超限 | 相邻成功样本变化过大 | 输出速度证据和区间 | 规则测试 |
| 加速度阈值缺失 | 未配置加速度 | 加速度检查跳过或失败，其他检查继续 | 配置测试 |
| workspace 超半径 | TCP 距离超过 610 mm | 输出 workspace 硬问题 | workspace 测试 |

## 19. 给 L3 任务生成的约束

1. 每个 L3 只能解决一个核心目标。
2. 第 7 功能组目录固定为 `service-s2-g7`。
3. L3 不得再联网查询阈值；阈值必须来自 [[JointConstraintConfig]] 和本 L2 的官方资料引用表。
4. SDK 环境 L3 必须 clone `https://github.com/RealManRobot/RM_API2.git` 到 `vendor/RealManRobot/RM_API2`。
5. SDK 环境 L3 必须搜索 `RMDemo_AlgoInterface`，不得硬编码唯一目录失败。
6. SDK 环境 L3 必须调用 IK、position limit 和 velocity limit smoke。
7. 关节限制检查必须同时读取 [[McapB]] 和 [[IkSolveSummary]]。
8. 速度和加速度不得跨越 IK 失败帧或大 gap。
9. 所有问题首版均输出 `severity=hard` 和 `suggested_mask=drop_or_mask`。
10. L3 自动化验收只证明局部实现正确；场景最终验收必须由用户本人运行 `./start_data_clean.sh --dev` 后确认。
