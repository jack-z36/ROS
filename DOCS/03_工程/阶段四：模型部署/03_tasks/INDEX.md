# 阶段四 L3 任务索引

本目录承载阶段四 L3 任务执行、调度和验收入口。执行前先读取 `DOCS/02_约束/上下文加载/04_L3微元任务执行加载规则.md`。

## 目录入口

| 目录 | 用途 | 读取条件 |
|---|---|---|
| `task/active/` | L3 任务正文 | 执行单个 L3，或按 L2 查看待执行任务 |
| `task/dispatch/` | L2 dispatch 文件 | 调度一个 L2 下的 L3，或判断并行 / 串行关系 |
| `cards/` | L3 与 L2 验收卡片 | 验收 L3 结果，或生成 L2 整体验收反馈 |
