# 阶段三：模型训练目标描述

## 阶段定位

阶段三负责使用阶段二生成的 canonical dataset，训练一个可以根据 observation 和 language instruction 输出 action 的小尺寸开源 VLA。

第一版重点不是追求最强性能，而是跑通完整训练链路。

## 核心目标

阶段三的核心目标是：

- canonical dataset 能被 exporter 转成目标训练格式。
- 训练脚本能读取 observation、language instruction 和 target action chunk。
- 小尺寸开源 VLA 能正常训练。
- loss 能正常下降。
- 模型能在验证集上输出格式正确的 candidate action。
- 输出 action 能被阶段四的部署链路解释。

## 训练样本定义

一个训练样本可以理解为：

- `observation_history`：过去若干帧 observation。
- `language_instruction`：任务语言，例如“把桌子上的胶水夹到篓筐里”。
- `target_action_chunk`：未来 K 步动作标签。

训练阶段必须继承阶段二的 action 语义。如果阶段二定义的是 UMI 风格 relative trajectory action，那么训练标签也必须是相对于当前推理起点 TCP 位姿的未来相对轨迹，而不是 raw pose、绝对 robot_base pose、关节角或逐步 delta。

## 第一版目标

第一版模型路线是先跑通小尺寸开源 VLA：

- 证明数据链路可用。
- 证明训练可以跑。
- 证明模型能输出动作。
- 证明部署程序能消费模型输出。

## 第二版目标

第二版在服务器和更多数据到位后，再训练更大尺寸 VLA：

- 使用更大参数量模型。
- 使用更多 episode。
- 支持更复杂任务。
- 提升泛化能力。
- 尝试更接近公司真实产品场景的部署链路。
