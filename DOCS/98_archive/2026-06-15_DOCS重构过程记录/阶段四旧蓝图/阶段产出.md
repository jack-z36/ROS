# 阶段四：模型部署阶段产出

## 文档定位

本文件用于记录阶段四在任务执行过程中实际产出的部署相关软件资产。

阶段四最终要完成什么真机闭环，写在 `阶段目标描述.md` 中；本文件只登记部署程序、服务、适配器、控制脚本和安全检查模块。

## 当前实际软件产出

阶段四目前尚未正式启动具体场景，因此还没有已经实现并验收的部署程序、policy server、robot adapter 或真机控制脚本。

当前不要把以下内容误记为“已产出软件”：

- 尚未实现的 Observation Builder。
- 尚未实现的 VLA Policy Server。
- 尚未实现的 Action Decoder。
- 尚未实现的 Action Post-processor。
- 尚未实现的 Robot Adapter。
- 尚未接入的机械臂/夹爪控制接口。

## 后续应登记的软件类型

当阶段四正式开始后，本文件应登记以下软件资产：

| 软件资产类型 | 应记录的功能 | 应记录的输入 | 应记录的输出 | 详细信息入口 |
| --- | --- | --- | --- | --- |
| Observation Builder | 从实时 ROS2 topic 构造模型需要的 observation。 | 图像、TCP pose、gripper width、tactile、language instruction。 | 与训练 schema 一致的 `observation_t`。 | 阶段四对应场景的 `输出程序与文件.md` 和模块架构文档。 |
| VLA Policy Server | 加载 checkpoint，接收 observation 和语言指令，输出 candidate action。 | checkpoint、模型配置、实时 observation。 | candidate action chunk。 | 阶段四场景输出清单。 |
| Action Decoder | 按 `action_schema.json` 解释模型输出的 action。 | candidate action、action schema。 | 标准化 relative trajectory action。 | 阶段四场景输出清单。 |
| Action Post-processor | 对 candidate action 做限幅、平滑、安全检查和异常过滤。 | relative trajectory action、当前机器人状态、安全配置。 | safe action。 | 阶段四场景输出清单。 |
| Robot Adapter | 把 safe action 转成机械臂和夹爪控制接口命令。 | safe action、当前 TCP pose、机械臂接口状态。 | 末端位姿命令、关节命令或轨迹命令。 | 阶段四场景输出清单。 |
| 在线日志与回放工具 | 记录部署过程中的 observation、action、状态反馈和错误。 | 部署运行数据。 | 可复盘日志和回放材料。 | 阶段四场景输出清单。 |

## 详细信息查找规则

阶段四当前没有具体场景。后续一旦新增部署场景，应在对应场景目录中维护 `输出程序与文件.md`，并把每个部署程序、服务、适配器、控制脚本和架构文档同步登记到本文件。
