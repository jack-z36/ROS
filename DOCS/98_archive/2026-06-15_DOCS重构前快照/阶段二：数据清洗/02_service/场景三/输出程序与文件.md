# 阶段二场景三：输出程序与文件

## 预期输出程序

| 程序/模块 | 功能 | 输入 | 输出 |
| --- | --- | --- | --- |
| 时间轴生成器 | 根据目标频率生成统一时间戳序列 | 目标频率、MCAP 时间范围 | 统一 step 时间戳序列 |
| topic 对齐器 | 将各 topic 数据对齐到统一时间轴 | validated MCAP、统一时间戳 | 对齐后的数据引用 |
| alignment report 生成器 | 汇总对齐质量统计 | 对齐结果 | alignment_report.json |

## 预期输出文件

| 文件 | 格式 | 说明 |
| --- | --- | --- |
| aligned MCAP | `.mcap` | 保持原始 topic 结构，附加对齐元数据 |
| alignment_report | `.json` | 各 topic 原始频率、统一频率、对齐误差统计、缺失帧数 |
