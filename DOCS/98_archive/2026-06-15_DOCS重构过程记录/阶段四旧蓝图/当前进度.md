# 阶段四：模型部署当前进度

## 当前状态

阶段四尚未正式启动具体场景。

当前只建立阶段目录和阶段级粗粒度文档，用于承接后续模型部署、真机推理和机械臂执行任务。

## 已明确的方向

- 部署阶段要消费阶段三输出的 checkpoint 和模型配置。
- 实时 observation 必须与训练 observation schema 一致。
- action 解释必须与训练 action schema 一致。
- VLA 输出的是 candidate action，不是最终机械臂命令。
- candidate action 必须经过后处理、安全检查和 robot adapter 后才能发送给机械臂。
