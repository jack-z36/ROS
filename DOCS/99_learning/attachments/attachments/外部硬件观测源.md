## 关键澄清

### 1. 它在哪个参考系下？

不适用。这里的“参考系”不是机器人空间坐标系，而是程序流水线中的数据阶段。

### 2. 它相对哪个原点？

不适用。它不是空间点或位姿变换结果。

### 3. 它对应哪个物理点 / 物理对象？

物理对象状态。如果它是缓存、请求或 batch，则无对应物理点，这是纯数学对象 / 程序容器。

### 4. 它是不是最终输出？

否。

### 5. 它不是什么？

它不应被误解为“整个推理程序的最终命令”。只有 ROS 控制命令输出才是下游执行系统真正收到的命令。
