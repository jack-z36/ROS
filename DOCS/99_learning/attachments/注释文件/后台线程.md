# 后台线程

> [!abstract] 核心定义
> 不阻塞主控制流程的并发执行单元，在本项目中主要指执行 VLA 推理的 `InferenceWorker`。

## 数据结构

| 字段名 | 类型 | 含义 | 是否必填 |
|--------|------|------|----------|
| `worker` | InferenceWorker | 后台执行主体 | 是 |
| `request_queue` | LatestQueue | 输入请求队列 | 是 |
| `result_queue` | LatestQueue | 输出结果队列 | 是 |

> [!info] 结构说明
> 后台线程的结构要点是：独立运行、通过队列交换数据、不直接卡住控制 tick。

## 具体数值示例

> [!example]- 点击展开具体数据实例
> ```json
>
> {
>   "worker": "InferenceWorker",
>   "input": "request_queue",
>   "output": "result_queue"
> }
> ```
>
> 该示例展示该术语在 [[部署推理数据流框架|部署推理数据流框架]] 中承担的数据契约角色。

## 具象隐喻

> [!tip] 生活场景类比
> 像餐厅后厨：前台持续接待客人，后厨异步处理耗时烹饪。
