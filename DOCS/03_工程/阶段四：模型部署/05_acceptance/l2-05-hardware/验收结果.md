## 测试输入

- 合法 16D policy action：保持当前位姿或极小 TCP 位移，夹爪 width 在安全范围内。
- 不可达 TCP 目标和越界 workspace 目标。
- 越界 gripper width。
- shadow-run 配置。
- real-robot smoke test 现场检查表。

## 观察点

- bridge dry-run 中 `/pi05/command/*` 或等价命令对象可观察，但 driver 不启动。
- shadow-run status 中 `sent_to_driver=false`。
- 不可达目标被拒绝，status 或日志中有 failure_reason。
- width 映射结果在夹爪安全范围内。
- real-robot smoke test 若执行，必须人工观察机械臂保持位姿、小位移方向正确、夹爪小幅开合正确、急停能立即中断。

## 通过现象

- shadow-run 全链路能从 policy action 生成受 gate 保护的命令和 status。
- IK、workspace、width 限幅能拒绝危险输入。
- 没有人工授权时，真实 driver 不会收到命令。
- real-robot smoke test 未执行时，Gate 可记录为“shadow-run 通过，真机 smoke test blocked”，但不得声称真机通过。
- real-robot smoke test 若执行，必须逐项记录动作幅度、SDK 返回码、人工观察结论和回滚结果。

## 失败现象与排查入口

- shadow-run 中 `sent_to_driver=true`：立即停止，检查 bridge gate 和 mode 配置。
- 不可达目标未拒绝：优先检查 IK / workspace 预检。
- width 映射越界：优先检查 width 到夹爪目标的映射和限幅。
- driver 启动或真机移动：立即急停，保留日志，停止 Gate 和 Git 同步。
