# 阶段二场景五：执行约束

## 必读文档

每次处理本场景前，必须先阅读阶段二四个阶段级文档、阶段二 `AGENTS.md`、`02_service/` 六件套，以及本场景六件套。涉及 canonical dataset 输入时，应阅读场景四的目标描述、背景信息和执行约束。

## 前置条件

- 场景四已完成，完整 canonical dataset 可用。
- 最终模型和数据格式已确定。

## 技术约束

- 导出器必须读取 schema，不能硬编码字段语义。
- 导出器必须按 masks 过滤，不能导出全部 step。
- 导出结果必须记录来源信息。
- `exports/` 必须可从 canonical dataset 完全重新生成。

## 解耦边界

- 本场景不改变 canonical dataset 主定义。
- 本场景不绕过 masks 直接导出全部 step。
- 本场景不提前实现训练逻辑。

## 验收边界

不能把以下情况算作完成：

- 只创建 `exports/` 目录，没有真实导出内容。
- 导出结果无法追溯到 episode 和 schema version。
- exporter 未按 masks 过滤无效 step。
- 阶段三无法读取或无法解释导出字段。
