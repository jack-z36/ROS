# 循环目标与边界

## 消费 Agent

- 主 Agent

## 本文职责

本文只定义阶段四 Ralph / OpenCode 循环工程的上位目标、当前无真机循环子目标和停止边界。

## 不负责

本文不定义具体 L3 执行步骤、验收细则、状态枚举、Git 命令或当前进度。

## 上位目标

阶段四最终目标是在真机中成功部署 VLA 模型，实现感知输入、状态装配、模型推理、动作解析、安全检查、机械臂 / 夹爪执行的闭环。

## 当前循环子目标

当前 Ralph / OpenCode 循环只承担无真机环境下的软件侧闭环建设：

```text
推进 L2-01 到 L2-05 deploy_022
→ 完成本地可运行、静态评审、dry-run、shadow-run 验证
→ 保持 deploy_023 real-robot smoke test blocked
→ 形成真机阶段可接手的交接条件
```

当前循环不得把无硬件环境下无法验证的 real-robot 行为写成通过。

## 循环主单位

- 每轮循环主单位是一个 L2 工作包。
- 主 Agent 自动选择下一个依赖满足、未 Gate 完成且有可推进任务的 L2。
- L3 是执行、验收、证据记录和 Git 原子提交的最小单位。
- L2 Gate 是进入下游 L2 或合入 `model_deploy` 的唯一依据。

## 停止边界

主 Agent 遇到以下任一情况必须停止当前循环并记录原因：

- 所选 L2 没有 ready L3，且 Gate 条件未满足。
- 同一个 L3 连续三轮 execute-review 后仍为 `FAIL_LOCAL`。
- 当前分支、工作区、远端或提交范围无法满足阶段四 Git 约束。
- 共享文件缺少 owner、串行顺序或允许修改范围。
- L2 Gate 未通过，但下游 L2 依赖该 Gate。
- `deploy_023` 缺少人工授权、急停、标定、bundle 或现场安全条件。
- 出现必须由用户决策的阻塞项。
