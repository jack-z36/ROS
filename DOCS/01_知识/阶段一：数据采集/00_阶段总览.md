# 阶段一：数据采集总览

阶段一负责把真实硬件传感器的数据稳定发布为 ROS2 topic，并通过 Octopus 录制成 raw MCAP。阶段一的产物是原始、可回放、可追溯的数据日志，不负责训练语义对齐、坐标统一、action 构造或训练格式导出。

## 阶段定位

阶段一位于项目数据链路的最前端：

```text
硬件传感器 -> ROS2 topic -> Octopus 显示与录制 -> raw MCAP
```

阶段一的成功标准是：需要的传感器 topic 能稳定发布，Octopus 能看到并录制这些 topic，生成的 raw MCAP 可被阶段二数据清洗继续消费。

## 核心边界

- 阶段一只保证原始采集链路正确。
- 阶段一不承诺 topic 之间时间同步。
- 阶段一不生成 canonical dataset、LeRobot dataset 或训练 action。
- 阶段一不把显示成功等同于录制成功；录制结果必须通过 MCAP 内容验证。
