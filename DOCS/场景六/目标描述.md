# 场景六：MCAP 数据清洗脚本与交互式启动器

## 一句话总结

将 Octopus 采集得到的 FASTUMI `.mcap` 文件，通过三个独立程序完成数据清洗、配置生成和坐标标定，三个程序通过同一入口启动。

## 核心目标

本场景包含三个程序，通过同一个启动入口统一调用：

### 程序一：数据清洗程序

从原始 MCAP 中提取夹爪的间距数据，并进行 TCP 坐标转换，输出清洗后的 MCAP 文件。

### 程序二：夹爪配置自动生成程序

自动生成夹爪相关的配置文件，核心内容为夹爪间距与像素之间的对应关系配置。

### 程序三：坐标系配置生成程序

生成坐标系相关的配置文件，核心内容包括：

- base 坐标系相对于相机原坐标系的位置和姿态
- 夹爪相对于深度相机的位置偏移

## 目标用户流程

用户理想操作流程：

1. 进入工作区：

   ```bash
   cd /home/hit/ROS
   ```

2. 启动程序：

   ```bash
   ./start_data_clean.sh
   ```

3. 在交互菜单中选择要执行的程序。

4. 查看终端展示的输入目录、输出目录、待处理文件、文件大小、输出路径、topic 检查结果等信息。

5. 确认后开始处理，并在终端查看逐文件进度与最终汇总。

## 成功标准

场景六成功时应满足：

- 三个程序均能通过同一入口调用。
- 程序一能完成 MCAP 数据清洗，输出包含原始 topic 和新增夹爪宽度 topic 的清洗后 MCAP。
- 程序二能自动生成夹爪间距与像素的对应配置。
- 程序三能生成包含 base 坐标系位姿和夹爪偏移的配置文件。
- 用户无需手写长命令，终端输出清晰可读。

## 与项目总目标的关系

场景六处于 Octopus 采集链路之后。场景三和场景四关注采集与显示，场景六关注采集产物 `.mcap` 的离线清洗和配置生成，使原始 FASTUMI 采集结果转化为更适合后续处理和验证的数据文件与配置参数。
