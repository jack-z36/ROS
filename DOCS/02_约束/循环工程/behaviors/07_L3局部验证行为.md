# L3 局部验证行为

## 消费 Agent

- 执行 sub-agent

## 本文职责

本文只约束执行 sub-agent 完成 L3 实现后如何执行局部验证。

## 不负责

本文不定义实现步骤、验收 sub-agent 结论、L2 Gate 或 Git。

## 验证规则

- L3 文件中声明的本地命令能运行时必须运行。
- `direct-local` 任务必须尽量执行 unit、import、config、mock 或 dry-run。
- 环境缺失时必须记录缺失项、影响范围和未验证内容。
- 真机相关内容只能记录 blocked 或 shadow-run，不得写成 real-robot 通过。

## 输出

- 实际执行命令。
- 运行目录。
- stdout / 日志摘要。
- 通过项。
- 未验证项及原因。

## 禁止事项

- 禁止把未运行命令写成已通过。
- 禁止伪造硬件、SDK 或 ROS 输出。
- 禁止为了通过验证扩大修改范围。
