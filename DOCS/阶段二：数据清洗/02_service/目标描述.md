# Service 目标描述

## 核心目标

Service 任务线负责阶段二五个业务场景的真实处理能力，把阶段一 raw MCAP 逐级转换为 canonical dataset，并最终支持训练格式导出。

## 五个场景

1. 场景一：从 raw MCAP 生成 cleaned MCAP，补齐夹爪宽度和 common frame 位姿语义。
2. 场景二：从 cleaned MCAP 生成 validated MCAP，处理可靠性、异常和机器人约束验证。
3. 场景三：从 validated MCAP 生成 aligned MCAP 和 alignment report。
4. 场景四：从 aligned MCAP 构建 canonical dataset。
5. 场景五：从 canonical dataset 导出模型训练格式。

## 成功标准

- 每个场景输入输出边界清晰。
- 每个场景有可追溯报告或 manifest。
- 不可训练、不可执行、不可对齐数据不会静默流入训练集。
- exporter 只消费 canonical dataset，不回头修复上游中间产物。
