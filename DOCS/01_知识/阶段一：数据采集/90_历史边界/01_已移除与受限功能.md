# 已移除与受限功能

本页记录阶段一已移除的功能和受限用法，避免后续工作重走老路或误用。

## 定位

本页是"不要再做"和"用了要小心"的清单。这些功能曾存在或受限，记录其边界有助于后续开发决策。

## 已移除的功能（gopro_camera_launch）

`gopro_camera_launch` 包经历了收敛，以下功能已从包中移除（见 `store.md`）：

| 已移除功能 | 原职责 | 移除原因 |
|---|---|---|
| `image_topic_relay.py` | 图像 topic 中转 | 不再需要中转，Octopus 直接订阅 |
| `external_pose_bridge.py` | 外部位姿桥接 | 位姿由 Baton Mini 直接发布，无需桥接 |
| `image_activity_monitor.py` | 图像活跃度监控 | 不在采集层维护监控 |
| `sync_monitor.py` | 同步监控 | 阶段一不负责时间同步 |
| 静态 TF | 坐标系静态变换 | TF 发布不属于采集层职责 |
| `ros2 bag record -s mcap` / mcap_writer | rosbag 录制 | 录制统一由 Octopus 录制链路负责 |

移除后的结论：`gopro_camera_launch` 已收敛为一个 **GoPro-only（实为 v4l2）的 ROS2 启动包**，只负责启动 `v4l2_camera_node`，不再承担中转、监控、TF、录制等职责。

## 受限用法

以下功能存在但使用时需注意限制：

### Baton Mini 200Hz fast_odom

- **约束**：在高振动场景下不建议使用 200Hz fast_odom，可能输出不稳定位姿。
- **缓解**：Octopus 录制链路已对 fast_odom 按 60Hz 节流（见 `10_数据流与产物/02_raw_MCAP产物语义.md`）。

### Baton Mini 固件版本

- **约束**：设备固件版本必须 > 2025-03-17，否则协议不兼容。
- **影响**：使用旧固件的设备无法正常通信，需先升级固件。

### 左右相机的独立 scope

- **约束**：左右两路 v4l2 相机必须通过独立进程/scope 启动，防止参数串扰。
- **原因**：launch 用 `OpaqueFunction` 立即解析参数，若共享 scope 可能导致左右实例参数互相覆盖。
- **实现**：通过 `start_all_sensor.sh` 总入口为左右相机分别启动独立进程。

### 触觉驱动 strict_identity 模式

- **约束**：`strict_identity=true` 时，若 `hardware_identity_map.yaml` 中无任何配置的 UID target，节点会致命错误退出。
- **影响**：新增传感器或更换硬件时，必须先更新身份映射表，否则驱动无法启动。
