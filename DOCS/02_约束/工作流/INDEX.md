# 工作流约束索引

本主题收纳必须遵守的工作流和模板资产。工作流属于约束体系，不放入工程区。

## 工作流入口

- `阶段二开发工作流/阶段二开发范式.md`
- `阶段四开发工作流/阶段四模型部署程序改造工作流.md`

## 模板入口

- `阶段二开发工作流/attachments/L2能力模块说明文件模板.md`
- `阶段二开发工作流/attachments/L3微元任务文件模板.md`
- `阶段二开发工作流/attachments/templates/`
- `阶段四开发工作流/attachments/L3微元改造任务模板.md`

## 读取规则

- 只有任务进入对应工作流时才读取工作流全文。
- 只有准备生成正式 L2/L3 文档时才读取模板全文。
- 阶段四模型部署程序改造不得直接套用阶段二 L2/L3 模板；阶段二 L3 模板只能作为结构参考，正式阶段四 L3 必须使用阶段四专用模板。
- 工作流中的通用强制规则应逐步抽取到对应原子约束文件；模板资产保留在本主题下。
