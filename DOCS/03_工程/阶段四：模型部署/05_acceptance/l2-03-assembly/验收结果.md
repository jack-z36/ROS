## 测试输入

- 鱼眼图像消息或等价 mock 图像数据。
- 左右 TCP `PoseStamped`：位置、四元数姿态。
- 左右 gripper `Float32` width。
- 缺失 TCP pose、缺失图像、触觉关闭三类负例。
- 与目标 bundle 一致的 batch key 期望。

## 观察点

- dry-run stdout 或日志中出现 snapshot 生成成功记录。
- encoded state 维度为 16D。
- batch 中图像 key、state key 和 shape 与目标模型输入一致。
- missing fields 场景中出现节流 missing 日志，不进入可发布 action 的路径。
- 运行过程中不出现 `/pi05/policy_action` 或任何 command topic 的真实发布。

## 通过现象

- 完整输入下生成 `ObservationSnapshot`。
- `encoded_state` 或 batch state shape 明确为 16D。
- 关闭 tactile 后仍能生成第一版 snapshot。
- 缺 TCP pose 或关键图像时不会伪造 snapshot，日志能说明缺失字段。
- dry-run 不连接硬件、不启动驱动、不发布真机命令。

## 失败现象与排查入口

- snapshot 不生成：优先检查订阅 topic 名、collector 字段缓存和 config。
- state 不是 16D：优先检查 state codec 和 `_build_batch`。
- missing fields 被静默忽略：优先检查 observation_collector 的缺失策略。
- dry-run 发布命令：立即停止，检查 deploy_node mode gate 和 publish 入口。
