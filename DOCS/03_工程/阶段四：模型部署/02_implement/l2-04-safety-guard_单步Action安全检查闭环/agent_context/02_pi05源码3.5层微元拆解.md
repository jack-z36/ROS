# Pi0.5 源码 3.5 层微元拆解：L2-04

## 1. 参考范围与降权规则

Pi0.5 只提供结构参考，不定义 ACT L2-04 边界。当前边界以 L1 Markdown 和用户确认的 A/B/C 体系为准。

| Pi0.5 路径 | 对象 | 可得到的结构启发 | ACT 复用判断 |
|---|---|---|---|
| `pi05/deploy/src/pi05/deploy/runtime/safety_guard.py` | `SafetyGuard`、`SafetyResult`、`filter_action` | 一个 config 驱动 guard、单入口结果、anchor 优先级 | 结构复用 |
| 同上 | `_clamp_delta` | target 相对 anchor 的限步思想 | 仅参考；逐轴关节 clip 不复用 |
| 同上 | `_delta_anchor` | previous action 优先、observation 兜底 | 结构复用；ACT 无基准改为 reject |
| 同上 | `_build_joint_limits`、`JointLimitSpec` | Pi0.5 关节绝对限位 | 不复用 |
| `pi05/deploy/src/pi05/deploy/runtime/control_loop.py` | `tick`、`_fallback`、`last_command` | Safety 的调用位置、fallback 状态所有权 | 参考理解；归 L2-06 |
| `pi05/deploy/src/pi05/deploy/ros_nodes/pi05_bridge_node.py` | 硬件前二次过滤 | 防御纵深 | 参考理解；归 L2-05 |

## 2. Pi0.5 微元与 ACT 映射

| Pi0.5 微元 | 3.5 类型 | 输入/输出或状态 | ACT 映射 | 风险 |
|---|---|---|---|---|
| `SafetyResult` | 数据 | Pi0.5 旧字段 action/accepted/reason | C1-C3/C5，改为 status + findings | 不能只保留 bool，调整原因会丢失 |
| `SafetyGuard` | 3.25 class | config，重复同步调用 | A1 | 不得把它放进 ACT runtime；ACT 是 service |
| `filter_action` | 编排函数 | action + anchor → result | B1 | ACT 需多层 B 编排，不能继续是大函数 |
| `_clamp_delta` | 计算函数 | 关节 target/anchor → component clip | C10/C11，改为几何投影 | 逐轴 clip 不限制三维总位移 |
| `_delta_anchor` | 计算函数 | previous/observation → anchor | C4/C9 | previous target 不能冒充实测 pose |
| `_build_joint_limits` | 数据/计算 | config → joint limits | 不复用 | TCP action 无关节空间含义 |
| `ControlLoop.last_command` | 内部状态更新 | 跨 tick 上一次命令 | L2-06 `previous_safe_action` | L2-04 不可持有该状态 |
| `ControlLoop._fallback` | 编排函数 | findings/policy → hold/stop | L2-06 | L2-04 只返回 REJECTED |
| bridge 二次过滤 | 计算/IO 边界 | driver target | L2-05 | 不把硬件 gate 塞进 L2-04 |

Pi0.5 中不存在 ACT 所需的 C8 四元数合法化、C11 旋转限步、C12-C13 夹爪同域限步，也没有 A/B/C 分层；这些是 ACT 新设计。

## 3. Pi0.5 class 封装盘点

| class | state | 打包微元 | 生命周期/并发 | 为什么是 class | ACT 建议 |
|---|---|---|---|---|---|
| `SafetyGuard` | config、joint limits | 检查链、anchor、delta | 启动创建，tick 同步调用，无可变业务状态 | 复用静态 policy | A1，持有 immutable SafetyConfig，不保留 joint limits |
| `SafetyResult` | 无 | frozen 返回数据 | 单次调用 | 跨模块契约 | C5；连同 C1-C3 放 `types/` |
| `ControlLoop` | last command、chunk、fallback policy | tick/fallback/state update | timer 驱动 | 需要跨 tick 状态 | 保持 L2-06，不迁入 L2-04 |

## 4. 不可照搬项

- Pi0.5 的 14D 关节空间、关节绝对限位、`max_joint_delta_rad` 和逐分量 clip 不进入 ACT。
- Pi0.5 `last_command` 在 ControlLoop 中更新；ACT 仍由 L2-06 在 L2-05 接受输出后更新。
- Pi0.5 只在 observation 缺失时回退 previous；ACT 需要明确 reference 来源，并在两者皆缺时拒绝。
- Pi0.5 bridge 安全和 hardware gate 属输出边界；ACT 仍由 L2-05承担。

## 5. 参考结论

结构复用仅限：`A1 → B1 → 结果` 的单入口 Guard 模式、anchor 优先级模式、L2-06调用位置。所有数值空间、几何算法、夹爪域和状态更新语义必须按 ACT 重新实现。
