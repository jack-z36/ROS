# 循环上下文加载规则

## 消费 Agent

- 全部 Agent

## 本文职责

本文只定义 Ralph / OpenCode 循环中主 Agent、执行 sub-agent、验收 sub-agent 和 L2 Gate agent 的最小上下文加载顺序。

## 不负责

本文不承载各角色完整行为规则、当前阶段四状态、L3 任务正文、验收证据或 Git 状态正文。

## 主 Agent 初始加载

每次 Ralph / OpenCode 主 Agent 循环必须按顺序读取：

1. `AGENTS.md`
2. `DOCS/02_约束/上下文加载/08_循环工程加载规则.md`
3. `DOCS/02_约束/循环工程/INDEX.md`
4. `DOCS/02_约束/循环工程/behaviors/INDEX.md`
5. `DOCS/02_约束/Git协作/Git操作规则.md`
6. `DOCS/02_约束/Git协作/阶段四：模型部署 Git操作规则.md`
7. `DOCS/02_约束/循环工程/00_循环目标与边界.md`
8. `DOCS/02_约束/循环工程/01_主Agent行为约束.md`
9. `DOCS/03_工程/阶段四：模型部署/00_status/INDEX.md`

主 Agent 读取 `01_主Agent行为约束.md` 后，必须按其中清单继续读取对应 `behaviors/` 原子文件。随后按 `00_status/INDEX.md` 读取状态摘要和目标 L2 的 dispatch、验收结果、Git 同步状态。

Git 规则必须在任何分支判断、工作区检查、提交、push、merge 或 L2 Gate 合入判断之前完成加载。

## 执行 Sub-Agent 加载

执行 sub-agent 只读取：

1. `AGENTS.md`
2. `DOCS/02_约束/循环工程/02_执行SubAgent行为约束.md`
3. `02_执行SubAgent行为约束.md` 中列出的 `behaviors/` 原子文件
4. 被分配的单个 L3 文件
5. 该 L3 文件列出的必读上下文和必读代码
6. 对应验收卡片中的通过标准

## 验收 Sub-Agent 加载

验收 sub-agent 只读取：

1. `AGENTS.md`
2. `DOCS/02_约束/循环工程/03_验收SubAgent行为约束.md`
3. `03_验收SubAgent行为约束.md` 中列出的 `behaviors/` 原子文件
4. 被分配的单个 L3 验收卡片
5. 对应 L3 文件
6. 执行摘要、允许查看的 diff、日志和命令输出

## L2 Gate Agent 加载

L2 Gate agent 只读取：

1. `AGENTS.md`
2. `DOCS/02_约束/循环工程/04_L2Gate行为约束.md`
3. `04_L2Gate行为约束.md` 中列出的 `behaviors/` 原子文件
4. 目标 L2 dispatch
5. 目标 L2 整体验收卡片
6. 目标 L2 `验收结果.md`
7. 目标 L2 全部 L3 验收反馈日志
8. `00_status/git_sync_status.md`
9. `00_status/hardware_block_status.md`

## 禁止默认加载

- 禁止主 Agent 在启动阶段加载全部 L3 正文。
- 禁止执行 sub-agent 加载其他 L2 / L3 的任务正文。
- 禁止验收 sub-agent 加载无关源码或修改任务状态。
- 禁止任何 Agent 默认读取 `DOCS/98_archive/` 或 `DOCS/99_learning/`。
