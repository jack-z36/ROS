# 场景四输出程序与文件

本文记录场景四“修改 Octopus UI 展示订阅 topic 与目标数据可视化”已经形成或依赖的具体程序、文件地址和功能。

## 输出清单

| 类型 | 地址 | 功能 |
| --- | --- | --- |
| Octopus GUI 可执行文件 | `install/octopus/lib/octopus/octopus` | 场景四最终运行的 GUI 程序；展示 8 个目标 topic、GoPro 图像、位姿和触觉数据。 |
| Octopus 包内架构文档 | `src/data_collection/VTLA_octopus-master/octopus/octopus_architecture.md` | 说明 Octopus 显示链路、录制链路、配置链路、依赖、启动方式和 UI 面板逻辑。 |

| Octopus 主窗口 | `src/data_collection/VTLA_octopus-master/octopus/src/mainwindow.cpp` | 创建主显示区、创建 ROS2 display subscriptions，并把 8 个目标 topic 路由到对应 UI 面板。 |
| Octopus 主窗口头文件 | `src/data_collection/VTLA_octopus-master/octopus/src/mainwindow.h` | 声明主窗口中新增或调整的显示面板成员和订阅管理接口。 |

| 触觉面板头文件 | `src/data_collection/VTLA_octopus-master/octopus/src/pages/pressure-panel.h` | 声明 `PressureDockWidget`。 |

## 场景四目标显示输出

| 显示区域 | topic | 功能 |
| --- | --- | --- |
| Left GoPro | `/gopro_left/image_raw` | 显示左手 GoPro 实时图像、FPS 和分辨率。 |
| Right GoPro | `/gopro_right/image_raw` | 显示右手 GoPro 实时图像、FPS 和分辨率。 |
| Left Pose | `/baton_mini_left/fast_odom` | 显示左手位姿数值和 xyz 曲线。 |
| Right Pose | `/baton_mini_right/fast_odom` | 显示右手位姿数值和 xyz 曲线。 |
| Left Tactile | `/pressure/left_hand/gripper_1`、`/pressure/left_hand/gripper_2` | 显示左手两路触觉热力图和统计值。 |
| Right Tactile | `/pressure/right_hand/gripper_1`、`/pressure/right_hand/gripper_2` | 显示右手两路触觉热力图和统计值。 |
| Operation topic 列表 | 8 个目标 topic | 让操作者直接查看并勾选全部录制 topic。 |

## 使用边界

- 本场景修改显示和操作体验，但不改变 MCAP 录制器的职责边界。
- 每次 UI 改动后仍需回归场景三：Start/Stop 后检查 MCAP 是否包含 8 个目标 topic。
- 如果 GoPro 面板不显示，应先区分是源头 ROS topic 未发布，还是 Octopus 订阅/显示链路问题。
