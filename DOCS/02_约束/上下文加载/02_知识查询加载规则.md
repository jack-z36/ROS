# 知识查询加载规则

## 适用范围

用户只要求解释项目、阶段、模块、数据流、架构或概念原理，不要求修改代码或文档。

## 触发信号

“解释”“梳理原理”“这个模块是什么”“数据流怎么走”“某阶段目标是什么”。

## 上下文加载顺序

1. 根据问题定位阶段或主题。
2. 读取 `DOCS/01_知识/<阶段>/` 下相关主题页。
3. 只有问题涉及当前任务推进、L2/L3、执行记录或 debug 证据时，才读取 `DOCS/03_工程/` 对应阶段目录。
4. 只有问题涉及规则边界时，才读取 `DOCS/02_约束/` 对应规则。

## 必读入口

- 相关阶段知识主题页。

## 禁止默认读取

- `DOCS/98_archive/`
- `DOCS/99_learning/`
- `DOCS/03_工程/` 全目录扫读

## 阻断条件

- 用户要求解释归档或学习资料，但未明确点名具体资料路径。

## 输出要求

回答必须区分“当前权威知识”和“历史参考/推断”。
