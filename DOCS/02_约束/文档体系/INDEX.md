# 文档体系约束索引

本目录收纳 DOCS 文档体系本身的治理规则。任何调整 DOCS 目录、迁移文档、修改路由入口或归档学习资料前，先读取本索引并按任务读取对应原子规则。

## 规则入口

| 任务 | 必读规则 |
|---|---|
| 调整 DOCS 目录结构 | `文档分类与目录规范.md` |
| 从旧文件拆分、合并、迁移语义 | `语义微元迁移规范.md` |
| 修改 `AGENTS.md` 或其他路由入口 | `路由文档纯度规范.md`、`AGENTS维护规则.md` |
| 移动历史资料、学习笔记或旧快照 | `归档与学习资料隔离规范.md` |

## 统一要求

- 文档迁移单位是语义微元，不是旧文件。
- 路由入口不得承载项目知识、工程进度或规则正文。
- 约束文件必须显式注明适用范围。
- `DOCS/98_archive/` 和 `DOCS/99_learning/` 默认禁止作为 Agent 上下文加载入口。
