# 阶段二场景二：输出程序与文件

## 预期输出程序

| 程序/模块 | 功能 | 输入 | 输出 |
| --- | --- | --- | --- |
| 异常值检测器 | 在 cleaned MCAP 原始序列中检测位姿、触觉和夹爪的缺失、非法值、跳变和异常变化片段 | cleaned MCAP 原始序列 + 检测规则配置 | 统一可靠性问题记录、异常时间段、点级证据和处理建议 |
| 数据补全器 | 对异常值检测器标记为可修复的片段进行插值、邻近保持或其他可追溯补全 | 原始序列 + 可靠性问题记录 + 处理建议 | 补全后连续序列、不可补全片段标记和修复日志 |
| 位姿滤波器 | 对已完成明显坏点处理的 arm-base TCP pose 应用滤波，降低高频噪声且保留真实运动趋势 | 补全后 arm-base TCP pose 序列 + 不可补全片段标记 | 滤波后 arm-base TCP pose 序列与滤波差异摘要 |
| 触觉滤波器 | 对已完成明显坏点处理的触觉压力矩阵应用尖峰优先滤波，降低单帧或短段异常尖峰且保留真实接触变化 | 补全后触觉序列 + 不可补全片段标记 | 滤波后触觉序列与触觉滤波报告 |
| MCAP_A 生成器 | 将补全和滤波后的位姿、触觉、夹爪等主数据写入 MCAP_A | cleaned MCAP 原文件 + 补全/滤波后序列 + 不可补全片段标记 | MCAP_A 和写出摘要 |
| IK 求解与 MCAP_B 生成器 | 将 MCAP_A 中的 arm-base TCP pose 转换为关节角诊断数据 | MCAP_A + 机器人运动学参数 | MCAP_B（当前不输出）、IK 成功/失败时间段和求解摘要 |
| 关节限制检查器 | 检查 MCAP_B 中关节角、速度、加速度和 workspace 是否在安全范围 | MCAP_B + 机器人约束参数 | 关节约束问题时间段和检查摘要 |
| MuJoCo 仿真验证器 | 在仿真中播放或检查 MCAP_B 轨迹，检测碰撞、接触、力矩和稳定性问题 | MCAP_B + MuJoCo 模型 + 仿真参数 | MuJoCo 仿真问题时间段和仿真摘要 |
| Parquet 标注与验证报告生成器 | 汇总所有问题时间段，生成统一标注和验证报告 | 各模块问题记录、摘要和产物索引 | `annotations.parquet`、验证报告和 validated 产物摘要 |

## 预期输出文件

| 文件 | 格式 | 说明 |
| --- | --- | --- |
| MCAP_A / validated 主 MCAP | `.mcap` | 滤波补全后的主数据 MCAP，位姿 topic 为 arm-base（`arm_base_tcp_pose`，frame_id per RM65 base），契约见 `L2数据定义/McapA.md`，保持相同 topic 结构 |
| 异常值报告 | `.json` | 记录统一可靠性问题、异常时间段、点级证据和处理建议 |
| IK 可行性报告 | `.json` | 记录 IK 求解失败（当前不输出 MCAP_B，保留以备未来）、关节限制违规的位置 |
| MuJoCo 仿真报告 | `.json` | 记录仿真中发现的问题段和原因 |
| 修复日志 | `.json` | 记录每个修复点的原始值、修复后值和修复方法 |
| annotations.parquet | `.parquet` | 汇总异常、不可补全、IK、关节约束和仿真问题时间段 |
