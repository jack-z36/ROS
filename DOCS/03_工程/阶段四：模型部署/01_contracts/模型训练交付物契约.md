# 模型训练交付物契约

关联部署契约：[[TO-BE Contract]]


## 一句话要求

请交付一个可部署的 `deploy_bundle` 目录，而不是只交付训练 checkpoint、wandb 链接或单个权重文件。

部署侧期望拿到：

```text
deploy_bundle/
├── manifest.json
├── normalizers.json
├── experiment_config.yaml
├── adapter/
│   ├── adapter_model.safetensors
│   └── adapter_config.json
└── tactile_preprocess.json   # 如果训练使用了触觉预处理，才需要
```

部署侧会把该目录放到 4090 推理主机本地，并在部署配置中填写：

```yaml
bundle:
  bundle_dir: /home/hit/ROS/model_bundles/current
```

## 必须交付的文件

| 文件 / 目录 | 是否必须 | 作用 | 验收要求 |
|---|---:|---|---|
| `manifest.json` | 是 | 描述模型输入输出契约、相机 key、state/action 维度、chunk size、base model 路径等。 | 必须能说明该 bundle 是什么模型、吃什么 observation、输出什么 action。 |
| `normalizers.json` | 是 | 保存训练数据统计得到的 state/action 归一化与反归一化参数。 | `state` / `action` 的维度必须与 `manifest.json` 一致。 |
| `experiment_config.yaml` | 是 | 保存重建模型结构所需的训练配置。 | 部署程序能用它重建 Pi0.5 + LoRA 结构。 |
| `adapter/adapter_model.safetensors` | 是 | 训练得到的 LoRA adapter 权重。 | 文件存在且可被 `safetensors` 加载。 |
| `adapter/adapter_config.json` | 是 | LoRA adapter 配置。 | 与 `adapter_model.safetensors` 匹配。 |
| `tactile_preprocess.json` | 视情况 | 如果训练输入包含触觉预处理，该文件描述触觉预处理参数。 | 如果模型使用触觉但缺该文件，视为交付不完整。 |

## 不要只交付这些东西

| 只交付这个 | 问题 |
|---|---|
| 单个 `.safetensors` 权重 | 部署侧不知道模型结构、normalizer、camera names、action schema。 |
| 训练 checkpoint 目录 | checkpoint 通常包含 optimizer / scheduler / trainer 状态，不等于部署 bundle。 |
| wandb run 链接 | 不能作为部署输入。 |
| LeRobotDataset 目录 | 数据集不是部署侧直接加载的模型产物。 |
| 只给 HuggingFace repo id | 真机部署需要可复现、可离线的本地 bundle。 |

## 请直接按这个目录交付

```text
pi05_rm65_v2/
├── manifest.json
├── normalizers.json
├── experiment_config.yaml
├── adapter/
│   ├── adapter_model.safetensors
│   └── adapter_config.json
├── tactile_preprocess.json
└── RELEASE.md
```

其中 `tactile_preprocess.json` 只有在模型训练时使用了触觉预处理才需要。

## `manifest.json` 示例

请让 `manifest.json` 直接写清楚模型输入输出契约。示例：

```json
{
  "schema_version": 1,
  "created_at_utc": "2026-06-18T12:00:00Z",
  "project": {
    "project_name": "pi05_rm65_deploy",
    "run_name": "pi05_rm65_v2"
  },
  "model": {
    "pretrained_path": "lerobot/pi05-base",
    "dtype": "bfloat16",
    "chunk_size": 30,
    "n_action_steps": 30,
    "state_dim": 0,
    "action_dim": 14,
    "max_action_dim": 14
  },
  "observation": {
    "fps": 30,
    "image_size": 224,
    "cameras": [
      "left_gripper_fisheye",
      "right_gripper_fisheye"
    ],
    "features": {
      "observation.images.left_gripper_fisheye": {
        "dtype": "image",
        "shape": [3, 224, 224]
      },
      "observation.images.right_gripper_fisheye": {
        "dtype": "image",
        "shape": [3, 224, 224]
      },
      "observation.state": {
        "dtype": "float32",
        "shape": ["state_dim"],
        "semantic": [
          "left_tcp_xyz_m[3]",
          "left_tcp_rpy_rad[3]",
          "left_gripper_angle[1]",
          "right_tcp_xyz_m[3]",
          "right_tcp_rpy_rad[3]",
          "right_gripper_angle[1]",
          "tactile_l1_flattened",
          "tactile_l2_flattened",
          "tactile_r1_flattened",
          "tactile_r2_flattened"
        ]
      },
      "action": {
        "dtype": "float32",
        "shape": [14],
        "semantic": [
          "left_tcp_xyz_m[3]",
          "left_tcp_rpy_rad[3]",
          "left_gripper_angle[1]",
          "right_tcp_xyz_m[3]",
          "right_tcp_rpy_rad[3]",
          "right_gripper_angle[1]"
        ]
      }
    },
    "tactile_preprocess_path": "tactile_preprocess.json"
  },
  "artifacts": {
    "adapter_dir": "adapter",
    "normalizers_path": "normalizers.json",
    "experiment_config_path": "experiment_config.yaml"
  }
}
```

如果没有使用触觉，则写成：

```json
{
  "observation": {
    "tactile_preprocess_path": null
  }
}
```

## `experiment_config.yaml` 示例

请把能重建模型结构的训练配置放进来。示例：

```yaml
model:
  policy_type: pi05
  pretrained_path: lerobot/pi05-base
  dtype: bfloat16
  chunk_size: 30
  n_action_steps: 30
  state_dim: 0
  action_dim: 14
  max_action_dim: 14
  lora:
    enabled: true
    r: 16
    alpha: 32
    dropout: 0.05
    target_modules: all-linear

data:
  dataset_version: pi05_rm65_clean_v2
  fps: 30
  image_size: 224
  cameras:
    - left_gripper_fisheye
    - right_gripper_fisheye

runtime_recommendation:
  task: "put the object into the container"
  device: cuda:0
  dtype: bfloat16
  chunk_size: 30
```

## `adapter/adapter_model.safetensors`

这是二进制权重文件，不需要人工写内容。交付时只需要确认文件存在：

```text
adapter/adapter_model.safetensors
```

部署程序会从这里加载训练得到的 LoRA 权重。

## `tactile_preprocess.json` 示例

如果模型使用触觉，请交付类似下面的文件：

```json
{
  "enabled": true,
  "sensors": {
    "l1": {
      "rows": 6,
      "cols": 15,
      "flatten_order": "row_major",
      "source_topic": "/pi05/observation/tactile/l1"
    },
    "l2": {
      "rows": 6,
      "cols": 15,
      "flatten_order": "row_major",
      "source_topic": "/pi05/observation/tactile/l2"
    },
    "r1": {
      "rows": 6,
      "cols": 15,
      "flatten_order": "row_major",
      "source_topic": "/pi05/observation/tactile/r1"
    },
    "r2": {
      "rows": 6,
      "cols": 15,
      "flatten_order": "row_major",
      "source_topic": "/pi05/observation/tactile/r2"
    }
  },
  "normalization": {
    "type": "dataset_stats",
```

```json

  }
}
```

```text

```

```yaml
bundle:
```
