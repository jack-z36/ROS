# Service 背景信息

阶段二 service 任务线处在 Runtime 和数据存储之间。Runtime 负责选择、编排和记录运行过程；Service 负责真实业务逻辑。

阶段二数据主链路为：

```text
raw MCAP
  -> cleaned MCAP
  -> validated MCAP
  -> aligned MCAP
  -> canonical_dataset_mcap
  -> exports
```

五个场景按上下游关系顺序推进。每个场景可以独立开发和验证，但必须遵守 `00_架构与路线图/阶段二产物架构设计.md` 中的产物契约和分层约束。

真实数据产物默认位于：

`asset/阶段二：数据清洗/`
