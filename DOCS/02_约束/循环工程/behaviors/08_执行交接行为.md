# 执行交接行为

## 消费 Agent

- 执行 sub-agent

## 本文职责

本文只约束执行 sub-agent 如何在 L3 实现和局部验证后交接结果。

## 不负责

本文不定义实现步骤、验收结论、dispatch 状态更新或 Git。

## 必须交接内容

执行摘要必须包含：

- 读取的 L3、Contract、L2 和代码。
- 任务身份校验结论。
- 修改文件清单。
- 新增或修改的函数、类、配置、测试或脚本。
- 实际验证命令和结果。
- 已完成成功标准。
- 未验证项。
- 是否影响 dry-run、shadow-run、real-policy 或 real-robot。
- 回滚方式。
- 明确没有做的事项。

## 写入范围

执行 sub-agent 只允许更新：

- 当前 L3 任务文件中的执行摘要和成功标准。
- L3 明确允许修改的代码、测试、脚本或文档。
- L3 明确要求登记的验收准备材料。
