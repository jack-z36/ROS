# AGENTS 维护规则

## 适用范围

- 阶段：全局
- 任务模式：文档体系维护、路由入口维护
- 适用对象：仓库根 `AGENTS.md`
- 不适用对象：普通知识文档、工程执行记录

## 强制规则

仓库只保留一个全局 `AGENTS.md`，位置固定在仓库根目录。

根 `AGENTS.md` 必须采用任务类型级路由。每个任务类型只写：

- 一句话说明
- 对应上下文加载规则路径

当前任务类型固定为：

1. 文档体系维护
2. 知识查询 / 原理解释
3. 非具体编程规划
4. L3 微元任务执行
5. Debug / Bugfix
6. 普通代码维护
7. Git 同步
8. 循环工程

## 禁止事项

- 禁止在 `DOCS/` 子目录放局部 `AGENTS.md`。
- 禁止把根 `AGENTS.md` 写成项目百科、执行手册或阶段状态文档。
- 禁止让根 `AGENTS.md` 默认路由到 `98_archive` 或 `99_learning`。

## 维护规则

新增任务类型前，必须先新增对应 `DOCS/02_约束/上下文加载/<编号>_<任务名>加载规则.md`，再更新根 `AGENTS.md`。
