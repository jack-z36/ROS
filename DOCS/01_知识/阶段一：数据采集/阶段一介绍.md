# 阶段一：数据采集

## 1. 阶段目标

**本阶段定位**：阶段一位于项目数据链路的最前端，负责把物理世界的传感器信号采集为可回放、可追溯的原始数据日志。这是整个机器人学习项目的数据基础。

**本阶段输入**：物理传感器硬件信号
- GoPro 相机（经 USB 采集卡）：提供 RGB 图像
- Baton Mini 双目 VIO 相机：提供位姿与运动数据
- 华威科灵巧手压力传感器（4 串口）：提供触觉压力数据

**本阶段输出**：raw MCAP 文件
- 包含传感器原始的 CDR 序列化字节流
- 包含双时间戳（`logTime` 和 `publishTime`）
- 默认包含 8 个核心 topic（2 图像 + 2 位姿 + 4 触觉）
- 支持 ZSTD 压缩

**支撑下游**：
- 阶段二（数据清洗）：读取 raw MCAP 后生成 cleaned MCAP、MCAP_A、aligned MCAP 和训练格式桥接产物
- 阶段三/四（模型训练/部署）：共享同一套消息契约，特别是触觉 PressureFrame

**本阶段不负责**：
- 不承诺 topic 之间的时间同步（跨 topic 对齐是阶段二的工作）
- 不生成训练语义产物（不产出 canonical dataset、LeRobot dataset、训练 action 或归一化数据）
- 不混入清洗/对齐逻辑（不滤波、不对齐、不构造坐标系统一）
- 不把"显示成功"等同于"录制成功"（Octopus 的显示链路与录制链路是两条相互独立的 ROS 节点）

## 3. 已有产物

**代码入口**：
- 工作空间根目录：`01-doing/ROS/`
- 传感器驱动代码：`src/data_collection/`
- 启动脚本：`start_all_sensor.sh`、`start_baton_gopro.sh`、`start_octopus.sh`

**数据路径**：
- raw MCAP 输出目录：`01-doing/ROS/mcap/`（由 `scanner.json` 的 `recording.mcap.path` 配置）
- 日志目录：`01-doing/ROS/log/start_all_sensor/`

**配置文件**：
- Octopus 录制配置：`~/.config/scanner.json`
- 压力传感器配置：`src/data_collection/hwk_pressure_driver/config/pressure_sensors.yaml`
- 硬件身份映射：`01-doing/ROS/config/hardware_identity_map.yaml`
- 所有传感器节点配置：`01-doing/ROS/config/all_sensor_nodes.yaml`

**运行命令**：
```bash
# 启动所有传感器节点
cd 01-doing/ROS
./start_all_sensor.sh

# 仅启动 Baton Mini 与 GoPro，不启动触觉节点
./start_baton_gopro.sh

# 启动 Octopus 录制 GUI
./start_octopus.sh

# 仅启动 GoPro
./start_gopro_only.sh

# 编译工作区
source /opt/ros/jazzy/setup.bash
colcon build
```

**输出结果**：
- 8 个核心 topic 的 raw MCAP 文件
- 支持 ZSTD 压缩
- 文件命名：录制开始时生成时间戳命名的 `.mcap` 文件

**注意事项**：
1. **显示与录制分离**：Octopus 的显示链路与录制链路是两个独立的 ROS 节点，看到画面不代表已经录进 MCAP
2. **fast_odom 节流**：`fast_odom` topic 在录制时按 60Hz 节流（原始 200Hz），这是有意设计
3. **schema 维护**：新增消息类型时必须在 `McapRecorder::get_message_definition()` 中补上手写 schema
4. **串口权限**：Linux 下需要把当前用户加入串口设备组（`sudo usermod -a -G dialout $USER`）
5. **ROS 发现范围**：默认设置为 LOCALHOST，验证时需要先执行 `ros2 daemon stop`

## 5. 快速上手指南

### 5.1 环境准备
```bash
# 安装系统依赖
sudo apt install python3-serial python3-yaml
sudo apt install ros-jazzy-v4l2-camera v4l-utils

# 安装 Qt 6.11.0（从 Qt 官网下载安装器）
# 安装 FFmpeg 8.0
sudo add-apt-repository ppa:ubuntuhandbook1/ffmpeg8
sudo apt install ffmpeg
```

### 5.2 编译与启动
```bash
# 进入工作空间
cd 01-doing/ROS

# 编译
source /opt/ros/jazzy/setup.bash
colcon build

# 启动所有传感器
./start_all_sensor.sh

# 启动 Octopus 录制 GUI
./start_octopus.sh
```

### 5.3 验证数据流
```bash
# 查看 topic 列表
ros2 topic list

# 查看特定 topic 的频率
ros2 topic hz /gopro_left/image_raw

# 查看压力数据
ros2 topic echo /pressure/left_hand/gripper_1
```

### 5.4 常见问题
1. **看不到 topic**：检查 ROS 发现范围，执行 `ros2 daemon stop` 后重试
2. **串口权限错误**：执行 `sudo usermod -a -G dialout $USER` 并重新登录
3. **Octopus GUI 无法显示**：检查 DISPLAY 环境变量是否设置
4. **录制文件为空**：确保在 Operation 面板勾选了 topic 并点击了 Start
