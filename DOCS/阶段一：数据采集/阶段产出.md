# 阶段一：数据采集阶段产出

## 文档定位

本文件记录阶段一在任务执行过程中已经形成或依赖的软件资产，包括程序、脚本、launch、配置和关键源码模块。

阶段一最终目标和最终数据产物写在 `阶段目标描述.md` 中；本文件不重复描述 raw MCAP 的数据语义，只回答三个问题：

- 这个阶段有哪些可运行或可维护的软件？
- 这些软件负责什么输入和输出？
- 更详细的软件说明应该去哪里读？

## 详细信息查找规则

- 想了解某个软件“为什么存在、服务哪个目标”，先读对应场景的 `目标描述.md`。
- 想了解某个软件“怎么运行、输入输出是什么”，读对应场景的 `输出程序与文件.md`。
- 想了解某个包“内部数据流、模块职责、配置项和上下游关系”，读包内架构文档。
- 涉及 Octopus 时，必须优先读 `DOCS/Octopus_architecture.md`。
