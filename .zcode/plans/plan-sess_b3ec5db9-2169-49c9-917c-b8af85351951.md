# 上位机美化方案：迁移到 customtkinter + HIT 标识 + UMI 无本体数采

## 背景与约束（已核实）
- **当前实现**：`scripts/act_launcher.py`（502 行），纯 stdlib `tkinter`，`class ActLauncher(tk.Tk)`，所有逻辑（环境加载/启动序列/停止/轮询/日志）与 UI 耦合在单一类中。UI 无主题、无样式，全是平台默认灰底控件——这就是"丑且单调"的根因。
- **运行环境**：`/usr/bin/python3` = Python 3.12.3。`EXTERNALLY-MANAGED` 标记存在（禁止系统级 pip 安装），但 **`pip install --user` 不受限制**，落地目录 `~/.local/lib/python3.12/site-packages` 已在 sys.path 且已存在（已有 fastapi/pydantic 等）。
- **customtkinter 现状**：系统中**任何位置都未安装**，也没有 apt 包。依赖仅 `darkdetect`（`packaging` 已由系统满足）。纯 Python 包，自带主题/字体资源。
- **HIT 含义澄清**：HIT = **武汉华威科智能有限公司**（不是哈工大），要求界面把 "HIT" 三个字母作为标识放上去即可。
- **务必保留**：所有启动脚本继续用 `/usr/bin/python3`（避免落到 conda 3.13）；所有 ROS/子进程/轮询逻辑不变。

## 用户已确认的方向
1. 技术路线：**迁移到 customtkinter**（现代深色控件、圆角按钮，视觉效果最佳）
2. HIT 标识：**直接放 "HIT" 三个字母**（文字徽章，不引图片），副标题标注"武汉华威科智能有限公司"
3. 配色：**现代深色主题**

### 1. 新增 `scripts/requirements-launcher.txt`

```
customtkinter>=5.2.0
```

### 2. 修改 `scripts/install_launcher.sh`
在桌面快捷方式安装之前，新增 customtkinter 安装步骤（幂等，已装则跳过）：
```bash
echo "=== 检查 Python GUI 依赖 (customtkinter) ==="
/usr/bin/python3 -m pip install --user -r "${WORKSPACE_DIR}/scripts/requirements-launcher.txt" || {
  echo "警告：customtkinter 安装失败，界面将无法启动，请检查网络后重试。"; exit 1;
}
```
- 用 `/usr/bin/python3 -m pip`（不用裸 `pip`/`pip3`，它们指向用户 PATH 里的版本）
- 用 `--user`：绕过 PEP 668，无需 `--break-system-packages`，无需 sudo

### 3. 重写 `scripts/act_launcher.py`（核心，保留文件名与类名 `ActLauncher`）

**保持不变的部分**（框架无关，直接沿用）：
- `_load_ros_env` / `_run_start_sequence` / `_read_proc_output` / `_do_stop_system` / `_poll_sensor_status` / `_parse_sensor_status` / `_match_and_update` / `_on_exit` / `_do_stop_and_quit` 的逻辑、`SENSOR_DEFS`
- 两阶段启动（Phase1 `start_all_sensor.sh`、Phase2 `start_octopus.sh`）、10s 轮询、进程组终止策略

**改造的部分**：

(a) **基类与主题**（`__init__` 顶部）：
```python
import customtkinter as ctk
ctk.set_appearance_mode("dark")
ctk.set_default_color_theme("blue")
class ActLauncher(ctk.CTk):
```

(b) **深色主题调色板**（类常量，替换原 `STATUS_COLORS`）：
```python
COLOR_BG="#1a1b26"; COLOR_CARD="#24253a"; COLOR_CARD_2="#2e3050"
COLOR_ACCENT="#3b82f6"   # HIT 徽章 + 启动按钮主色（现代蓝）
COLOR_OK="#2ecc71"; COLOR_ERR="#e74c3c"; COLOR_WARN="#e67e22"; COLOR_DIM="#6b6f8d"
COLOR_TEXT="#e8e8f0"; COLOR_TEXT_DIM="#9aa0c0"
STATUS_COLORS = {"unknown":COLOR_DIM,"ok":COLOR_OK,"error":COLOR_ERR,"starting":COLOR_WARN}
```

(c) **顶部品牌横幅**（新增，CTkFrame，`_create_widgets` 最上方）：
- 左：**"HIT" 圆角徽章**（带强调蓝背景的小 `CTkFrame` + 白色加粗 `CTkLabel`，corner_radius 较大），徽章下方/右侧副标题 `CTkLabel` "武汉华威科智能有限公司"
- 中：主标题 `CTkLabel`（font 22pt 加粗）**"UMI 无本体数据采集系统"**
- 右：副标题 `CTkLabel`（小字）"· ACT Launcher"

(d) **传感器状态面板**（`CTkFrame` 卡片）：标题 "传感器状态"；4 行，每行 = 名称 `CTkLabel`(width 20) + 状态点 `CTkLabel`(text="●", text_color 按状态) + 描述 `CTkLabel`。

(e) **日志面板**（`CTkFrame` 卡片）：标题 "系统日志"；改用 `ctk.CTkTextbox`（深色终端风，等宽字体，`wrap="word"`）。

(f) **底部按钮栏**（`CTkFrame`）：圆角 `CTkButton`，按语义配色——
- 启动系统 → `fg_color=COLOR_OK`（绿）
- 冒烟测试 → `fg_color=COLOR_ACCENT`（蓝）
- 停止系统 → `fg_color=COLOR_ERR`（红），默认 disabled
- 退出 → `fg_color=COLOR_DIM`（灰），右对齐

(g) **API 适配**（tk→ctk 语法差异）：
- `_append_log`：`CTkTextbox` 用 `configure(state="normal"/"disabled")` + `insert("end", text)` + `see("end")`
- `_update_sensor_status`：`status_label.configure(text_color=color)`（原 `config(fg=...)`）
- `_set_buttons_running` / `_reset_to_idle`：`configure(state="normal"/"disabled")`
- 按钮状态：`ctk.NORMAL`/`ctk.DISABLED`

(h) **窗口标题**：`self.title("HIT · UMI 无本体数据采集系统")`

## 风险与回退
- **网络不可用**导致 `pip install --user` 失败：install_launcher.sh 会明确报错退出；回退方案是手动把 `customtkinter`+`darkdetect` vendor 到 `~/.local/lib/python3.12/site-packages`（本次不预先做，仅在联网失败时启用）。
- **CTkTextbox 大日志性能**：当前日志量不大，可接受；如卡顿再优化（限长/分片）。
- 配色为合理默认（深色+蓝），实施后若想换 HIT 品牌色，改 `COLOR_ACCENT` 一处即可。
