# Git 协作约束索引

## 规则入口

- `Git操作规则.md`：全局 Git 底线规则和阶段规则路由。
- `阶段二：数据清洗 Git操作规则.md`：阶段二数据清洗分支和场景专属规则。
- `阶段四：模型部署 Git操作规则.md`：阶段四模型部署 L2 分支、L2 Gate 自动同步和 `model_deploy` 合并规则。

## 读取条件

只有任务涉及 Git 状态、提交、推送、拉取、远端、分支、合并或同步时读取本主题。

如果任务属于明确阶段，读取 `Git操作规则.md` 后，必须继续读取对应阶段专属 Git 规则。

## 禁止事项

- 禁止从历史执行日志推断当前 Git 规则。
- 禁止未读取 `Git操作规则.md` 就执行 Git 写操作。
