# 阶段二场景三：执行约束

## 必读文档

每次处理本场景前，必须先阅读阶段二四个阶段级文档、阶段二 `AGENTS.md`、`02_service/` 六件套，以及本场景六件套。

## 前置条件

- 场景二已完成，validated MCAP 可用。
- 目标 topic 列表和对齐参数已确定。

## 技术约束

- 四元数插值必须使用 slerp，不能使用线性插值。
- 图像数据不做插值，只使用最近邻匹配。
- 统一时间轴的起止时间由 MCAP 中所有 topic 的时间范围共同决定。
- 对齐后的 MCAP 不能丢失原始 topic 数据，对齐信息通过 step_index 记录。

## 解耦边界

- 本场景不做 canonical dataset 的 schema 定义和 episode 构建。
- 本场景不做训练格式导出。
- 本场景不做数据质量判定（由场景四负责），只记录对齐质量。

## 验收边界

不能把以下情况算作完成：

- 只复制 MCAP，没有生成统一时间轴。
- 没有记录对齐方式和时间误差。
- 对四元数使用了线性插值。
- 没有生成 alignment_report。
