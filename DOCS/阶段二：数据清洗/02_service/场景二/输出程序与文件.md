# 阶段二场景二：输出程序与文件

## 预期输出程序

| 程序/模块 | 功能 | 输入 | 输出 |
| --- | --- | --- | --- |
| 位姿滤波器 | 对 TCP 位姿应用低通滤波，平滑高频噪声 | cleaned MCAP 位姿 topic | 滤波后位姿序列 |
| 触觉滤波器 | 对触觉数据应用低通滤波 | cleaned MCAP 触觉 topic | 滤波后触觉序列 |
| 异常值检测器 | 检测位姿跳变和触觉突变 | 滤波后数据 | 异常值标记和位置列表 |
| 数据补全器 | 对删除的异常值进行插值补全 | 原始序列 + 异常值标记 | 补全后连续序列 |
| IK 求解器 | 将 TCP 位姿转换为关节角 | TCP 位姿序列 | 关节角序列 |
| 关节限制检查器 | 检查关节角/速度/加速度是否在安全范围 | 关节角序列 | 违规标记列表 |
| MuJoCo 仿真验证器 | 在仿真中播放轨迹，检测碰撞和力矩超限 | 关节角序列 + MuJoCo 模型 | 仿真问题报告 |
| 问题数据修复器 | 修复仿真发现的问题数据段 | 问题段标记 + 原始数据 | 修复后数据 |
| 验证报告生成器 | 汇总所有检查结果 | 各模块输出 | 验证报告文件 |

## 预期输出文件

| 文件 | 格式 | 说明 |
| --- | --- | --- |
| validated MCAP | `.mcap` | 滤波补全后的 MCAP，保持相同 topic 结构 |
| 异常值报告 | `.json` | 记录检测到的异常值位置、类型和原始值 |
| IK 可行性报告 | `.json` | 记录 IK 求解失败、关节限制违规的位置 |
| MuJoCo 仿真报告 | `.json` | 记录仿真中发现的问题段和原因 |
| 修复日志 | `.json` | 记录每个修复点的原始值、修复后值和修复方法 |
