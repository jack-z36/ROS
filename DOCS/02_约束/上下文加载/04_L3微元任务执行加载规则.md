# L3 微元任务执行加载规则

## 适用范围

用户明确要求执行某个 L3 微元任务文件。

## 触发信号

用户给出具体 L3 文件路径并要求执行。

## 上下文加载顺序

1. 读取用户指定的 L3 文件。
2. 校验用户指定路径、实际读取路径、文件名编号和正文 `L3 编号` 一致。
3. 读取 L3 文件列出的必读任务文档、约束文档、相关 L3 和代码文件。
4. 读取阶段二任务体系中与 L3 执行相关的规则。
5. 按 L3 的允许修改范围进入代码和测试。

## 必读入口

- 用户指定 L3 文件
- `DOCS/02_约束/阶段二任务体系/L3任务身份校验规则.md`
- `DOCS/02_约束/阶段二任务体系/L3调度元数据规则.md`
- `DOCS/02_约束/阶段二任务体系/双机协作写入边界.md`

## 禁止默认读取

- 同目录其他 L3 替代文件
- `DOCS/98_archive/`
- `DOCS/99_learning/`

## 阻断条件

- 用户没有给出具体 L3 文件路径。
- L3 路径、文件名编号和正文编号不一致。
- 当前分支不符合 L3 所属 Runtime 或 Service 场景分支要求。
- L3 未明确允许修改范围。

## 输出要求

完成后只更新当前 L3 文件和允许修改的代码/测试，并按 L3 归档规则处理任务文件。
