# 阶段二场景五：输出程序与文件

## 预期输出程序

| 程序/模块 | 功能 | 输入 | 输出 |
| --- | --- | --- | --- |
| 格式导出器 | 从 canonical dataset 导出训练格式 | canonical dataset、目标格式配置 | 训练格式文件 |
| 导出验证器 | 验证导出结果可被训练消费 | 导出文件 | 验证报告 |

具体导出器数量和实现取决于最终确定的模型和数据格式。

## 预期输出文件

默认根目录：`asset/阶段二：数据清洗/canonical_dataset_mcap/exports/`。

| 文件 | 位置 | 说明 |
| --- | --- | --- |
| 训练格式文件 | `canonical_dataset_mcap/exports/<format>/` | 根据模型要求生成 |
| 导出报告 | `canonical_dataset_mcap/exports/export_report.json` | 记录导出参数、来源、过滤统计 |
