## 3. L2 Gate 场景覆盖

### S1：类型契约

- **贡献 L3**: deploy_021, deploy_025
- **覆盖要点**: ActionChunk 构造时五项校验（rank 2, 16D, float32, all finite, rows>0），frozen 不可变，无运行元数据字段。非法输入（1D/3D, 维度!=16, float64/int, NaN/Inf, 空 chunk）均抛异常不静默。
- **证据**: 15 个 types 测试 + verify.sh `types.action_chunk_contract` PASS

### S2：阶段一 Observation 批次准备

- **贡献 L3**: deploy_022, deploy_024, deploy_025
- **覆盖要点**: 7 个计算微元（兼容性检查、state tensor 化、state normalize、图像绑定、batch 维、batch 组装、device 对齐）均独立可测。图像按完整 policy key（`observation.images.<camera>`）精确绑定。State normalize 和 action unnormalize 各调用一次。
- **证据**: 29 个 batch 测试 + verify.sh 中 8 个 service.batch.* 标签 PASS

### S3：阶段二 ACT 前向推理

- **贡献 L3**: deploy_024, deploy_025
- **覆盖要点**: 仅调用 `policy.predict_action_chunk(batch)`，在 `torch.no_grad()` 下执行。`select_action` 未调用。前向失败时异常传播。
- **证据**: verify.sh `service.policy.predict_chunk` + `service.policy.no_select_action` + `service.policy.error_propagation` PASS

### S4：阶段三 ActionChunk 后处理

- **贡献 L3**: deploy_023, deploy_024, deploy_025
- **覆盖要点**: 6 个计算微元（raw 结构检查、unbatch、action unnormalize、CPU float32 转换、最终契约检查、ActionChunk 构造）。无 clamp/crop/pad/reorder。无 safety/smoothing 逻辑。
- **证据**: 39 个 postprocess 测试 + verify.sh 中 7 个 service.output.* 标签 PASS
