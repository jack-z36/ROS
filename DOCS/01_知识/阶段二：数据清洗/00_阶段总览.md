# 阶段二：数据清洗总览

## 文档定位

本目录是阶段二数据清洗的稳定知识入口。它服务两个目标：

1. 给阶段三、阶段四的文档规划和程序设计提供前置知识。
2. 给阶段二工程目录下的数据定义、功能模块、L2/L3 文档生成提供概念底座。

这里不记录当前进度、执行记录、dispatch、L3 任务清单或 debug 过程。那些内容属于工程工作台，见 `DOCS/03_工程/阶段二：数据清洗/`。

## 当前权威主线

阶段二的当前主线是把阶段一采集得到的 raw MCAP 处理成 LeRobotDataset v3，用于 PI0.5 / ACT 训练前输入：

```text
raw MCAP
  -> cleaned MCAP
  -> MCAP_A
  -> aligned MCAP
  -> LeRobotDataset v3
  -> PI0.5 / ACT 训练前检查
```

阶段二不是简单另存 MCAP。它要把多 topic 原始日志逐步整理成 step 级 observation/action 数据，并保留配置快照、处理报告、质量摘要和可追溯产物。

## 阅读顺序

1. 先读 `10_数据流与产物/01_主数据链路.md`，建立阶段二整体数据流。
2. 再读 `20_数据定义语义/01_topic世界与step世界.md`，理解 topic 与 step 两套语义。
3. 涉及坐标、单位、时间戳时，读 `20_数据定义语义/02_坐标系单位与时间域.md`。
4. 需要生成 L2/L3 或理解代码职责时，读 `30_能力分层/`。
5. 需要判断能否进入训练前检查时，读 `40_质量与训练前判断/`。
