# ui 层设计：L2-02

## 1. 目标源码路径

```text
src/model_deploy/act/ui/observation_ros_adapter.py
```

## 2. 层职责

`ui/` 是外部交互边界。L2-02 的 ui 层负责把 ROS observation messages 转成 service 层可消费的 RAM 值，并在 callback 后尝试把 ready snapshot 写入 runtime buffer。

ui 层不得实现核心 snapshot 业务规则，不得调用 ACT 模型，不得发布硬件命令。

## 3. 文件设计

### `ObservationRosAdapter`

文件职责：

- 根据 `DeployConfig.topics.observation` 创建 subscription。
- 将 ROS message decode 成 RAM 值。
- 调用 `ObservationCollector.update_*`。
- 调用 `ObservationCollector.snapshot(max_age_s)` 并在 ready 时写入 `ObservationBuffer`。
- 在缺字段或 decode 失败时记录 diagnostics。

class 设计：

| class | 封装微元 | 内部状态 | 生命周期 / 并发 | 为什么是 class |
|---|---|---|---|---|
| `ObservationRosAdapter` | subscription 创建、callback、message decode、try snapshot | ROS node handle、collector、buffer、config、last log time | 随 ROS node 生命周期存在，callback 事件驱动 | 需要持有 node 和 callback 依赖 |

函数设计：

| 函数 | 输入 | 输出 | 副作用 | 错误行为 |
|---|---|---|---|---|
| `create_subscriptions(node)` | ROS node | subscription handles | 注册 ROS subscriptions | topic 缺失时报错 |
| `decode_image_message(msg)` | Image / CompressedImage | RGB RAM image | 读取 message payload | unsupported encoding 抛错 |
| `handle_image(name, msg)` | camera name、message | 无 | 更新 collector，可能写 buffer | decode 失败记录 warning |
| `handle_tcp_pose(side, msg)` | side、pose msg | 无 | 更新 collector，可能写 buffer | shape / quaternion 非法记录 warning |
| `handle_gripper_state(side, msg)` | side、state msg | 无 | 更新 collector，可能写 buffer | 缺 value 记录 warning |
| `try_publish_observation()` | 无 | bool | ready 时写 buffer | missing fields 时只记录 diagnostics |

## 4. ROS import 策略

真实 ROS packages 应延迟 import 或封装在 adapter 初始化路径中，保证以下模块在无 ROS 环境下仍可 import：

- `types/observation.py`
- `service/observation_collector.py`
- `runtime/observation_buffer.py`

如果当前环境缺 ROS，ui 层真实 subscription 验收记录为 `BLOCKED_ENV`，但 mock message decode 和静态检查仍应执行。

## 5. 输入输出

| 输入 | 输出 |
|---|---|
| ROS Image / CompressedImage / Pose / gripper state messages | service update 调用、runtime buffer 写入 |

## 6. 副作用

- 创建 ROS subscription。
- callback 写入 collector / buffer。
- 记录 warning 或 diagnostics。

不发布 command topic，不触发硬件动作。

## 7. 依赖关系

允许依赖：

- `types/observation.py`
- `config` 公开配置对象
- `service/observation_collector.py`
- `service/image_preprocess.py`
- `runtime/observation_buffer.py`
- ROS packages（仅 ui 层）

禁止依赖：

- L2-03 ACT policy runtime
- L2-04 SafetyGuard
- L2-05 command publisher / hardware driver
- L2-06 ControlLoop internals

## 8. Pi0.5 参考

- `Pi05VlaDeployNode._create_subscriptions`
- `Pi05VlaDeployNode._image_cb`
- `Pi05VlaDeployNode._point_cb`
- `Pi05VlaDeployNode._hand_cb`
- `Pi05VlaDeployNode._publish_observation_if_ready`
- `_decode_image`

ACT 必须把这些能力拆成 adapter，而不是把整套 Pi0.5 deploy node 照搬为 L2-02。

## 9. 验收覆盖

- 无 ROS 环境下核心模块 import 不失败。
- mock image / pose / gripper callbacks 能调用 collector。
- decode 失败不更新缓存。
- ready snapshot 写入 buffer。
- 本 L2 不发布硬件命令。

## 10. 边界继承声明

本文件服务当前 L1/L2 功能边界，不从旧 layer-based L2 卡片继承任务边界。
