## <N+1>. TDD 执行要求

执行前必须先完成 L3 任务文件身份校验：用户指定路径、实际读取路径、文件名编号、正文 `L3 编号` 必须一致；不一致或读取失败时必须停止，不得改读同目录其他 L3。

执行前必须确认当前分支是本 L3 所属 L1 feature 分支；Runtime MVP 使用 `runtime-mvp`，Service 使用 `feature/stage2-service`。如果当前分支是 `main` 或其他不匹配分支，必须停止并提示切换。

如果本 L3 涉及代码新增、代码修改、bug 修复或行为变更，必须先读取并使用 `$tdd` 技能：

```text
$tdd
```

执行时按垂直切片推进：一个行为测试或最小复现 -> 最少实现 -> 验证通过 -> 必要整理 -> 下一个行为。

## <N+7>. 完成后交接
