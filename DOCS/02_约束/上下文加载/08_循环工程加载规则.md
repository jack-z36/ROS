# 循环工程加载规则

## 消费 Agent

- OpenCode 主 Agent
- 执行 sub-agent
- 验收 sub-agent
- L2 Gate agent

## 本文职责

本文只定义 Ralph / OpenCode 循环工程任务开始时，各类 Agent 应按什么顺序加载行为约束和状态上下文。

## 不负责

本文不承载循环行为规则正文、阶段四当前进度、L3 任务正文、验收日志、Git 命令细节或执行记录。

## 适用范围

用户要求启动、恢复、设计或执行 Ralph / OpenCode 阶段四循环；或要求主 Agent 按 L2 工作包调度阶段四 L3 执行、验收、状态记录和原子提交。

## 触发信号

- 用户提到 Ralph / OpenCode 循环、循环工程、Stage4 L2 Loop Orchestrator。
- 用户要求自动选择下一个可推进 L2。
- 用户要求按 L2 调度一组 L3 sub-agent。
- 用户要求从阶段四 `00_status` 恢复循环状态。
- 用户要求维护 `ralph_stage4_prompt.md`。

## 主 Agent 加载顺序

1. 读取 `DOCS/02_约束/循环工程/INDEX.md`。
2. 读取行为原子索引：
   - `DOCS/02_约束/循环工程/behaviors/INDEX.md`
3. 读取 Git 协作规则：
   - `DOCS/02_约束/Git协作/Git操作规则.md`
   - `DOCS/02_约束/Git协作/阶段四：模型部署 Git操作规则.md`
4. 读取主 Agent 消费清单：
   - `DOCS/02_约束/循环工程/01_主Agent行为约束.md`
5. 按主 Agent 消费清单读取对应行为原子文件：
   - `DOCS/02_约束/循环工程/00_循环目标与边界.md`
   - `DOCS/02_约束/循环工程/08_循环上下文加载规则.md`
   - `DOCS/02_约束/循环工程/behaviors/01_状态恢复行为.md`
   - `DOCS/02_约束/循环工程/behaviors/02_L2选择行为.md`
   - `DOCS/02_约束/循环工程/behaviors/03_L2开工前检查行为.md`
   - `DOCS/02_约束/循环工程/behaviors/16_环境依赖配置行为.md`
   - `DOCS/02_约束/循环工程/behaviors/04_L3候选选择行为.md`
   - `DOCS/02_约束/循环工程/behaviors/05_任务分配行为.md`
   - `DOCS/02_约束/循环工程/behaviors/09_失败回路处理行为.md`
   - `DOCS/02_约束/循环工程/behaviors/10_L3状态固化行为.md`
   - `DOCS/02_约束/循环工程/behaviors/11_Git原子提交行为.md`
   - `DOCS/02_约束/循环工程/behaviors/12_L2Gate触发行为.md`
   - `DOCS/02_约束/循环工程/behaviors/14_循环快照写入行为.md`
6. 读取阶段四状态入口：
   - `DOCS/03_工程/阶段四：模型部署/00_status/INDEX.md`
7. 按状态入口读取状态摘要：
   - `stage4_loop_goal.md`
   - `l2_progress_status.md`
   - `l3_dispatch_status.md`
   - `git_sync_status.md`
   - `hardware_block_status.md`
   - `current_loop_snapshot.md`
8. 读取阶段四调度和验收权威来源：
   - `DOCS/03_工程/阶段四：模型部署/03_tasks/task/dispatch/*.yaml`
   - 目标 L2 的 `DOCS/03_工程/阶段四：模型部署/05_acceptance/<l2>/验收结果.md`
   - 目标 L2 的 `DOCS/03_工程/阶段四：模型部署/03_tasks/cards/<l2>/<l2>_整体验收卡片.md`

## Sub-Agent 加载规则

执行 sub-agent 只读取：

- `DOCS/02_约束/循环工程/02_执行SubAgent行为约束.md`
- `DOCS/02_约束/循环工程/behaviors/16_环境依赖配置行为.md`
- `DOCS/02_约束/循环工程/behaviors/06_L3执行实现行为.md`
- `DOCS/02_约束/循环工程/behaviors/07_L3局部验证行为.md`
- `DOCS/02_约束/循环工程/behaviors/08_执行交接行为.md`
- 被分配的单个 L3 文件
- 该 L3 文件列出的必读上下文、必读代码和直接依赖记录

验收 sub-agent 只读取：

- `DOCS/02_约束/循环工程/03_验收SubAgent行为约束.md`
- `DOCS/02_约束/循环工程/behaviors/13_L3验收行为.md`
- 被分配的单个 L3 验收卡片
- 对应 L3 文件、执行摘要、允许查看的 diff 和日志

L2 Gate agent 只读取：

- `DOCS/02_约束/循环工程/04_L2Gate行为约束.md`
- `DOCS/02_约束/循环工程/behaviors/15_L2Gate汇总行为.md`
- 目标 L2 dispatch
- 目标 L2 整体验收卡片
- 目标 L2 `验收结果.md`
- 目标 L2 的 L3 验收反馈日志
- 阶段四 `00_status` 中 Git 和硬件 blocked 状态

## 禁止默认读取

- 禁止主 Agent 在启动阶段默认读取全部 L3 正文。
- 禁止 sub-agent 读取未分配的 L2 / L3 任务正文。
- 禁止默认读取 `DOCS/98_archive/` 和 `DOCS/99_learning/`。
- 禁止从历史复盘推断当前循环状态。

## 阻断条件

- `DOCS/02_约束/循环工程/INDEX.md` 不存在。
- `DOCS/03_工程/阶段四：模型部署/00_status/INDEX.md` 不存在。
- Git 全局规则或阶段四 Git 规则未读取。
- 主 Agent 无法确定目标 L2。
- 目标 L2 的 dispatch、验收结果或整体验收卡片缺失。
- 当前任务要求 Git 写操作，但未读取 Git 全局规则和阶段四 Git 规则。

## 输出要求

主 Agent 必须先输出当前循环状态摘要，再说明本轮选择的 L2、可派发 L3、阻塞项和本轮终止条件。
