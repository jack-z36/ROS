# 阶段四模型部署知识总览

## 定位

阶段四负责把训练得到的 PI0.5 / VLA 能力接到真实双臂系统上。它关注模型 bundle、观测采集、动作解码、运行调度、安全约束和 ROS topic 边界，不承载阶段二数据清洗细节。

硬件厂商资料只能说明设备接口能力；阶段四项目知识应说明本项目如何定义模型部署契约。

## PI0.5 部署契约

当前 PI0.5 部署语义以双臂动作和状态契约为中心：

- action 是 14 维：左臂 6 维、右臂 6 维、左右手各 1 维。
- state 是 26 维：左右臂关节、左右手状态、左右末端位置和姿态。
- 手部动作/状态围绕 `TCP_width` 语义进入部署侧契约，避免训练和执行端对夹爪宽度含义各自解释。
- legacy proprioception 可以来自 `[right6, left6]` 顺序，但部署内部应解码为明确的 left/right 字段。

## 配置与运行边界

部署配置应把训练配置、模型 bundle 和真实机器人运行配置分开。阶段四运行时至少需要明确：

- observation topic：模型输入图像、proprioception、左右手状态、左右末端位置和姿态从哪些 ROS topic 来。
- RuntimeConfig：推理频率、控制频率、chunk / horizon、预取、blend、设备、dtype 和 fallback 策略。
- SafetyConfig：最大关节增量、观测超时、命令超时、手部范围、动作 clamp 和 hold-last-action 策略。
- command / bridge / mux topic：模型命令先发布为候选 VLA 输出，再由桥接或 mux 决定是否进入真实执行链路。
