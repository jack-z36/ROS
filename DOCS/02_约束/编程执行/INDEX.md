# Agent 编程执行约束索引

本目录收纳 Agent 修改代码、测试、配置和架构边界时必须遵守的通用规则。它只承载约束，不承载工程进度、执行记录或业务知识。

## 规则入口

| 任务 | 必读规则 |
|---|---|
| 代码新增、修改、补测、配置维护 | `Agent编程执行原则.md` |
| 架构改造、跨层改动、公共类型 / schema / provider / adapter 调整 | `架构边界与机械约束原则.md` |
| Debug / Bugfix 后决定是否补测试或 lint | `Agent编程执行原则.md`、必要时读 `架构边界与机械约束原则.md` |
| 阶段二或阶段四代码类 L3 | `Agent编程执行原则.md`、`架构边界与机械约束原则.md`，再读对应阶段专属 L3 规则 |

## 统一要求

- 通用原则约束所有阶段；阶段专属规则只能补充身份校验、任务调度、归档、分支和验收要求。
- 文档规则能被稳定检查时，应逐步升级为 lint、结构测试、脚本或验收命令。
- 已有机械检查表达的规则，以机械检查结果作为执行和验收依据；文档用于解释意图和修复方向。
