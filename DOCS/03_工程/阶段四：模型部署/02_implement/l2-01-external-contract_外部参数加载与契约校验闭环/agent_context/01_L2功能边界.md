## 1. 一句话运行时职责

在程序启动阶段，把整个部署程序运行依赖的外部静态参数读入当前 Python 进程 RAM，做合规性校验，形成后续所有模块可以稳定 import 的配置对象、数据规格对象和 bundle 契约对象；非法参数在入口处直接失败，阻止程序进入半初始化运行循环。

## 2. 输入

外部静态资源：

```text
deploy.yaml
manifest.json
normalizers.json
experiment_config.yaml
checkpoint 路径
```

这些输入全部是进程外文件。本 L2 不接收 ROS topic，不接收稳态运行数据。

## 3. 输出

进入 Python 进程 RAM 的稳定对象：

```text
DeployConfig
StateSpec / ActionSpec
BundleContractResult
NormalizerContractResult
RuntimeConfig / SafetyConfig / TopicsConfig / ImageConfig / BundleConfig
```

`DeployConfig` 一旦构造成功并校验通过，在程序生命周期内视为不可变。

## 4. 负责内容

- 固定 `observation.state` 的 16D 维度、段序、字段语义和值域。
- 固定 `action` 的 16D 维度、段序、字段语义和值域。
- 固定 `/act/*` observation、policy_action、status、metrics、command topic 名。
- 固定 runtime 参数：`control_hz`、`inference_hz`、`chunk_size`、`mode`、fallback 策略、active chunk / cursor 首版消费所需的最小超时与队列参数。
- 固定 safety 参数：TCP 单步限制、quaternion 检查、gripper width 值域。
- 校验 ACT bundle 交付物是否具备后续 L2-03 加载推理所需文件与元数据。
- 校验 normalizer 维度与 16D state/action 契约一致。
- 把 `deploy.yaml` 的外部值整理成类型化、校验过的配置对象树。

## 5. 不负责内容

- 不订阅 ROS topic（属 L2-02）。
- 不创建 ROS publisher（属 L2-05）。
- 不加载 ACT 权重到模型对象 / 不做模型前向推理（属 L2-03）。
- 不启动控制循环 / 不安排 tick 调度（属 L2-06）。
- 不发送硬件命令（属 L2-05）。
- 不做 runtime 安全检查（属 L2-04；本 L2 只定义 safety 参数，不执行 safety 检查）。
- 不定义 action smoothing、smoothstep blend、跨 chunk 融合、RTC 类平滑或复杂时间对齐参数。第一版由 L2-06 维护 active chunk 与 cursor 并直取当前 step。

## 6. 完成判据

- 合法配置能载入 RAM：字段齐全、取值合法的 `deploy.yaml` + 合法 bundle 能构造 `DeployConfig`、`StateSpec`、`ActionSpec`、bundle/normalizer contract 检查结果。
- 非法配置在入口处失败：缺字段、维度非 16、topic 名非法、bundle 缺文件、normalizer 维度不一致、mode/hz/chunk 参数非法等情形抛出明确异常。
- 下游零猜测：后续 L2 不需要猜 state/action/topic/bundle 长什么样，全部从本 L2 产出的对象读取。
- 无平滑配置泄漏：配置 schema、默认配置和 Gate 说明中不得出现 smoothstep、blend、cross-chunk fusion、RTC alignment 等第一版外能力。

## 7. 代码层落点

| 代码层 | 本 L2 是否落点 | 落点内容 |
|---|---|---|
| `types/` | 是 | `StateSpec`、`ActionSpec`、16D 维度常量、段序定义、codec、contract result 对象 |
| `config/` | 是 | `DeployConfig` schema、子配置 dataclass、配置校验逻辑 |
| `repo/` | 是 | bundle reader、manifest parser、normalizer loader、experiment config loader、checkpoint 路径解析 |
| `config_files/` | 是 | `deploy.yaml` 配置实例 |
| `service/` | 否 | 本 L2 不做 observation/batch/safety/action 业务计算 |
| `runtime/` | 否 | 本 L2 不做时间/线程/队列/调度，不做 chunk cursor 状态维护 |
| `ui/` | 否 | 本 L2 不做 ROS node / topic 订阅发布 |

## 8. 上下游

- 上游：无。本 L2 是全部后续 L2 的静态契约地基。
- 下游：全部 L2 都 import `DeployConfig` / `StateSpec` / `ActionSpec`。
- L2-06 从本 L2 读取 `chunk_size`、`control_hz`、fallback 策略和最小 cursor 消费参数，但 action 平滑优化不属于本 L2，也不属于第一版 Gate。
